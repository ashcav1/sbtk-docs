    Density models by component type#

    Last edited October 20, 2026

    One example per component type and model feature. Each example after the first is a fragment: it uses the body and uncertainties defined in the setup script below, which must be run first. Building a true model and its exact values (sbtk.data.simulate) needs no uncertainties; only the examples that make measurements and estimate densities use unc. Geometry definitions: Density distributions.

    Setup#

    MATLAB script: Body and uncertainties used by the examples on this page
    run("/path/to/SBTK/sbtk_setup.m")
body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);    % mass [kg], R_ref [km]
unc  = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);   % for measurements

    Sphere#

    A sphere is given by its center (shape-model frame, km), radius and relative density. A sphere entirely inside the body is integrated as a point mass. sbtk.interior.latlon gives a position by latitude, longitude and distance; added to the center of figure, as here, it is measured from there (Where to place components).

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    core    = sbtk.interior.sphere("core", body.centroid_km, 0.170, +450);
boulder = sbtk.interior.sphere("boulder", body.centroid_km + sbtk.interior.latlon(25, 60, 0.250), 0.040, +900);
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create([core, boulder]), 4, "spheres");
fprintf("center of mass - center of figure: [%.1f %.1f %.1f] m\n", 1e3*exact.com_minus_cof_km)

    Ellipsoid#

    Semi-axes along x, y, z before the rotation by yaw (about z), pitch (about y) and roll (about x), in degrees.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    lens = sbtk.interior.ellipsoid("lens", body.centroid_km + [0.05 0.10 0.12], [0.20 0.08 0.05], [40 -30 15], +300);
disp(lens.axes)                                   % columns: the ellipsoid axes in the shape-model frame
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(lens), 4, "ellipsoid");
sbtk.plot.slices(body, {truth}, {'ellipsoid'});

    Torus#

    A torus about the z-axis: ring radius, tube radius, height of its plane. Only the part inside the body counts, so a torus that crosses the surface at the equator represents a belt of different density along the equator. Set its center_km to place it about the center of figure, and align it with the spin axis with sbtk.interior.align_with_spin_axis (Axes of components).

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    torus = sbtk.interior.torus("torus", 0.370, 0.055, 0, -500);
torus.center_km = body.centroid_km;                          % about the z-axis through the center of figure
geo = sbtk.gravity.geometry(body, body.centroid_km, 0);
I = sbtk.gravity.component_integrals(geo, torus);
fprintf("torus volume inside the body: %.5f km^3 (%.1f%% of the body)\n", I.V, 100*I.V/body.volume_km3)

    Layer#

    Top and bottom depth below the surface, along rays from the expansion origin.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    regolith = sbtk.interior.layer("regolith", 0, 0.012, -900);          % the outermost 12 m
mantle   = sbtk.interior.layer("mantle", 0.012, 0.080, -200);        % from 12 m to 80 m deep
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create([regolith, mantle]), 4, "layers");
fprintf("background density %.0f kg/m^3\n", truth.rho_bg_kgm3)

    Sector#

    Radial fractions of the distance from the expansion origin to the surface, a latitude range and a longitude range (degrees). Longitude ranges may extend beyond ±180°.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    block = sbtk.interior.sector("block", [0.3 0.9], [40 90], [150 240], +200);    % northern block across 180 deg
shell = sbtk.interior.sector("shell", [0.5 0.75], [-90 90], [-180 180], -300); % a shell that follows the shape
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create([block, shell]), 4, "sectors");
sbtk.plot.slices(body, {truth}, {'sectors'});

    Sector grid#

    A grid of sectors that fills the body is a model without assumed structure. As an estimation model it needs the background held at the bulk density and, with many sectors, regularization. Here the true interior is a dense core and the estimate uses 36 sectors.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    [exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(sbtk.interior.sphere("core", body.centroid_km, 0.17, +450)), ...
                                    4, "core");
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);       % measurements of it
sectors = sbtk.interior.sector_grid([0 0.5 0.85 1], [-90 -30 30 90], [-180 -90 0 90 180]);   % 3 x 3 x 4
prob = sbtk.invert.setup(body, sectors, obs, sbtk.invert.options(background="bulk"));
prob.opts.regularization = sbtk.invert.choose_regularization(prob);
fit = sbtk.invert.run(prob);
fprintf("lambda %.3g, reduced chi2 %.2f, dof %.1f\n", fit.regularization, fit.chi2_reduced, fit.dof)
sbtk.plot.slices(body, {truth, fit}, {'true density', 'sector estimate'});

    Random density field#

    Standard deviation (kg/m³), correlation length (km) and seed. The field is added to the components; it is used in simulations and is not estimated by the inversion.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    field = sbtk.interior.random_field(40, 0.06, 7);                     % sigma 40 kg/m^3, correlation length 60 m
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(sbtk.interior.no_components(), field), 4, "field");
grid = sbtk.exchange.density_grid(body, truth, 0.020);              % density at 20 m cell centers inside the body
fprintf("%d cells: mean %.0f, standard deviation %.1f kg/m^3\n", numel(grid.density_kgm3), ...
        mean(grid.density_kgm3), std(grid.density_kgm3))

    Homogeneous body#

    sbtk.interior.no_components without a random field gives a uniform density M/V.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    [exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(sbtk.interior.no_components()), 4, "uniform");
fprintf("background %.1f kg/m^3, bulk density %.1f kg/m^3\n", truth.rho_bg_kgm3, body.bulk_density_kgm3)

    Prescribed component#

    A component with estimate_density = false keeps its relative density in the inversion; here a regolith layer of known density while the core is estimated.

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    truth_components = [sbtk.interior.sphere("core", body.centroid_km, 0.17, +450), sbtk.interior.layer("regolith", 0, 0.012, -900)];
exact = sbtk.data.simulate(body, sbtk.interior.create(truth_components), 4, "prescribed");
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
model = truth_components;
model(1).drho_kgm3 = 0;                  % estimated: the value is not used
model(2).estimate_density = false;       % prescribed: -900 kg/m^3 is kept
fit = sbtk.invert.solve(body, model, obs);
sbtk.invert.summary(fit)

    Estimated sphere position#

    The center of a sphere with estimate_position = true is estimated with its density; position_sigma_km adds an a priori constraint about the starting position. The center, height and orientation of tori and ellipsoids can be estimated the same way (Estimated geometry).

    MATLAB fragment. Requires the variables defined in Body and uncertainties used by the examples on this page.
    truth_components = sbtk.interior.sphere("core", body.centroid_km + [0.03 -0.02 0.01], 0.17, +500);
exact = sbtk.data.simulate(body, sbtk.interior.create(truth_components), 4, "position");
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
model = sbtk.interior.sphere("core", body.centroid_km, 0.17, 0);       % started at the center of figure
model.estimate_position = true;
fit = sbtk.invert.solve(body, model, obs, sbtk.invert.options(position_sigma_km=0.050));
fprintf("center [%.1f %.1f %.1f] m from the center of figure +- [%.1f %.1f %.1f] m after %d iterations\n", ...
        1e3*(fit.components(1).center_km - body.centroid_km), 1e3*fit.center_sigma_km(1, :), fit.iterations)
