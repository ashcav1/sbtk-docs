    Tutorial scripts#

    The repository folder examples/ contains eight tutorial scripts with sections. Each adds toolbox/ to the path itself and can be run whole or section by section. All eight run in the test suite (tests/integration/test_examples.m, also section by section for ex01). The code below is included from the repository files.

    Script Topic Run time
    ex01_quick_start.m Body, interior, simulation, inversion, comparison on the 1.165 m Didymos model about 90 s
    ex02_shapes_and_bodies.m Shape models from files, arrays and ellipsoids; checks; bodies about 5 s
    ex03_forward_model.m Every component type, a random field, the simulated measurements, plots about 20 s
    ex04_inversion.m Homogeneous test, inertia data, sphere positions, regularization, calibration about 30 s
    ex05_import_data.m Measurements from matrices, kg m², a full covariance, the text format about 5 s
    ex06_results_folders.m Run folders, reports, logs, settings about 30 s
    ex07_exchange_packages.m Measurement, interior-model and solution packages about 40 s
    ex08_moments_of_inertia.m What inertia data and the libration ratio add to the gravity field about 20 s

    ex01: quick start#

    The sequence of the first script on the full-resolution Didymos model (3,145,728 facets), which is not in the repository (Installation). With "didymos" instead of "didymos_highres" it runs in about 15 s.

    MATLAB script: examples/ex01_quick_start.m
    %% EX01_QUICK_START  Simulate measurements of an interior, invert them, compare with the true model. (~90 s with the 1.165 m shape model)
%
% The SBTK workflow on the Didymos shape model:
%   1. a body: shape model, bulk density, reference radius
%   2. forward model: components -> gravity coefficients and moments of inertia
%   3. inversion: measurements + component geometry -> densities with 1-sigma uncertainties
%   4. comparison with the true model

addpath(fullfile(fileparts(fileparts(which('ex01_quick_start'))), 'toolbox'));

%% 1. Body
body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos_highres"), 5.273e11, 0.43);   % mass [kg], R_ref [km] (Hera end-to-end test)
sbtk.body.summary(body)

%% 2. Forward model: a dense core and a low-density surface layer
components = [sbtk.interior.sphere("core", [0 0 0], 0.170, +450), ...      % center [km], radius [km], relative density [kg/m^3]
              sbtk.interior.layer("regolith", 0, 0.012, -900)];           % from 0 to 12 m below the surface
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(components), 4, "quick_start");   % exact values

% measurements: 1-sigma uncertainties, then one noise realization
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), ...  % degree 1: 2 m center of mass
                               1e-4, 2e-4, 4e-4], ...                          % degrees 2, 3, 4
                              2e-3, ...                                        % each MOI / (M R_ref^2)
                              0.02);                                           % libration ratio
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
sbtk.data.summary(obs)

%% 3. Inversion: the same components, relative densities unknown
% (the relative densities given with the components are not used: they are estimated)
fit = sbtk.invert.solve(body, components, obs);
sbtk.invert.summary(fit)

%% 4. Comparison with the true model
cmp = sbtk.compare.with_truth(body, truth, fit);
sbtk.compare.summary(cmp)
sbtk.plot.densities(fit);
sbtk.plot.truth_vs_estimate(body, truth, fit);

    ex02: shapes and bodies#

    Shape models from an OBJ file with a stated unit, from arrays (a tetrahedron in meters) and as an ellipsoid; the checks of sbtk.shape.properties; writing OBJ; a body; the unit table.

    MATLAB script: examples/ex02_shapes_and_bodies.m
    %% EX02_SHAPES_AND_BODIES  Shape models from files or arrays, units, checks. (~5 s)
%
% Any closed polyhedral shape works if it is star-shaped about its center of
% mass (every facet visible from it). Lengths are converted to km on input:
% the unit of the file must be given.

addpath(fullfile(fileparts(fileparts(which('ex02_shapes_and_bodies'))), 'toolbox'));

%% From an OBJ file (unit stated explicitly)
didymos = sbtk.shape.load(fullfile(sbtk.root, "data", "shapes", "didymos_g_9309mm_spc_obj_0000n00000_v003.obj"), "km");
% the shape models that ship with SBTK also load by name:
%   sbtk.shape.bundled("didymos"), ("bennu"), ("dimorphos_placeholder"), ("example_asteroid")
props = sbtk.shape.properties(didymos);
fprintf('%s: %d facets, volume %.5f km^3, centroid [%.1f %.1f %.1f] m, star-shaped: %d\n', didymos.name, ...
        props.n_facets, props.volume_km3, 1e3*props.centroid_km, props.star_shaped_about_centroid);

%% From arrays (here a tetrahedron given in meters)
V = [0 0 0; 100 0 0; 0 100 0; 0 0 100] - 25;          % vertices [m]
F = [1 3 2; 1 2 4; 1 4 3; 2 3 4];                      % facets, outward
tetra = sbtk.shape.from_arrays("tetra", F, V, "m");
disp(sbtk.shape.properties(tetra))

%% A triaxial ellipsoid (exact test shape), saved to OBJ
ell = sbtk.shape.ellipsoid("test_ellipsoid", [0.40 0.35 0.30], 4);     % 5,120 facets
file = fullfile(tempdir, 'test_ellipsoid.obj');
sbtk.shape.write_obj(ell, file);
ell2 = sbtk.shape.load(file, "km");

%% Bodies: shape + bulk density + reference radius of the gravity field
body = sbtk.body.create("Ellipsoid", ell2, 2200, 0.40);
sbtk.body.summary(body)
sbtk.plot.shape(body);
sbtk.units.table()

    ex03: forward model#

    Every component type and a random field, the simulated measurements as a table, the density at given points, and the three-dimensional, slice and measurement figures.

    MATLAB script: examples/ex03_forward_model.m
    %% EX03_FORWARD_MODEL  Every component type, a random density field, and the simulated measurements. (~20 s)
%
% Components are regions of uniform relative density (density minus the
% background density). Overlapping relative densities add and components are
% clipped to the body. The background density follows from the total mass.

addpath(fullfile(fileparts(fileparts(which('ex03_forward_model'))), 'toolbox'));
body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);

%% Components
components = [ ...
  sbtk.interior.sphere("core", [0 0 0], 0.170, +250), ...                                 % center, radius
  sbtk.interior.ellipsoid("lens", [0.05 0.10 0.12], [0.20 0.08 0.05], [40 -30 15], +300), ... % center, semi-axes, yaw/pitch/roll
  sbtk.interior.torus("torus", 0.370, 0.055, 0.000, -500), ...                            % ring radius, tube radius, height
  sbtk.interior.layer("regolith", 0.000, 0.012, -900), ...                                % top, bottom depth
  sbtk.interior.sector("block", [0.3 0.9], [40 90], [150 240], +200), ...                 % radial fraction, lat, lon
  sbtk.interior.sphere("boulder", sbtk.interior.latlon(25, 60, 0.250), 0.040, +900)];     % position from lat/lon/distance
sbtk.interior.summary(components)

%% Gaussian random density field (standard deviation 40 kg/m^3, correlation length 60 m, seed 7)
interior = sbtk.interior.create(components, sbtk.interior.random_field(40, 0.06, 7));

%% Forward model: the true model and its exact gravity coefficients and moments of inertia
[exact, truth, geo] = sbtk.data.simulate(body, interior, 4, "example_interior");

%% Measurements of it: uncertainties, then noise drawn from them
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
fprintf('background density %.0f kg/m^3, center of mass %.1f m from the center of figure\n', ...
        truth.rho_bg_kgm3, 1e3*norm(obs.com_minus_cof_km));

% What the measurements look like
disp(table(obs.coef_labels(1:8), obs.coef(1:8), sqrt(diag(obs.coef_cov(1:8, 1:8))), ...
           'VariableNames', {'label', 'value', 'sigma'}))
disp(struct2table(obs.moi))

%% Density anywhere inside (truth frame = center of mass)
rho = sbtk.interior.density_at(truth, [0 0 0; 0.3 0 0] + truth.origin_km, geo);
fprintf('density at the center %.0f, 300 m out along x %.0f kg/m^3\n', rho);

%% Plots
sbtk.plot.interior3d(body, truth, "example interior");
sbtk.plot.slices(body, {truth}, {'truth'});
sbtk.plot.measurements(obs);

    ex04: inversion options#

    The homogeneous test; fits with and without inertia data; estimation of a sphere center; a 36-sector grid with Tikhonov regularization chosen by the discrepancy principle; and the standard deviation of (estimate − truth)/σ over 50 noise realizations using sbtk.invert.replace_data.

    MATLAB script: examples/ex04_inversion.m
    %% EX04_INVERSION  Inversion options: homogeneous model, MOI, sphere positions, regularization. (~30 s)
%
% setup does the slow part once (geometry and each component's effect on every
% measurement); run solves in milliseconds, so trying options is cheap.

addpath(fullfile(fileparts(fileparts(which('ex04_inversion'))), 'toolbox'));
body  = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);
unc   = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);
truth_components = [sbtk.interior.sphere("core", [0.03 -0.02 0.01], 0.17, +500), ...
               sbtk.interior.torus("torus", 0.37, 0.055, 0, -500), sbtk.interior.layer("regolith", 0, 0.012, -900)];
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(truth_components), 4, "ex04");
exact = sbtk.data.set_uncertainties(exact, unc);
obs = sbtk.data.add_noise(exact, 1);

%% Set up once
% Component geometry is fixed (the core is placed at the origin, off the true center);
% relative densities are estimated, so their values here are not used.
components = [sbtk.interior.sphere("core", [0 0 0], 0.17, 0), sbtk.interior.torus("torus", 0.37, 0.055, 0, 0), ...
              sbtk.interior.layer("regolith", 0, 0.012, 0)];
opts = sbtk.invert.options();             % every setting and its standard value
disp(opts)
prob = sbtk.invert.setup(body, components, obs, opts);

%% Is a homogeneous body consistent with the measurements?
u = sbtk.invert.homogeneous(prob);
fprintf('homogeneous body: reduced chi2 %.2f, p = %.2g\n', u.chi2_reduced, u.p_value);

%% Fit, and the same with gravity only (no MOI): MOI shrink the uncertainties
fit = sbtk.invert.run(prob);
sbtk.invert.summary(fit)
fit_g = sbtk.invert.solve(body, components, obs, sbtk.invert.options(moi_labels={}));
fprintf('core 1-sigma: %.0f kg/m^3 with MOI, %.0f without\n', fit.rho_sigma_kgm3(1), fit_g.rho_sigma_kgm3(1));

%% Estimate the core position as well
moving = components;  moving(1).estimate_position = true;
fit_p = sbtk.invert.solve(body, moving, obs);
fprintf('core center [%.0f %.0f %.0f] m +- [%.0f %.0f %.0f] m (truth [30 -20 10] m from the shape origin)\n', ...
        1e3*fit_p.components(1).center_km, 1e3*fit_p.center_sigma_km(1, :));

%% Tikhonov regularization for many components (36-sector grid), parameter by the discrepancy principle
% The sectors fill the body, so the background is held at the bulk density.
sectors = sbtk.interior.sector_grid([0 0.5 0.85 1], [-90 -30 30 90], [-180 -90 0 90 180]);
probc = sbtk.invert.setup(body, sectors, obs, sbtk.invert.options(background="bulk"));
probc.opts.regularization = sbtk.invert.choose_regularization(probc);
fitc = sbtk.invert.run(probc);
fprintf('sector grid: lambda %.3g, reduced chi2 %.2f (dof %.1f)\n', fitc.regularization, fitc.chi2_reduced, fitc.dof);

%% Calibration of the uncertainties: 50 noise realizations
z = zeros(50, 4);
for k = 1:50
    f = sbtk.invert.run(sbtk.invert.replace_data(prob, sbtk.data.add_noise(exact, 100 + k)));
    z(k, :) = ([f.rho_bg_kgm3, [f.components.drho_kgm3]] - [truth.rho_bg_kgm3, [truth_components.drho_kgm3]]) ...
              ./[f.rho_bg_sigma_kgm3, f.drho_sigma_kgm3];
end
fprintf('standard deviation of (estimate - truth)/sigma: %.2f (1 for calibrated uncertainties)\n', std(z(:)));
sbtk.plot.residuals(fit);

    ex05: importing data#

    A measurement set from coefficient matrices; inertia given in kg m²; a libration ratio; a full covariance; the text format written and read back; selection of degrees.

    MATLAB script: examples/ex05_import_data.m
    %% EX05_IMPORT_DATA  Measurements from arrays, kg m^2, a full covariance, and text files. (~5 s)
%
% Real data arrive as coefficient matrices with uncertainties (and maybe a full
% covariance) and as moments of inertia. This builds an SBTK measurement set
% from them, in the units SBTK uses.

addpath(fullfile(fileparts(fileparts(which('ex05_import_data'))), 'toolbox'));
body = sbtk.body.from_mass("Dimorphos", sbtk.shape.bundled("dimorphos"), 2.700e9, 0.10);

%% Coefficient matrices: C(l+1, m+1) = C_lm, fully normalized about origin_km
L = 2;
C = zeros(L + 1);  S = zeros(L + 1);
C(1,1) = 1;  C(3,1) = -0.08;  C(3,3) = 0.03;  S(3,3) = 0.002;     % C00, C20, C22, S22
Cs = 1e-3*ones(L + 1);  Ss = 1e-3*ones(L + 1);                     % 1-sigma of each
obs = sbtk.data.from_coefficients(body, "example_import", [0 0 0], C, S, Cs, Ss);

%% Moments of inertia, given in kg m^2 -> I/(M R_ref^2)
Izz_kgm2 = 1.6e14;
Izz = sbtk.units.moi_to_norm(Izz_kgm2, body.mass_kg, body.R_ref_km);
obs = sbtk.data.add_moi(obs, "Izz", Izz, 0.01*Izz);
obs = sbtk.data.add_libration(obs, 0.20, 0.03, Izz);                % (B-A)/C and its 1-sigma

%% A full covariance (here: 30% correlation between all coefficients)
sig = sqrt(diag(obs.coef_cov));
corr = 0.3*ones(numel(sig)) + 0.7*eye(numel(sig));
obs = sbtk.data.set_covariance(obs, corr.*(sig*sig'));
sbtk.data.summary(obs)

%% The SBTK text format: write it, read it back
% (for data to send to other teams see ex07_exchange_packages.m)
file = fullfile(tempdir, 'example_measurements.txt');
sbtk.io.write_measurements(obs, file);
type(file)
back = sbtk.io.load_measurements(file);     % (the text keeps only the diagonal of the covariance)

%% Use fewer degrees
obs1 = sbtk.data.select_degree(obs, 1);
fprintf('%d coefficients up to degree 1\n', numel(obs1.coef));

    ex06: results folders#

    A simulation, an inversion of the newest simulation found with sbtk.io.latest_run, and a comparison, each in its own run folder with log, settings and figures (Results folders).

    MATLAB script: examples/ex06_results_folders.m
    %% EX06_RESULTS_FOLDERS  Standard outputs: run folders, reports, logs, settings. (~30 s)
%
% Every run gets results/<project>/<date_time>_<name>/ with standard file names,
% settings.json (every number used) and log.txt (everything printed). The
% report_* functions save, print and plot the standard set in one call.

addpath(fullfile(fileparts(fileparts(which('ex06_results_folders'))), 'toolbox'));
shape = sbtk.shape.ellipsoid("ellipsoid", [0.40 0.35 0.30], 4);
body  = sbtk.body.create("Ellipsoid", shape, 2200, 0.40);
unc   = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.40), 1e-4, 2e-4], 2e-3, 0.02);

%% Simulation
components = [sbtk.interior.sphere("core", [0.03 0 0], 0.15, +600), sbtk.interior.layer("regolith", 0, 0.02, -700)];
out = sbtk.io.new_run("examples", "ellipsoid_T1");
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(components), 3, "ellipsoid_T1");
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
sbtk.io.report_simulation(out, body, obs, truth);
sbtk.io.finish_run(out);

%% Inversion of the newest simulation
obs = sbtk.io.load_measurements(sbtk.io.latest_run("examples", "ellipsoid_T1"));
out = sbtk.io.new_run("examples", "ellipsoid_T1_inversion");
prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
fit = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, fit, sbtk.invert.homogeneous(prob));
sbtk.io.finish_run(out);

%% Comparison with the true model
truth = sbtk.io.load_truth(sbtk.io.latest_run("examples", "ellipsoid_T1"));
out = sbtk.io.new_run("examples", "ellipsoid_T1_comparison");
sbtk.io.report_comparison(out, body, truth, fit, sbtk.compare.with_truth(body, truth, fit));
sbtk.io.finish_run(out);
dir(out.folder)

    ex07: exchange packages#

    A blind test in miniature: one team writes a measurement package and an interior-model package; another reads the measurement package, inverts it and writes a solution package; the solution is compared with the hidden model on the density grid (Exchange packages).

    MATLAB script: examples/ex07_exchange_packages.m
    %% EX07_EXCHANGE_PACKAGES  Data for other teams: measurement, interior-model and solution packages. (~40 s)
%
% A blind test: one team simulates measurements of an interior it keeps hidden and
% sends only the measurement package; another team inverts the package and sends a
% solution package; at the end both are compared with the hidden model on a common
% density grid. Every package is plain text with its units, frame and normalization
% written in it (docs/exchange_format.md). projects/hera_hlp6 does the same with
% results folders.

addpath(fullfile(fileparts(fileparts(which('ex07_exchange_packages'))), 'toolbox'));
body = sbtk.body.create("Example asteroid", sbtk.shape.bundled("example_asteroid"), 2000, 0.60);
unc  = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.005, 0.60), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);
folder = tempname;                         % where the packages go (normally a results folder)

%% The team that makes the data
hidden = [sbtk.interior.sphere("core", [0.03 0 0], 0.25, +500), sbtk.interior.layer("regolith", 0, 0.02, -800)];
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(hidden), 4, "hidden_model");
exact = sbtk.data.set_uncertainties(exact, unc);      % noise-free values with their uncertainties
obs = sbtk.data.add_noise(exact, 1);
data = sbtk.exchange.write_data(folder, "TEAM-DATA1-example", body, obs, "Team, contact");         % send now
model = sbtk.exchange.write_model(folder, "TEAM-MOD1-example", "TEAM-DATA1-example", body, truth, ...
                                  exact, 0.04, "Team, contact");                                     % send at the end
type(fullfile(data, 'README.txt'))

%% The team that inverts it: everything comes from the package
[obs2, body2] = sbtk.exchange.read_data(data);          % shape model, GM and reference radius included
components = [sbtk.interior.sphere("core", [0 0 0], 0.25, 0), sbtk.interior.layer("regolith", 0, 0.02, 0)];
prob = sbtk.invert.setup(body2, components, obs2, sbtk.invert.options());
fit  = sbtk.invert.run(prob);
sbtk.invert.summary(fit)
solution = sbtk.exchange.write_solution(folder, sbtk.exchange.solution_name("OTHER", obs2.name), body2, fit, ...
                                        sbtk.invert.homogeneous(prob), 0.04, "Other team, contact");

%% At the end: the solution against the hidden model, cell by cell
cmp = sbtk.compare.grids(sbtk.exchange.read_grid(fullfile(model, 'density_grid.txt')), ...
                         sbtk.exchange.read_grid(fullfile(solution, 'density_grid.txt')));
sbtk.compare.grid_summary(cmp);

    ex08: moments of inertia and the libration ratio#

    The same inversion with no inertia data, Izz, the libration ratio at two precisions, and Ixx, Iyy, Izz; the libration ratio from an observed libration amplitude; adding measured inertia values (Moments of inertia).

    MATLAB script: examples/ex08_moments_of_inertia.m
    %% EX08_MOMENTS_OF_INERTIA  What moments of inertia and the libration ratio add to the gravity field. (~20 s)
%
% The degree-2 gravity coefficients fix five combinations of the inertia tensor
% (C20 ~ (Ixx + Iyy - 2 Izz), C22 ~ (Iyy - Ixx), C21, S21, S22 ~ products of inertia),
% but not its trace. A dense core and a light surface layer can therefore give the
% same gravity field, and the inversion cannot separate them. A moment of inertia
% such as the polar moment Izz (from the spin state) adds the missing combination:
% it measures how concentrated the mass is toward the center.
%
% The libration ratio (B - A)/C (principal moments: A <= B about the axes in the
% xy-plane, C = Izz) comes from the libration amplitude of a synchronously rotating body
% (e.g. Dimorphos). The degree-2 field gives B - A, so the ratio gives C: it carries the
% same information as a polar moment, with a relative precision of sigma/ratio.

addpath(fullfile(fileparts(fileparts(which('ex08_moments_of_inertia'))), 'toolbox'));
body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);

%% Simulated measurements: every inertia quantity is available
truth_components = [sbtk.interior.sphere("core", [0 0 0], 0.170, +450), ...
                    sbtk.interior.layer("regolith", 0, 0.012, -900)];
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(truth_components), 4, "ex08");
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], ...
                              2e-3, ...        % 1-sigma of each inertia element, as a fraction of M R_ref^2
                              0.02);           % 1-sigma of the libration ratio
exact = sbtk.data.set_uncertainties(exact, unc);
obs = sbtk.data.add_noise(exact, 1);
disp(struct2table(rmfield(obs.moi, 'weights')))    % Ixx Iyy Izz Ixy Ixz Iyz libration, as I/(M R_ref^2)

%% The same inversion with different inertia measurements
% opts.moi_labels chooses which of the data's inertia rows are fitted. The libration
% ratio of this body is about 0.056, so the simulated 1-sigma of 0.02 (36%) says little;
% a ratio measured to 0.001 (1.8%) is added as a separate data set (sbtk.data.add_libration).
gravity  = sbtk.data.select_moi(obs, {});                                % gravity coefficients only
precise  = sbtk.data.add_libration(gravity, exact.libration_ratio, 0.001, obs.moi(3).value);
cases = {'none (gravity only)',    obs,     {}
         'Izz',                    obs,     {'Izz'}
         'libration +- 0.02',      obs,     {'libration'}
         'libration +- 0.001',     precise, {'libration'}
         'Ixx Iyy Izz',            obs,     {'Ixx', 'Iyy', 'Izz'}};
fprintf('\n%-22s %18s %18s %12s %8s\n', 'inertia used', 'core [kg/m^3]', 'regolith [kg/m^3]', 'correlation', 'chi2/nu');
for k = 1:size(cases, 1)
    fit = sbtk.invert.solve(body, truth_components, cases{k, 2}, sbtk.invert.options(moi_labels=cases{k, 3}));
    fprintf('%-22s %10.0f +- %4.0f %10.0f +- %4.0f %12.2f %8.2f\n', cases{k, 1}, fit.rho_kgm3(1), ...
            fit.rho_sigma_kgm3(1), fit.rho_kgm3(2), fit.rho_sigma_kgm3(2), fit.corr(2, 3), fit.chi2_reduced);
end
fprintf('%-22s %10.0f %20.0f\n', 'true', truth.rho_bg_kgm3 + truth_components(1).drho_kgm3, ...
        truth.rho_bg_kgm3 + truth_components(2).drho_kgm3);
% correlation: between the core and regolith relative densities (near 1 = the data
% cannot tell them apart).
% Izz halves the regolith uncertainty. The libration ratio gives C = (B - A)/ratio, so it
% constrains C as well as the ratio is known relative to its value: +-0.001 is 1.8% of
% C and helps, Izz +-0.002 is 0.5% and helps more.

%% A libration ratio from the observed libration amplitude
% A synchronous satellite in an orbit of eccentricity e librates with amplitude
% 2e/(3 ratio - 1) (forced libration, first order in e). Near ratio = 1/3 (elongation
% about 1.4 : 1) the amplitude is large and fixes the ratio precisely; a nearly
% axisymmetric body librates little and the ratio stays uncertain.
for amp = [-4 -12]
    [k, sk] = sbtk.data.libration_ratio_from_amplitude(amp, 0.2, 0.027, 0.001);   % deg, deg, e, sigma e
    fprintf('amplitude %5.1f +- 0.2 deg, e = 0.027 +- 0.001: (B - A)/C = %.3f +- %.4f (%.0f%%)\n', ...
            amp, k, sk, 100*sk/k);
end

%% Your own inertia measurements
% Start from the gravity coefficients (a package, a SHADR file, coefficient matrices,
% ...) and add each measured quantity. Values given in kg m^2 convert with
% sbtk.units.moi_to_norm; inertia is about the center of mass, shape-model axes.
Izz_kgm2 = sbtk.units.norm_to_moi(obs.moi(3).value, body.mass_kg, body.R_ref_km);   % e.g. a measured polar moment
mine = sbtk.data.add_moi(gravity, "Izz", sbtk.units.moi_to_norm(Izz_kgm2, body.mass_kg, body.R_ref_km), 2e-3);
mine = sbtk.data.add_libration(mine, exact.libration_ratio, 0.001, mine.moi(1).value);  % (B - A)/C, 1-sigma, Izz
fit = sbtk.invert.solve(body, truth_components, mine, sbtk.invert.options(moi_labels={'Izz', 'libration'}));
sbtk.invert.summary(fit)
