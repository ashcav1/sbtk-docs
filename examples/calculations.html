    Calculations#

    Short examples of individual calculations. Fragments on this page use the variables of the setup script below.

    Setup#

    MATLAB script: Body, interior and measurements used by the examples on this page
    run("/path/to/SBTK/sbtk_setup.m")
body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);
components = [sbtk.interior.sphere("core", [0 0 0], 0.170, +450), sbtk.interior.layer("regolith", 0, 0.012, -900)];
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(components), 4, "calculations");   % the true model
unc  = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);
exact = sbtk.data.set_uncertainties(exact, unc);                     % exact values with uncertainties
obs = sbtk.data.add_noise(exact, 1);                                 % one noisy realization

    Unit conversions#

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    Izz = sbtk.units.moi_to_norm(1.6e16, body.mass_kg, body.R_ref_km)    % kg m^2 -> I / (M R_ref^2)
I_kgm2 = sbtk.units.norm_to_moi(Izz, body.mass_kg, body.R_ref_km)    % and back
c = sbtk.units.offset_to_degree1(0.002, body.R_ref_km)               % 2 m center-of-mass offset -> degree 1
f = sbtk.units.length_scale("m")                                     % m -> km: 1e-3

    Volume and moments of one component#

    sbtk.gravity.component_integrals returns the integrals of the part of a component inside the body, per unit density, about the origin of the geometry.

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    geo = sbtk.gravity.geometry(body, truth.origin_km, 4);
I = sbtk.gravity.component_integrals(geo, components(2));            % the regolith layer
fprintf("regolith volume %.5f km^3 = %.1f%% of the body\n", I.V, 100*I.V/geo.V_body)
mass_deficit_kg = components(2).drho_kgm3*I.V*1e9                   % its mass relative to the background

    Coefficients and inertia about another origin#

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    geo0 = sbtk.gravity.geometry(body, [0 0 0], 4);                       % about the shape-model origin
fm = sbtk.gravity.forward(geo0, sbtk.interior.create(components), body.mass_kg);
lab = sbtk.gravity.labels(4);
fprintf("C11 about the shape origin %.4e; about the center of mass %.1e\n", ...
        fm.coef(strcmp(lab, "C11")), truth.coef(strcmp(lab, "C11")))

    Difference from the homogeneous body#

    The gravity coefficients of the true model and of the measurements, minus those of a body of uniform density, with the 3σ of the measurements (Figures). The second output holds the plotted values; axes_deg gives the angles between the principal axes of each set and of the homogeneous body.

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    [fig, d] = sbtk.plot.difference_from_homogeneous(body, {obs, truth}, ["measured" "true model"], "linear", "shape");
fprintf("%s: %+.2e\n", [d(2).labels(1:4); string(d(2).difference(1:4))])   % C10, C11, S11, J2 of the true model
sbtk.plot.difference_from_homogeneous(body, {obs, truth}, ["measured" "true model"], "log", "shape");
[~, dp] = sbtk.plot.difference_from_homogeneous(body, {truth}, "true model", "linear", "principal");
fprintf("principal axes of the true model vs the homogeneous body: tilt %.2f deg, turn %.2f deg\n", dp.axes_deg)

    Field about the center of mass, in spin and principal axes#

    sbtk.gravity.center_of_mass_frame moves a field to its center of mass (degree 1 becomes 0) and, with "spin", turns its axis of the largest moment to z (C¯21=S¯21=0) or, with "principal", rotates it into its principal axes of inertia (C¯21=S¯21=S¯22=0) (Frames of a gravity field).

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    cs = sbtk.gravity.center_of_mass_frame(truth, body, "shape");
cz = sbtk.gravity.center_of_mass_frame(truth, body, "spin");
cp = sbtk.gravity.center_of_mass_frame(truth, body, "principal");
disp(table(cs.labels(1:8)', cs.coef(1:8)', cz.coef(1:8)', cp.coef(1:8)', 'VariableNames', ...
           ["coefficient" "shape axes" "spin axes" "principal axes"]))
fprintf("axis of the largest moment %.2f deg from the shape-model z-axis\n", acosd(cp.principal(3, 3)))
mo = sbtk.gravity.center_of_mass_frame(obs, body, "principal");      % a measurement set: with its covariance
fprintf("C22 in principal axes %.4e +- %.1e\n", mo.coef(mo.labels == "C22"), mo.sigma(mo.labels == "C22"))

    A body and its true model in another frame#

    sbtk.body.to_frame and sbtk.interior.to_frame carry the shape model and the true model into the spin axes; the density grid is then on cells of that frame (Frames of a gravity field).

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    spin = sbtk.gravity.center_of_mass_frame(truth, body, "spin");
body_s  = sbtk.body.to_frame(body, [0 0 0], spin.axes, "didymos_v003_spin_axes");
truth_s = sbtk.interior.to_frame(truth, [0 0 0], spin.axes);
fprintf("center of mass %s km in the shape-model frame, %s km in the spin axes\n", mat2str(truth.com_km, 4), ...
        mat2str(truth_s.com_km, 4))
grid_s = sbtk.exchange.density_grid(body_s, truth_s, 0.040);
fprintf("%d cells of 40 m in the spin axes\n", numel(grid_s.density_kgm3))

    Density at points and on a grid#

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    geo = sbtk.gravity.geometry(body, truth.origin_km, 0);               % geometry in the model's frame
x = linspace(-0.3, 0.3, 61)';
rho = sbtk.interior.density_at(truth, truth.origin_km + [x, 0*x, 0*x], geo);
plot(1e3*x, rho); xlabel("x from the center of mass [m]"); ylabel("density [kg/m^3]");

grid = sbtk.exchange.density_grid(body, truth, 0.040);              % 40 m cells
fprintf("%d cells, mean density %.0f kg/m^3\n", numel(grid.density_kgm3), mean(grid.density_kgm3))

    Uncertainties from another data set#

    sbtk.data.use_uncertainties gives simulated coefficients the covariance of a reference data set, converted to the target reference radius. Here the reference has Rref=0.40 km.

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    L = 4;
[C, S] = deal(zeros(L + 1));  C(1, 1) = 1;
sig = 5e-5*ones(L + 1);
reference = sbtk.data.from_coefficients(sbtk.body.from_mass("Didymos", body.shape, body.mass_kg, 0.40), ...
                                        "precision", [0 0 0], C, S, sig, sig);
noisy = sbtk.data.add_noise(sbtk.data.use_uncertainties(exact, reference), 2);
fprintf("1-sigma of C20: %.3e (reference %.1e at 0.40 km)\n", sqrt(noisy.coef_cov(4, 4)), 5e-5)

    Inertia measurements#

    sbtk.data.select_moi chooses the inertia rows of a data set; opts.moi_labels the rows a fit uses. sbtk.data.libration_ratio_from_amplitude converts a libration amplitude into a libration ratio.

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    gravity_only = sbtk.data.select_moi(obs, {});
with_izz = sbtk.data.add_moi(gravity_only, "Izz", exact.moi(3).value, 2e-3);
with_lib = sbtk.data.add_libration(gravity_only, exact.libration_ratio, 0.001, exact.moi(3).value);
[k, sk] = sbtk.data.libration_ratio_from_amplitude(-12, 0.2, 0.027, 0.001)   % G [deg], its sigma, e, its sigma

f0 = sbtk.invert.solve(body, components, gravity_only, sbtk.invert.options(moi_labels={}));
f1 = sbtk.invert.solve(body, components, with_izz, sbtk.invert.options(moi_labels={'Izz'}));
f2 = sbtk.invert.solve(body, components, with_lib, sbtk.invert.options(moi_labels={'libration'}));
fprintf("regolith density 1-sigma: gravity only %.0f, with Izz %.0f, with the libration ratio %.0f kg/m^3\n", ...
        f0.rho_sigma_kgm3(2), f1.rho_sigma_kgm3(2), f2.rho_sigma_kgm3(2))

    Measured center of mass#

    A gravity field about the center of mass has no degree-1 terms; sbtk.data.add_center_of_mass adds the measured position, after which the inversion expands about the model's own center of mass (Density estimation).

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    field = sbtk.data.select_coefficients(obs, setdiff(obs.coef_labels, {'C10', 'C11', 'S11'}, "stable"));
field = sbtk.data.add_center_of_mass(field, obs.origin_km + [0.0005 0 0], 0.002);   % measured 0.5 m off
fit = sbtk.invert.solve(body, components, field);
fprintf("frame iterations %d, model center of mass - origin: [%.2f %.2f %.2f] m\n", fit.frame_iterations, 1e3*fit.com_shift_km)

    Reading a SHADR-layout gravity file#

    The example writes a small file in the PDS SHADR layout and reads it back. The coefficients are about the shape-model origin, so the file includes degree-1 terms and origin_km = [0 0 0].

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    geo0 = sbtk.gravity.geometry(body, [0 0 0], 2);
fm = sbtk.gravity.forward(geo0, sbtk.interior.create(components), body.mass_kg);
lab = sbtk.gravity.labels(2);
coef = @(name) fm.coef(strcmp(lab, name));
file = [tempname '.tab'];
rows = sprintf("%.4f, %.6e, 0, 2, 2, 1, 0, 0", body.R_ref_km, body.GM_km3_s2);   % R, GM, sigma GM, degree, order, normalized
rows(2) = sprintf("1, 0, %.10e, 0, 1e-5, 1e-5", coef("C10"));
rows(3) = sprintf("1, 1, %.10e, %.10e, 1e-5, 1e-5", coef("C11"), coef("S11"));
rows(4) = sprintf("2, 0, %.10e, 0, 1e-5, 1e-5", coef("C20"));
rows(5) = sprintf("2, 1, %.10e, %.10e, 1e-5, 1e-5", coef("C21"), coef("S21"));
rows(6) = sprintf("2, 2, %.10e, %.10e, 1e-5, 1e-5", coef("C22"), coef("S22"));
writelines(rows, file);
[shadr, shadr_body] = sbtk.exchange.read_shadr(file, "Didymos", body.shape, [0 0 0], 2);
sbtk.data.summary(shadr)

    Packages for another team#

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    folder = tempname;
data  = sbtk.exchange.write_data(folder, "TEAM-DATA1-Didymos", body, obs, "Team name");
model = sbtk.exchange.write_model(folder, "TEAM-MOD1-Didymos", "TEAM-DATA1-Didymos", body, truth, exact, 0.040, "Team name");
[obs2, body2] = sbtk.exchange.read_data(data);                       % what the other team reads
prob = sbtk.invert.setup(body2, components, obs2, sbtk.invert.options());
solution = sbtk.exchange.write_solution(folder, sbtk.exchange.solution_name("OTHER", obs2.name), body2, ...
                                        sbtk.invert.run(prob), sbtk.invert.homogeneous(prob), 0.040, "Other team");
cmp = sbtk.compare.grids(sbtk.exchange.read_grid(fullfile(model, "density_grid.txt")), ...
                         sbtk.exchange.read_grid(fullfile(solution, "density_grid.txt")));
sbtk.compare.grid_summary(cmp);

    Many fits against one true model#

    sbtk.compare.reference samples the true model once; sbtk.compare.evaluate then compares each fit in milliseconds. sbtk.invert.replace_data reuses the setup for each noise realization.

    MATLAB fragment. Requires the variables defined in Body, interior and measurements used by the examples on this page.
    prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
ref = sbtk.compare.reference(body, truth, components, prob.geo.origin_km);
R2 = zeros(1, 20);
for k = 1:20
    fit = sbtk.invert.run(sbtk.invert.replace_data(prob, sbtk.data.add_noise(exact, 10 + k)));
    R2(k) = sbtk.compare.evaluate(ref, fit).R2;
end
fprintf("R2 over 20 noise realizations: %.2f +- %.2f\n", mean(R2), std(R2))
