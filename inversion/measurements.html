    Measurement sets#

    Last edited October 19, 2026

    A measurement set (obs) holds fully normalized gravity coefficients with their covariance, moment-of-inertia measurement rows, the total mass, the reference radius and the expansion origin.

    Sources#

    Source Function Notes
    A simulated interior sbtk.data.simulate Exact values about the true center of mass, without uncertainties (they are NaN until set, below); coef_about = 'origin'.
    An SBTK measurement package sbtk.exchange.read_data Coefficients about the measured center of mass with their full covariance; returns the body as well (Exchange packages).
    A gravity file in the PDS SHADR layout sbtk.exchange.read_shadr Header row (R, GM, σGM, degree, order, normalization state, …) then rows l, m, C, S, sigma_C, sigma_S; diagonal covariance. The caller gives the shape model and the point the coefficients are about.
    A JPL SSD gravity file sbtk.io.read_jpl_gravity MATLAB-assignment form with NAMES, VALS, COV; parsed as text; full covariance; Jl converted to C¯l0.
    Coefficient matrices sbtk.data.from_coefficients C(l+1, m+1), S(l+1, m+1) and their 1σ; diagonal covariance.
    The SBTK text format sbtk.io.read_measurements, sbtk.io.load_measurements One keyword per line; diagonal covariance only (Results folders).

    Uncertainties and covariance#

    • Exact values have none. sbtk.data.simulate returns the true model's exact values without uncertainties: coef_cov and every inertia σ are NaN. Measurements need them: sbtk.data.add_noise, sbtk.invert.setup and sbtk.exchange.write_data stop with sbtk:data:noUncertainties otherwise.
    • By degree. sbtk.data.set_uncertainties(obs, unc) gives every coefficient of degree l the 1σ of sbtk.data.uncertainties for that degree (a diagonal covariance), every inertia element its 1σ (as a fraction of MRref2), and the libration row the 1σ of the ratio times Izz/(MRref2).
    • From another data set. sbtk.data.use_uncertainties gives every coefficient that a reference data set also contains the reference's variances and covariances, converted to the reference radius of the target by (R/R′)l. Coefficients the reference lacks keep their variances and become uncorrelated with the others.
    • Full covariance. sbtk.data.set_covariance replaces the coefficient covariance with any symmetric positive definite matrix in the order of obs.coef_labels.
    • Inertia rows. sbtk.data.set_moi_sigma sets the σ of named rows; the field libration gives the 1σ of the ratio.

    Noise#

    sbtk.data.add_noise(obs, seed) returns one realization: the coefficients plus L𝐳, with L the lower Cholesky factor of the coefficient covariance and 𝐳 standard normal; each inertia row plus its σ times a standard normal variable. The same seed gives the same noise; obs.noise_seed records it.

    Inertia measurements and the center of mass#

    Function Adds
    sbtk.data.add_moi One element Ixx … Iyz as I/(MRref2) (sbtk.units.moi_to_norm converts from kg m²).
    sbtk.data.add_moi_row Any linear combination of the six elements.
    sbtk.data.add_libration The libration ratio (B−A)/C as a linear row (Moments of inertia). Requires C¯22 and S¯22.
    sbtk.data.libration_ratio_from_amplitude Computes the ratio and its 1σ from a forced libration amplitude.
    sbtk.data.add_center_of_mass The measured center of mass as degree-1 coefficients; sets coef_about to 'center_of_mass'.

    Selecting measurements#

    sbtk.data.select_degree keeps the coefficients up to a degree, sbtk.data.select_coefficients a list of coefficients, and sbtk.data.select_moi a list of inertia rows; the covariance keeps the matching rows and columns. sbtk.data.move_origin changes the expansion origin of data about the center of mass. sbtk.data.summary prints the contents of a measurement set.

    Example#

    MATLAB script: Measurements from coefficient matrices
    run("/path/to/SBTK/sbtk_setup.m")
body = sbtk.body.from_mass("Dimorphos", sbtk.shape.bundled("dimorphos"), 2.700e9, 0.10);

% coefficient matrices, C(l+1, m+1) = C_lm, fully normalized, about the shape-model origin
L = 2;
C = zeros(L + 1);  S = zeros(L + 1);
C(1,1) = 1;  C(3,1) = -0.08;  C(3,3) = 0.03;  S(3,3) = 0.002;     % C00, C20, C22, S22
Cs = 1e-3*ones(L + 1);  Ss = 1e-3*ones(L + 1);                     % 1-sigma of each
obs = sbtk.data.from_coefficients(body, "example", [0 0 0], C, S, Cs, Ss);

% a polar moment given in kg m^2, and a libration ratio
Izz = sbtk.units.moi_to_norm(1.6e14, body.mass_kg, body.R_ref_km);
obs = sbtk.data.add_moi(obs, "Izz", Izz, 0.01*Izz);
obs = sbtk.data.add_libration(obs, 0.20, 0.03, Izz);

% 30% correlation between all coefficients
sig = sqrt(diag(obs.coef_cov));
obs = sbtk.data.set_covariance(obs, (0.3 + 0.7*eye(numel(sig))).*(sig*sig'));
sbtk.data.summary(obs)

    Calculations has further examples: simulated data with uncertainties from another data set, selection of inertia rows, and reading files.
