    Error identifiers

    SBTK raises an error instead of substituting a value when an input is invalid or a computation cannot proceed. Every error has an identifier sbtk:<package>:<condition>, usable with verifyError in tests. The messages below are the fixed parts of the message text; values inserted at run time appear as format specifiers (%s, %d, %g).

    IdentifierRaised byMessage
    sbtk:compare:differentComponentssbtk.compare.evaluateThe fit's components differ from the reference's or origin (e.g. a sphere position was estimated): use sbtk.compare.with_truth.
    sbtk:compare:gridSpacingsbtk.compare.gridsThe grids have different spacings (%g and %g km).
    sbtk:data:axisymmetricsbtk.internal.libration_weightsIyy - Ixx = Ixy = 0 (C22 = S22 = 0): the body has no preferred equatorial axis, so (B - A)/C is not defined.
    sbtk:data:coefLabelsbtk.data.select_coefficientsThe data have no coefficient %s.
    sbtk:data:coefSizesbtk.data.from_coefficientsC, S, C_sigma and S_sigma must all be (L+1) x (L+1) with L >= 1.
    sbtk:data:covPositivesbtk.data.set_covarianceThe covariance must be positive definite.
    sbtk:data:covSizesbtk.data.set_covarianceCovariance is %d x %d; the data have %d coefficients.
    sbtk:data:covSymmetricsbtk.data.set_covarianceThe covariance must be symmetric.
    sbtk:data:degreeOnesbtk.data.add_center_of_massThe data already have degree-1 coefficients.
    sbtk:data:duplicateMoisbtk.data.add_moi_rowThe data already have a moment-of-inertia row named %s.
    sbtk:data:moiLabelsbtk.data.select_moiThe data have no moment-of-inertia measurement %s.
    sbtk:data:moiLabelsbtk.data.set_moi_sigmaThe data have no moment-of-inertia measurement %s.
    sbtk:data:moveOriginsbtk.data.move_originOnly measurements about the center of mass can move their origin; these are about obs.origin_km.
    sbtk:data:negativeDensitysbtk.data.simulateThe interior has negative density (minimum %.0f kg/m^3): make the light components less light.
    sbtk:data:noC22sbtk.data.add_librationThe libration ratio needs the measured C22 and S22 (they give the direction of the principal axes).
    sbtk:data:noCommonCoefficientssbtk.data.use_uncertaintiesThe two data sets have no gravity coefficient in common.
    sbtk:data:uncertaintiessbtk.data.simulateunc.coef_sigma_by_degree has %d values; degree %d needs one per degree.
    sbtk:data:zeroSigmasbtk.data.from_coefficientsUncertainty of %s is zero; every used coefficient needs sigma > 0.
    sbtk:exchange:correlatedCenterOfMasssbtk.internal.exchange_data_filesThe center of mass is correlated with the other coefficients; the exchange format gives them separately.
    sbtk:exchange:covariancesbtk.exchange.read_datagravity_covariance.txt has no row for %s.
    sbtk:exchange:dataSetNamesbtk.exchange.solution_nameData set %s is not named <team>-DATA<number>.
    sbtk:exchange:locatesbtk.exchange.locateFound %d %s packages in %s (and its redacted/, unredacted/); expected one.
    sbtk:exchange:missingKeysbtk.internal.exchange_numberThe file has no "# %s:" line.
    sbtk:exchange:moiRowsbtk.internal.exchange_data_filesMoment-of-inertia row %s has no exchange-format equivalent.
    sbtk:exchange:noCenterOfMasssbtk.internal.exchange_data_filesThe data need the degree-1 coefficients (the measured center of mass): add them with sbtk.data.add_center_of_mass.
    sbtk:exchange:normalizationsbtk.exchange.read_shadrThe header of %s gives normalization state %g; SBTK needs 1 (fully normalized).
    sbtk:exchange:shapeFilesbtk.internal.exchange_data_filesThe package needs the shape-model file; this shape came from "%s". Write it with sbtk.shape.write_obj and load it with sbtk.shape.load.
    sbtk:gravity:notStarShapedsbtk.gravity.geometry%d facets face the expansion origin: the shape is not star-shaped about [%g %g %g] km.
    sbtk:interior:duplicateNamesbtk.interior.createComponent names must be unique (they label the results): %s
    sbtk:interior:sectorCountsbtk.interior.sector_gridUse 1 to 9 bands in each direction (got %d, %d, %d).
    sbtk:interior:sectorRangesbtk.interior.sectorSector %s: each range must increase (frac %s, lat %s, lon %s) and span at most 360 deg of longitude.
    sbtk:invert:coefLabelsbtk.invert.setupCoefficient %s is above obs.degree = %d.
    sbtk:invert:differentDatasbtk.invert.replace_dataThe new data differ in labels, origin, degree, mass or inertia weights: run sbtk.invert.setup instead.
    sbtk:invert:duplicateNamesbtk.invert.setupComponent names must be unique: %s
    sbtk:invert:infeasiblesbtk.invert.runPrescribed densities violate the density bounds.
    sbtk:invert:moiLabelsbtk.invert.setupopts.moi_labels asks for %s; the data have: %s.
    sbtk:invert:noCenterOfMasssbtk.invert.setupCoefficients about the center of mass need its measured position as degree-1 coefficients (sbtk.data.add_center_of_mass).
    sbtk:invert:outsideBodysbtk.invert.setupComponent %s lies entirely outside the body.
    sbtk:invert:solversbtk.invert.runThe bounded least-squares solution did not converge (lsqlin exit flag %d).
    sbtk:io:degreesbtk.io.read_jpl_gravityThe file has coefficients up to degree %d only.
    sbtk:io:jplFormatsbtk.io.read_jpl_gravityNAMES, VALS and COV sizes do not agree in %s.
    sbtk:io:jplFormatsbtk.io.read_jpl_gravityCoefficient %s is missing from %s.
    sbtk:io:jplFormatsbtk.io.read_jpl_gravityKeyword %s not found.
    sbtk:io:jplFormatsbtk.io.read_jpl_gravityBlock %s not found.
    sbtk:io:noRunsbtk.io.latest_runNo run named %s in results/%s.
    sbtk:io:notNormalizedsbtk.io.read_jpl_gravityThe coefficients in %s are not normalized.
    sbtk:io:referenceRadiussbtk.io.read_jpl_gravityThe file's reference radius is %g km; body.R_ref_km is %g km.
    sbtk:shape:notDownloadedsbtk.shape.bundled%s is not in data/shapes/: the high-resolution models are not in git; copy it from the Hera server (End-to-End Test/Shape/).
    sbtk:shape:notSpcsbtk.shape.reduce_spc%d vertices and %d facets: not an SPC grid model (6 (q+1)^2 vertices, 12 q^2 facets).
    sbtk:shape:reducesbtk.shape.reduceThe reduced shape (%d facets) is closed %d, outward %d, star-shaped %d: try another number of facets.
    sbtk:shape:spcReducesbtk.shape.reduce_spcThe reduced grid (%d vertices) is closed %d, outward %d, star-shaped %d: the vertices are not in SPC grid order.
    sbtk:shape:spcStepsbtk.shape.reduce_spcstep %d does not divide the grid size q = %d.
