    sbtk.invert.choose_regularization#

    Tikhonov regularization parameter by the discrepancy principle.

    Syntax

    MATLAB
    lambda = sbtk.invert.choose_regularization(prob)
prob.opts.regularization = lambda;  fit = sbtk.invert.run(prob);

    Arguments

    NameSizeClassUnitDefaultDescription
    prob1 × 1structrequiredPrepared inversion; prob.opts.regularization is not used. Fields: prob.

    Outputs

    NameDescription
    lambdaTikhonov parameter chosen by the discrepancy principle.

    Description

    The regularization term lambda * sum((drho_c / rho_mean)^2) damps the relative densities. Models with many components (a sector grid) or weak data need it to keep noise from producing large alternating densities. This returns the largest lambda for which chi^2 <= max(n, chi^2_min + sqrt(2n)), n measurements, chi^2_min the unregularized value: chi^2 may rise by about one standard deviation of its distribution. Bisection on log10(lambda) over [-2, 8] (9 solves, about 0.2 s with prob reused).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, obs.
    sectors = sbtk.interior.sector_grid([0 0.5 1], [-90 0 90], [-180 0 180]);
prob = sbtk.invert.setup(body, sectors, obs, sbtk.invert.options(background="bulk"));
prob.opts.regularization = sbtk.invert.choose_regularization(prob);
fit = sbtk.invert.run(prob);

    sbtk.invert.goodness_of_fit#

    Reduced chi-square and chi-square test of a fit.

    Syntax

    MATLAB
    [chi2_reduced, p_value, consistent] = sbtk.invert.goodness_of_fit(chi2, dof)

    Arguments

    NameSizeClassUnitDefaultDescription
    chi2scalardoublerequiredsum of squared normalized residuals (with the full covariance) Validation: mustBeNonnegative.
    dofscalardoublerequireddegrees of freedom: number of measurements minus the effective number of estimated parameters Validation: mustBeFinite.

    Outputs

    NameDescription
    chi2_reducedchi2/dof; about 1 when the model and the stated uncertainties are right
    p_valueprobability that a correct model gives a chi2 at least this large
    consistentp_value >= 0.05: the model is consistent with the measurements at the 5% significance level

    Description

    With dof <= 0 (at least as many parameters as measurements) the test is undefined: chi2_reduced and p_value are NaN and consistent is false.

    Example

    MATLAB, from the help text
    [chi2_reduced, p, consistent] = sbtk.invert.goodness_of_fit(30.2, 24);   % 1.26, 0.18, true

    Related functions

    Called by
    sbtk.invert.run

    Implementation: toolbox/+sbtk/+invert/goodness_of_fit.m, line 1.

    sbtk.invert.homogeneous#

    Fit a homogeneous body (no components) to the same measurements.

    Syntax

    MATLAB
    fit = sbtk.invert.homogeneous(prob)

    Arguments

    NameSizeClassUnitDefaultDescription
    prob1 × 1structrequiredPrepared inversion; its components are ignored. Fields: prob.

    Outputs

    NameDescription
    fitFit of a homogeneous body: the bulk density everywhere, no free parameters. Fields: fit.

    Description

    The density is the bulk density everywhere (fixed by the mass), so there are no free parameters. If this fit is already consistent with the measurements (fit.consistent), the data do not require internal structure.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs.
    prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
h = sbtk.invert.homogeneous(prob);
fprintf('homogeneous body: reduced chi2 %.2f, p = %.2g\n', h.chi2_reduced, h.p_value);

    Related functions

    Mentioned in the help text
    sbtk.invert.options, sbtk.invert.setup
    Calls
    sbtk.invert.run

    Implementation: toolbox/+sbtk/+invert/homogeneous.m, line 1.

    sbtk.invert.options#

    Inversion settings with their standard values.

    Syntax

    MATLAB
    opts = sbtk.invert.options()                     % the standard values
opts = sbtk.invert.options(Name=Value, ...)      % with some of them changed

    Arguments

    NameSizeClassUnitDefaultDescription
    moi_labels{'Ixx', 'Iyy', 'Izz'}Name-value argument; moment-of-inertia measurements to fit, e.g. {'Ixx','Iyy','Izz'}, {'libration'}, or {} (gravity only) Validation: mustBeText.
    regularizationscalardouble0Name-value argument; Tikhonov parameter lambda (0 = none). The penalty is lambda * sum((drho_c / rho_mean)^2) in units of chi^2. Use sbtk.invert.choose_regularization for many components. Validation: mustBeNonnegative.
    background1 × 1string"estimate"Name-value argument; "estimate": the background density is estimated (with the mass constraint); "bulk": it is held at the mean density M/V, so the relative densities of the components conserve the mass by themselves Validation: mustBeMember(settings.background, ["estimate", "bulk"]).
    rho_max_kgm3scalardoublekg/m³4500Name-value argument; upper bound on any component's density [kg/m^3] Validation: mustBePositive.
    max_iterscalardouble20Name-value argument; Gauss-Newton iterations for the geometry of components with estimate_position or estimate_axis Validation: mustBeInteger, mustBeNonnegative.
    step_kmscalardoublekm0.010Name-value argument; trust-region radius of a step of a center coordinate [km] Validation: mustBePositive.
    position_sigma_kmscalardoublekmInfName-value argument; a priori 1-sigma of each estimated center coordinate about its Validation: mustBePositive.
    step_degscalardoubledeg1Name-value argument; trust-region radius of a step of an axis tilt or turn [deg] Validation: mustBePositive.
    axis_sigma_degscalardoubledegInfName-value argument; a priori 1-sigma of each estimated axis tilt and turn about the starting orientation [deg]; Inf = no constraint Validation: mustBePositive.
    max_shift_kmscalardoublekmInfName-value argument; largest distance of an estimated center from its starting point [km]; Inf = no limit (a sphere is kept inside the body in any case) Validation: mustBePositive.
    max_tilt_degscalardoubledegInfName-value argument; largest angle of an estimated axis from its starting direction [deg]; Inf = no limit Validation: mustBePositive.
    geometry_tolscalardouble1e-3Name-value argument; the geometry has converged when an accepted step changes every geometry parameter by less than this fraction of its step limit Validation: mustBeNonnegative.
    max_turn_degscalardoubledegInfName-value argument; largest turn of an estimated ellipsoid about its axis from its starting orientation [deg]; Inf = no limit Validation: mustBePositive.

    Outputs

    NameDescription
    optsThe settings. Fields: opts.

    Description

    starting point [km]; Inf = no constraint. Needed when more
    geometry is estimated than the measurements determine.

    Standard values: moi_labels {'Ixx','Iyy','Izz'}, regularization 0, background "estimate", rho_max_kgm3 4500, max_iter 20, step_km 0.010, step_deg 1, position_sigma_km Inf, axis_sigma_deg Inf, max_shift_km Inf, max_tilt_deg Inf, max_turn_deg Inf, geometry_tol 1e-3. The fields can also be changed afterwards (opts.regularization = 10).

    Example

    MATLAB, from the help text

    sbtk.invert.replace_data#

    Use another realization of the same measurements without repeating the setup.

    Syntax

    MATLAB
    prob = sbtk.invert.replace_data(prob, obs)

    Arguments

    NameSizeClassUnitDefaultDescription
    prob1 × 1structrequiredPrepared inversion. Fields: prob.
    obs1 × 1structrequiredAnother realization of the same measurements (same labels, inertia weights, origin, degree and mass). Fields: obs.

    Outputs

    NameDescription
    probThe inversion with the new measurement values and uncertainties; geometry and design matrix reused. Fields: prob.

    Description

    obs must have the same coefficient labels, moment-of-inertia rows (weights), origin, degree and mass as the data prob was set up with; only the values and uncertainties may differ (e.g. another noise seed). The geometry and design matrix are reused and a run takes milliseconds.

    Example

    100 noise realizations

    MATLAB fragment from the help text. Uses variables defined by earlier calls: prob, exact.
    for k = 1:100
    fit = sbtk.invert.run(sbtk.invert.replace_data(prob, sbtk.data.add_noise(exact, k)));
end

    sbtk.invert.run#

    Estimate the densities for a prepared inversion (bounded, mass-constrained least squares).

    Syntax

    MATLAB
    fit = sbtk.invert.run(prob)          % prob from sbtk.invert.setup

    Arguments

    NameSizeClassUnitDefaultDescription
    prob1 × 1structrequiredPrepared inversion from sbtk.invert.setup (or sbtk.invert.replace_data). Fields: prob.

    Outputs

    NameDescription
    fitInversion result. Fields: fit.

    Description

    Unknowns: the background density, the relative density of each component, and the geometry asked for: the center of spheres, ellipsoids and tori with estimate_position (all coordinates, or those of a mask [x y z]) and the axis of ellipsoids and tori with estimate_axis = true. The total mass is an equality constraint and every component's density is bounded to [0, opts.rho_max_kgm3]. Measurements are whitened by the Cholesky factor of their covariance and the columns scaled to unit norm; the problem is solved with lsqlin (active set, or interior point if the active set does not converge). The geometry is refined by Gauss-Newton (at most opts.max_iter steps) with a trust region (opts.step_km for center coordinates, opts.step_deg for axis tilts): a step that does not lower the objective is undone and the trust region halved; it has converged when the objective changes by less than 1e-10 relative or a step changes every parameter by less than opts.geometry_tol of its step limit. Optional a priori constraints keep the geometry near its start (opts.position_sigma_km, opts.axis_sigma_deg), hard limits bound how far it may go (opts.max_shift_km, opts.max_tilt_deg), and spheres are kept inside the body. The parameters are listed by sbtk.internal.geometry_parameters. Optional Tikhonov regularization (opts.regularization) penalizes the relative densities. The covariance is the linearized one with the mass constraint eliminated (inequality bounds are not included; see fit.at_bound).

    fit (a model: rho_bg_kgm3, components, random_field, origin_km, plus)

    rho_bg_kgm3, rho_bg_sigma_kgm3background density and its 1-sigma [kg/m^3]
    componentsthe components with the estimated relative densities drho_kgm3
    drho_sigma_kgm31-sigma of each relative density
    rho_kgm3, rho_sigma_kgm3density of each component (background + relative) and its 1-sigma
    center_sigma_kmn x 3 1-sigma of the center coordinates (NaN unless estimated)
    axis_sigma_degn x 3 1-sigma of the rotations about the component's first, second and third axes [deg]: the tilts of its axis and, for an ellipsoid, its turn about it (NaN unless estimated)
    at_bounddensity at 0 or rho_max
    resolved|relative density| > its 1-sigma
    determinedfalse if the measurements (with any prior or regularization) do not determine all free parameters; cov is then a pseudo-inverse and the solution is not unique
    chi2, n_obs, dofchi-square, number of measurements, degrees of freedom (n_obs minus the effective number of parameters, trace of the data resolution matrix)
    chi2_reduced, p_value chi2/dof and P(chi2 >= observed) for a correct model
    consistentp_value >= 0.05 (model consistent with the measurements)
    labels, measured, predicted, sigma, normalized_residual
    every measurement, its predicted value, (predicted - measured)/sigma
    names, cov, corrparameters, their covariance and correlation
    iterations, regularization, moi_labels, background, body, data_name
    coef_about'origin' or 'center_of_mass' (from the measurements)
    com_shift_kmmodel's center of mass minus origin_km: the point the predicted coefficients of degree >= 2 and inertia are about ([0 0 0] for 'origin')
    frame_iterationsGauss-Newton steps on the model's center of mass (0 for 'origin')
    frame_offset_kmchange of that center in the last step (below 1e-6 km when converged)

    When obs.coef_about is 'center_of_mass' (packages read with sbtk.exchange.read_data, fields from sbtk.data.add_center_of_mass), the predicted coefficients of degree >= 2 and inertia are moved to the fitted model's own center of mass (exact translation), and the fit repeated until that center moves less than 1 mm. The model itself stays fixed: origin_km is the measured center of mass, from which layers and sectors are measured.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs.
    prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
fit  = sbtk.invert.run(prob);
sbtk.invert.summary(fit)

    sbtk.invert.setup#

    Prepare an inversion: geometry and the design-matrix column of every component, computed once.

    Syntax

    MATLAB
    prob = sbtk.invert.setup(body, components, obs, opts)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredfrom sbtk.body.create (shape; the mass used is obs.mass_kg) Fields: body.
    components1 × anystructrequiredthe model's components (sbtk.interior constructors). Their geometry is fixed except for the center of spheres, ellipsoids and tori with estimate_position (true, or a mask [x y z]) and the axis of ellipsoids and tori with estimate_axis = true (sbtk.invert.run). Their drho_kgm3 is estimated (the value given is not used), except for components with estimate_density = false, whose value is kept. Fields: component.
    obs1 × 1structrequiredthe measurements (sbtk.data.simulate, sbtk.io.load_measurements, ...) Fields: obs.
    opts1 × 1structrequiredfrom sbtk.invert.options Fields: opts.

    Outputs

    NameDescription
    probeverything sbtk.invert.run needs. Further runs with other options (prob.opts.regularization = ...), sbtk.invert.homogeneous and sbtk.invert.replace_data reuse it (Didymos, three components: setup 0.7 s, each run about 0.2 s; tools/benchmark.m). Fields: prob.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs.
    prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
fit  = sbtk.invert.run(prob);                      % about 0.2 s
prob.opts.regularization = 5;                      % settings that do not select measurements
fit5 = sbtk.invert.run(prob);                      % can change between runs

    sbtk.invert.solve#

    Setup and run in one call.

    Syntax

    MATLAB
    fit = sbtk.invert.solve(body, components, obs)          % standard options
fit = sbtk.invert.solve(body, components, obs, opts)    % opts from sbtk.invert.options

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body (shape model; the mass used is obs.mass_kg). Fields: body.
    components1 × anystructrequiredThe model's components; their geometry is fixed and their relative densities are estimated (the values given are not used) unless estimate_density is false. Fields: component.
    obs1 × 1structrequiredThe measurement set. Fields: obs.
    opts1 × 1structsbtk.invert.options()Settings from sbtk.invert.options. Fields: opts.

    Outputs

    NameDescription
    fitInversion result. Fields: fit.

    Description

    Same as sbtk.invert.run(sbtk.invert.setup(body, components, obs, opts)). Use setup + run when solving the same problem more than once (other options, sbtk.invert.homogeneous, other noise realizations).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs.
    fit = sbtk.invert.solve(body, components, obs);
fit = sbtk.invert.solve(body, components, obs, sbtk.invert.options(moi_labels={'Izz'}));
sbtk.invert.summary(fit)
