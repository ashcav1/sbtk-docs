    sbtk.shape.bundled#

    A shape model that ships with SBTK, by short name.

    Syntax

    MATLAB
    shape = sbtk.shape.bundled(name)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredfile in data/shapes/ (all in km) Validation: mustBeMember(name, ["didymos", "dimorphos", "didymos_highres", "dimorphos_highres", "didymos_every8", "dimorphos_placeholder", "bennu", "example_asteroid"]).

    Outputs

    NameDescription
    shapeThe shape model, lengths in km. Fields: shape.

    Description

    "didymos"didymos_g_9309mm_spc_obj_0000n00000_v003.obj: DART SPC model v003 at 9.3 m sampling (49,152 facets), the version the Hera radio-science team and the HLP6-G test use
    "dimorphos"g_00243mm_spc_obj_dimo_0000n00000_v004_every8.obj: DART SPC model v004 (pre-impact) at 1.94 m sampling (49,152 facets), every 8th point of the high-resolution grid (sbtk.shape.reduce_spc)
    "didymos_highres"g_01165mm_spc_obj_didy_0000n00000_v003.obj: 1.165 m, 3,145,728 facets
    "dimorphos_highres"g_00243mm_spc_obj_dimo_0000n00000_v004.obj: 0.243 m, 3,145,728 facets
    "didymos_every8"g_01165mm_spc_obj_didy_0000n00000_v003_every8.obj: every 8th point of "didymos_highres" (49,152 facets)
    "dimorphos_placeholder"a placeholder shape (not a mission model; kept for the tests)
    "bennu"OSIRIS-REx shape model (bennu_higher_qual)
    "example_asteroid"a synthetic 1.2 km body (projects/template)

    The two high-resolution files (about 160 MB each) are not in git: copy them from the Hera server (End-to-End Test/Shape/) or ESA's SPICE server (spiftp.esac.esa.int/data/SPICE/HERA/kernels/dsk/) into data/shapes/. See data/shapes/README.md for every file. For any other shape model use sbtk.shape.load(file, unit).

    Example

    MATLAB, from the help text
    body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);
big  = sbtk.shape.bundled("dimorphos_highres");                % 3 s to read

    Mentioned in the help text

    sbtk.shape.ellipsoid#

    Triaxial ellipsoid shape model (an icosphere stretched to the semi-axes).

    Syntax

    MATLAB
    shape = sbtk.shape.ellipsoid(name, semi_axes_km, level)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the shape.
    semi_axes_km1 × 3doublekmrequired[a b c] along x, y, z [km] Validation: mustBePositive.
    levelscalardoublerequiredicosphere refinement: 20*4^level facets (5 -> 20,480) Validation: mustBeInteger, mustBeNonnegative.

    Outputs

    NameDescription
    shapeTriaxial ellipsoid with 20·4^level facets, vertices on the ellipsoid. Fields: shape.

    Description

    Vertices lie exactly on the ellipsoid. Useful for tests and stand-ins.

    Example

    MATLAB, from the help text
    shape = sbtk.shape.ellipsoid("test", [0.40 0.35 0.30], 4);          % 5,120 facets

    Implementation: toolbox/+sbtk/+shape/ellipsoid.m, line 1.

    sbtk.shape.from_arrays#

    Shape model from face and vertex arrays.

    Syntax

    MATLAB
    shape = sbtk.shape.from_arrays(name, faces, vertices, unit)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the shape.
    facesany × 3doublerequirednf x 3 vertex indices (1-based), triangles Validation: mustBeInteger, mustBePositive.
    verticesany × 3doublerequirednv x 3 positions in UNIT ("km", "m" or "cm") Validation: mustBeFinite.
    unit1 × 1stringrequiredLength unit of the vertices: "km", "m" or "cm". Validation: mustBeMember(unit, ["km", "m", "cm"]).

    Outputs

    NameDescription
    shapeThe shape model, vertices converted to km. Fields: shape.

    Description

    Returns the same struct as sbtk.shape.load.

    sbtk.shape.load#

    Read a polyhedral shape model (Wavefront OBJ) and convert it to km.

    MATLAB

    Arguments

    NameSizeClassUnitDefaultDescription
    file1 × 1stringrequiredpath to an .obj file with 'v x y z' and 'f i j k' records (normals, textures and 'f i/t/n' forms are accepted) Validation: mustBeFile.
    unit1 × 1stringrequiredlength unit of the file: "km", "m" or "cm" (required: there is no safe way to guess it) Validation: mustBeMember(unit, ["km", "m", "cm"]).

    sbtk.shape.properties#

    Volume, centroid and closure checks of a shape model.

    Syntax

    MATLAB
    props = sbtk.shape.properties(shape)

    Arguments

    NameSizeClassUnitDefaultDescription
    shape1 × 1structrequiredThe shape model to check. Fields: shape.

    Outputs

    NameDescription
    propsVolume, centroid and checks. Fields: props.

    Description

    props.volume_km3enclosed volume [km^3]
    props.centroid_kmcenter of figure [km]

    props.n_facets, .n_vertices

    props.extent_km[min; max] of the vertices per axis [km]
    props.closedtrue if every edge is shared by exactly two facets, in opposite directions (a closed, consistently ordered surface)
    props.outwardtrue if the facets are ordered outward
    props.star_shaped_about_centroidtrue if every facet faces away from the
    centroid (required to integrate about it)

    Example

    MATLAB, from the help text
    p = sbtk.shape.properties(sbtk.shape.bundled("didymos"));
fprintf('volume %.4f km^3, star-shaped: %d\n', p.volume_km3, p.star_shaped_about_centroid);

    sbtk.shape.reduce#

    A shape model with fewer facets, checked to stay closed, outward and star-shaped.

    Syntax

    MATLAB
    small = sbtk.shape.reduce(shape, n_facets)

    Arguments

    NameSizeClassUnitDefaultDescription
    shape1 × 1structrequiredfrom sbtk.shape.load (e.g. a high-resolution SPC model with millions of facets) Fields: shape.
    n_facetsscalardoublerequiredtarget number of facets Validation: mustBeInteger, mustBePositive.

    Outputs

    NameDescription
    smallThe reduced shape model. Fields: shape.

    Description

    Uses MATLAB's reducepatch. Gravity coefficients to degree 4 or so need far fewer facets than a high-resolution shape model has; check what the reduction changes by comparing sbtk.shape.properties (volume, centroid) and the homogeneous-body coefficients of both (tools/make_reduced_shapes.m does both). Errors if the reduced surface is not closed, not ordered outward, or not star-shaped about its centroid. Save it with sbtk.shape.write_obj.

    Example

    MATLAB, from the help text
    big   = sbtk.shape.load("g_00243mm_spc_obj_dimo_0000n00000_v004.obj", "km");
small = sbtk.shape.reduce(big, 50000);
sbtk.shape.write_obj(small, "dimorphos_v004_50k.obj");

    sbtk.shape.reduce_spc#

    Every step-th grid point of an SPC shape model: the same surface, sampled step times coarser.

    Syntax

    MATLAB
    small = sbtk.shape.reduce_spc(shape, step)

    Arguments

    NameSizeClassUnitDefaultDescription
    shape1 × 1structrequiredan SPC (stereophotoclinometry) shape model in its grid order, as in the DART g_<sampling>_spc_obj_<body>_... OBJ files: 6 cube faces of (q+1) x (q+1) vertices each, the first index fastest, 12 q^2 triangles Fields: shape.
    stepscalardoublerequireda divisor of q, e.g. 8 Validation: mustBeInteger, mustBePositive.

    Outputs

    NameDescription
    small12 (q/step)^2 facets and 6 (q/step)^2 + 2 vertices: the grid points (i, j) with i and j multiples of step, triangulated like the original (diagonal from (i, j) to (i+1, j+1)), the copies along the cube edges merged. A cell whose triangles would face the body's center (a steep slope seen almost edge on, e.g. 1 of 24,576 cells of Dimorphos v004 at step 8) is split along its other diagonal; no point moves. Fields: shape.

    Description

    The grid is radial (one surface point per direction from the body's center), so the result stays star-shaped about the center, unlike a general mesh reduction (sbtk.shape.reduce). Each cube face's triangles are ordered outward.

    Example

    MATLAB, from the help text
    big   = sbtk.shape.load("g_00243mm_spc_obj_dimo_0000n00000_v004.obj", "km");   % q = 512
small = sbtk.shape.reduce_spc(big, 8);                                         % q = 64, 49,152 facets
sbtk.shape.write_obj(small, "g_00243mm_spc_obj_dimo_0000n00000_v004_every8.obj");
