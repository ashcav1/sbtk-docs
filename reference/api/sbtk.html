    sbtk: Version and repository folder

    Last edited October 21, 2026

    FunctionPurpose
    rootFolder of the SBTK repository (the one containing toolbox/, examples/, data/).
    versionSBTK version string (semantic versioning).

    sbtk.root#

    Folder of the SBTK repository (the one containing toolbox/, examples/, data/).

    Syntax

    MATLAB
    r = sbtk.root()

    Outputs

    NameDescription
    rAbsolute path of the SBTK repository folder (the folder that contains toolbox/).

    Related functions

    Called by
    sbtk.exchange.read_data, sbtk.io.latest_run, sbtk.io.new_run, sbtk.shape.bundled

    Implementation: toolbox/+sbtk/root.m, line 1.

    sbtk.version#

    SBTK version string (semantic versioning).

    Syntax

    MATLAB
    v = sbtk.version()      % e.g. '1.0.0'

    Outputs

    NameDescription
    vVersion text, e.g. '1.0.0' (semantic versioning).

    Related functions

    Called by
    sbtk.io.save_settings, sbtk.io.write_truth

    Implementation: toolbox/+sbtk/version.m, line 1.
