    sbtk.body: Bodies

    Last edited October 29, 2026

    sbtk.body.create#

    A small body: shape model, bulk density and reference radius.

    Syntax

    MATLAB
    body = sbtk.body.create(name, shape, bulk_density_kgm3, R_ref_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequired
    shape1 × 1structrequiredfrom sbtk.shape.load / from_arrays / ellipsoid Fields: shape.
    bulk_density_kgm3scalardoublekg/m³requiredmean density [kg/m^3]; sets the total mass Validation: mustBePositive.
    R_ref_kmscalardoublekmrequiredreference radius of the gravity coefficients [km] Validation: mustBePositive.

    Outputs

    NameDescription
    bodystruct Fields: body.

    Description

    .volume_km3enclosed volume [km^3]
    .mass_kgbulk_density_kgm3 * volume [kg]
    .GM_km3_s2G * mass [km^3/s^2]
    .centroid_kmcenter of figure [km]

    Example

    MATLAB, from the help text
    shape = sbtk.shape.ellipsoid("test", [0.4 0.35 0.3], 4);
body  = sbtk.body.create("Test", shape, 2600, 0.4);

    sbtk.body.from_mass#

    A small body defined by its mass instead of its bulk density.

    Syntax

    MATLAB
    body = sbtk.body.from_mass(name, shape, mass_kg, R_ref_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the body.
    shape1 × 1structrequiredThe shape model. Fields: shape.
    mass_kgscalardoublekgrequiredTotal mass M. Validation: mustBePositive.
    R_ref_kmscalardoublekmrequiredReference radius of the gravity coefficients. Validation: mustBePositive.

    Outputs

    NameDescription
    bodyThe body, with bulk density = mass / shape volume. Fields: body.

    Description

    Same as sbtk.body.create with bulk density = mass / shape volume. Use it when the mass (or GM / G) is what was measured.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: shape.
    body = sbtk.body.from_mass("Didymos", shape, 5.273e11, 0.43);

    sbtk.body.to_frame#

    A body with its shape model in another frame: x' = (x - origin_km) * axes.

    Syntax

    MATLAB
    body = sbtk.body.to_frame(body, origin_km, axes, shape_name)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredfrom sbtk.body.create or sbtk.body.from_mass Fields: body.
    origin_km1 × 3doublekmrequiredorigin of the new frame in the current frame [km]; [0 0 0] keeps the origin Validation: mustBeFinite.
    axes3 × 3doublerequired3 x 3 rotation, columns: the new axes as unit vectors in the current frame, e.g. cf.axes of sbtk.gravity.center_of_mass_frame; eye(3) keeps the axes Validation: mustBeFinite.
    shape_name1 × 1stringrequiredname of the transformed shape model; an exchange package writes it as <data set>_<shape_name>.obj

    Outputs

    NameDescription
    bodyfrom sbtk.body.create or sbtk.body.from_mass Fields: body.

    Description

    The vertices become (v - origin_km)*axes; the mass, reference radius and name of the body are kept, and the center of figure moves with the shape. shape.source keeps the name of the original file (not its path, which a package must not carry), and shape.frame_origin_km and shape.frame_axes give the frame relative to that file, combined over successive changes of frame: vertices = (file vertices - frame_origin_km)*frame_axes. An exchange package states them in conventions.txt. Use the same origin_km and axes for the measurements (sbtk.data.to_frame) and the interior or true model (sbtk.interior.to_frame).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: truth, body.
    spin   = sbtk.gravity.center_of_mass_frame(truth, body, "spin");
body_s = sbtk.body.to_frame(body, spin.com_km, spin.axes, "didymos_v003_com_spin_axes");
