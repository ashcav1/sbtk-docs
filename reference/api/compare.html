    Last edited October 21, 2026

    FunctionPurpose

    sbtk.compare.evaluate#

    Compare a fit with the true model, using a prepared reference (see sbtk.compare.reference).

    Syntax

    MATLAB
    cmp = sbtk.compare.evaluate(ref, fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    ref1 × 1structrequiredPrepared reference from sbtk.compare.reference. Fields: ref.
    fit1 × 1structrequiredInversion result with the same components and origin as the reference. Fields: fit.

    Outputs

    NameDescription
    cmpComparison with the true model. Fields: cmp.

    Description

    fit must use the same components (same geometry) as ref. Returns the fields described in sbtk.compare.with_truth.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, components, prob, exact.
    % many fits of the same components against one true model
ref = sbtk.compare.reference(body, truth, components, prob.geo.origin_km);   % once, about 0.5 s
for k = 1:100
    fit = sbtk.invert.run(sbtk.invert.replace_data(prob, sbtk.data.add_noise(exact, k)));
    cmp = sbtk.compare.evaluate(ref, fit);                                  % milliseconds
    R2(k) = cmp.R2;
end

    sbtk.compare.grids#

    Compare two density grids cell by cell (e.g. a solution package with an interior-model package).

    Syntax

    MATLAB
    cmp = sbtk.compare.grids(truth, estimate)

    Arguments

    NameSizeClassUnitDefaultDescription
    truth1 × 1structrequiredfrom sbtk.exchange.read_grid or sbtk.exchange.density_grid, with the same spacing; cells present in both are compared (every cell has the same volume, so all have equal weight) Fields: grid.
    estimate1 × 1structrequiredfrom sbtk.exchange.read_grid or sbtk.exchange.density_grid, with the same spacing; cells present in both are compared (every cell has the same volume, so all have equal weight) Fields: grid.

    Outputs

    NameDescription
    cmpComparison of the grids. Fields: gridcmp.

    Description

    cmp.R21 - sum (estimate - true)^2 / sum (true - mean true)^2: the fraction of the variance of the true density explained
    cmp.rms_kgm3RMS of estimate - true
    cmp.mean_error_kgm3mean of estimate - true
    cmp.std_true_kgm3standard deviation of the true density
    cmp.within_2sigmafraction of cells with |estimate - true| <= 2 sigma of the estimate (NaN if the estimate has no uncertainties)

    cmp.n_common, cmp.n_truth, cmp.n_estimate numbers of cells

    Example

    MATLAB, from the help text
    cmp = sbtk.compare.grids(sbtk.exchange.read_grid("UCB-MOD1-Didymos/density_grid.txt"), ...
                         sbtk.exchange.read_grid("XYZ-SOL_UCB1/density_grid.txt"));

    Related functions

    Mentioned in the help text
    sbtk.exchange.density_grid, sbtk.exchange.read_grid

    sbtk.compare.reference#

    The true model sampled once for comparisons with fits that use a given set of components.

    Syntax

    MATLAB
    ref = sbtk.compare.reference(body, truth, components, origin_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    truth1 × 1structrequiredTrue model from sbtk.data.simulate. Fields: truth.
    components1 × anystructrequiredthe components of the fits to be compared (their geometry; densities are not used) Fields: component.
    origin_km1 × 3doublekmrequiredthe point their layers and sectors are measured from: the fits' origin_km (the true model's origin for data in its frame, the measured center of mass for data about the center of mass) Validation: mustBeFinite.

    Outputs

    NameDescription
    refThe prepared reference. Fields: ref.

    Description

    Evaluates the true density at points filling the body (24 radial shells per facet cone, weighted by volume, in the true model's frame), the membership of every point in every component, and R2_max for these components. sbtk.compare.evaluate(ref, fit) then compares any such fit in milliseconds.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, components, prob.
    ref = sbtk.compare.reference(body, truth, components, prob.geo.origin_km);
cmp = sbtk.compare.evaluate(ref, sbtk.invert.run(prob));
% (see sbtk.compare.evaluate for a loop over noise realizations)

    Related functions

    Mentioned in the help text

    sbtk.compare.with_truth

    sbtk.compare.with_truth#

    Compare an estimated density with the true density (synthetic tests).

    Syntax

    MATLAB
    cmp = sbtk.compare.with_truth(body, truth, fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    truth1 × 1structrequiredthe true model, from sbtk.data.simulate Fields: truth.
    fit1 × 1structrequiredthe estimate, from sbtk.invert.run Fields: fit.

    Outputs

    NameDescription
    cmpComparison with the true model. Fields: cmp.

    Description

    Both densities are evaluated at points filling the body (24 radial shells per facet cone, 1.18 million for Didymos, each weighted by its volume); the true model's layers and sectors are measured from truth.origin_km, the fit's from fit.origin_km. About 0.5 s for Didymos.

    cmp.R2coefficient of determination of the estimated density: R2 = 1 - sum w (rho_est - rho_true)^2 / sum w (rho_true - mean)^2, the fraction of the variance of the true density (about its volume-weighted mean) that the estimate explains. 1 = exact; 0 = no better than a homogeneous body; < 0 = worse than that.
    cmp.R2_maxthe largest R2 attainable with the same components (weighted least-squares fit of the true density by the background and the components): the limit set by the choice of components
    cmp.rms_kgm3volume-weighted RMS density error [kg/m^3]
    cmp.std_true_kgm3volume-weighted standard deviation of the true density [kg/m^3]
    cmp.componentscomponents with the same name in both: name, estimate_kgm3, sigma_kgm3, true_kgm3 (densities), deviation_sigma (|estimate - true| / sigma)
    cmp.chi2_reduced, cmp.p_valuecopied from the fit

    For many fits with the same components against one true model, call sbtk.compare.reference once and sbtk.compare.evaluate for each fit.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, fit.
    cmp = sbtk.compare.with_truth(body, truth, fit);
sbtk.compare.summary(cmp)
sbtk.plot.comparison(cmp);
