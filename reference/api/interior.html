    sbtk.interior.align_with_spin_axis#

    Set the axis of components along the axis of the largest moment of the whole model.

    Syntax

    MATLAB
    [interior, axis_dir, iterations] = sbtk.interior.align_with_spin_axis(body, interior, names, tol_deg, max_iter)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredthe body Fields: body.
    interior1 × 1structrequiredfrom sbtk.interior.create Fields: interior.
    names1 × anystringrequiredthe components to align (string array; tori, ellipsoids or sectors), e.g. "torus"; strings(1, 0) for none
    tol_degscalardoubledegrequiredconvergence: the axis moves by at most this angle in the last iteration [deg] Validation: mustBePositive.
    max_iterscalardoublerequiredlargest number of iterations (sbtk:iteration:notConverged beyond it) Validation: mustBeInteger, mustBePositive.

    Outputs

    NameDescription
    interiorfrom sbtk.interior.create Fields: interior.
    axis_dir1 x 3 axis of the largest moment of the aligned interior, in the frame of the shape model (pointing to +z's side)
    iterationsnumber of simulations made

    Description

    A body in principal-axis rotation spins about its axis of the largest moment, so a component that formed about the spin axis, such as an equatorial torus, lies about that axis. The axis depends on every component, the aligned ones included, so the alignment is a fixed-point iteration (sbtk.internal.fixed_point): simulate to degree 2, take the axis of the largest moment (sbtk.gravity.center_of_mass_frame), turn the named components to it (sbtk.interior.set_axis), repeat. Each iteration is one simulation; the axis usually settles to 0.01 deg in 2 to 4.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, core.
    t = sbtk.interior.torus("torus", 0.370, 0.055, 0, -500);
t.center_km = body.centroid_km;
interior = sbtk.interior.create([core, t], sbtk.interior.no_random_field());
[interior, axis_dir] = sbtk.interior.align_with_spin_axis(body, interior, "torus", 0.01, 20);
fprintf('axis %.2f deg from the shape-model z-axis\n', acosd(axis_dir(3)));

    sbtk.interior.create#

    An interior model: components plus an optional random density field.

    Syntax

    MATLAB
    interior = sbtk.interior.create(components, field)

    Arguments

    NameSizeClassUnitDefaultDescription
    components1 × anystructrequired1 x n struct array from the component constructors (sphere, ellipsoid, torus, layer, sector); sbtk.interior.no_components() for none. Overlapping relative densities add; everything outside the body is clipped. Fields: component.
    field1 × 1structsbtk.interior.no_random_field()sbtk.interior.random_field(...); omit it (or pass sbtk.interior.no_random_field()) for none Fields: random_field.

    Outputs

    NameDescription
    interiorComponents and random field. Fields: interior.

    Description

    The background density is not set here: sbtk.data.simulate sets it so that the total mass matches the body.

    Example

    MATLAB, from the help text

              sbtk.interior.layer("regolith", 0, 0.012, -900)];
interior = sbtk.interior.create(components);                                   % no random field
interior = sbtk.interior.create(components, sbtk.interior.random_field(40, 0.06, 7));

    sbtk.interior.density_at#

    Syntax

    Arguments

    NameSizeClassUnitDefaultDescription
    model1 × 1structrequiredanything with rho_bg_kgm3, components and random_field: a true model from sbtk.data.simulate or a fit from sbtk.invert.run

    Syntax

    MATLAB
    c = sbtk.interior.layer(name, top_depth_km, bottom_depth_km, drho_kgm3)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the component; unique within a model.
    top_depth_kmscalardoublekmrequiredDepth of the top of the layer below the surface, along rays from the expansion origin (0 = at the surface). Validation: mustBeNonnegative.
    bottom_depth_kmscalardoublekmrequiredDepth of the bottom of the layer; larger than the top depth. Validation: mustBePositive, mustBeGreaterThan(bottom_depth_km, top_depth_km).

    sbtk.interior.random_field#

    Gaussian random density field added to the interior.

    Syntax

    MATLAB
    field = sbtk.interior.random_field(sigma_kgm3, corr_length_km, seed)

    Arguments

    NameSizeClassUnitDefaultDescription
    sigma_kgm3scalardoublekg/m³requiredstandard deviation of the density perturbation [kg/m^3] Validation: mustBeNonnegative.
    corr_length_kmscalardoublekmrequiredcorrelation length [km]: correlation exp(-|dx|^2 / (2 L^2)) Validation: mustBePositive.
    seedscalardoublerequiredrandom seed (the same seed gives the same field) Validation: mustBeInteger, mustBeNonnegative.

    Outputs

    NameDescription

    Description

    The field is a sum of 300 random Fourier modes, defined at every point and independent of the expansion origin. sbtk.interior.no_random_field() for none.

    Example

    MATLAB, from the help text

    sbtk.interior.sector#

    Uniform sector component: radial fractions x latitude/longitude range.

    Syntax

    MATLAB
    c = sbtk.interior.sector(name, frac, lat_deg, lon_deg, drho_kgm3)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the component; unique within a model.
    frac1 × 2doublerequired[f_in f_out]: fraction of the local distance from the expansion origin to the surface (0 = center, 1 = surface) Validation: mustBeInRange(frac, 0, 1).
    lat_deg1 × 2doubledegrequired[lat_min lat_max] in -90..90 [deg] Validation: mustBeInRange(lat_deg, -90, 90).
    lon_deg1 × 2doubledegrequired[lon_min lon_max] in -360..360 [deg], at most 360 apart; ranges past +-180 wrap around. Every range must increase. Validation: mustBeInRange(lon_deg, -360, 360).
    drho_kgm3scalardoublekg/m³requiredRelative density: density minus the background density. Validation: mustBeFinite.

    Outputs

    NameDescription
    pThe component. Fields: component.

    Description

    drho_kgm3 relative density [kg/m^3]

    Latitude and longitude are measured about the expansion origin, in the axes of the shape-model frame (c.axes = eye(3); sbtk.interior.to_frame turns them with the frame). sbtk.interior.sector("shell", [0.5 0.75], [-90 90], [-180 180], 0) is a shell that follows the shape. See also sbtk.interior.sector_grid.

    Example

    MATLAB, from the help text
    block = sbtk.interior.sector("block", [0.3 0.9], [40 90], [150 240], +200);   % radial fraction, latitude, longitude
shell = sbtk.interior.sector("shell", [0.5 0.75], [-90 90], [-180 180], -300);

    sbtk.interior.sector_grid#

    Sectors that tile the whole body (a model without assumed structure).

    Syntax

    MATLAB
    components = sbtk.interior.sector_grid(frac_edges, lat_edges_deg, lon_edges_deg)

    Arguments

    NameSizeClassUnitDefaultDescription
    frac_edges1 × anydoublerequiredradial fraction edges from 0 to 1, e.g. [0 0.45 0.8 1] Validation: mustBeInRange(frac_edges, 0, 1).
    lat_edges_deg1 × anydoubledegrequiredlatitude edges from -90 to 90, e.g. [-90 0 90] Validation: mustBeInRange(lat_edges_deg, -90, 90).
    lon_edges_deg1 × anydoubledegrequiredlongitude edges spanning 360 deg, e.g. [-180 -90 0 90 180] Validation: mustBeInRange(lon_edges_deg, -360, 360).

    Outputs

    NameDescription
    componentsOne sector per radial shell, latitude band and longitude band, named s<shell><lat><lon>, with relative density 0. Fields: component.

    Description

    One sector per (radial shell, latitude band, longitude band), named 's<shell><lat><lon>' (s111 = innermost shell, southernmost band, first longitude band), drho_kgm3 = 0. The example edges give 3 x 2 x 4 = 24 sectors. Many components usually need regularization (sbtk.invert.choose_regularization). Because the sectors fill the body, the background density and a common shift of all sector densities are interchangeable: use regularization or hold the background at the bulk density (opts.background = "bulk").

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, obs.
    sectors = sbtk.interior.sector_grid([0 0.5 0.85 1], [-90 -30 30 90], [-180 -90 0 90 180]);   % 36
prob = sbtk.invert.setup(body, sectors, obs, sbtk.invert.options(background="bulk"));
prob.opts.regularization = sbtk.invert.choose_regularization(prob);
fit = sbtk.invert.run(prob);

    Related functions

    Mentioned in the help text

    sbtk.interior.set_axis#

    Turn a component so that its axis points along a given direction.

    Syntax

    MATLAB
    c = sbtk.interior.set_axis(c, direction)

    Arguments

    NameSizeClassUnitDefaultDescription
    c1 × 1structrequireda torus, an ellipsoid or a sector (a component with axes, c.axes) Fields: component.
    direction1 × 3doublerequired1 x 3 direction in the frame of the shape model (normalized here) Validation: mustBeFinite.

    Outputs

    NameDescription
    ca torus, an ellipsoid or a sector (a component with axes, c.axes) Fields: component.

    Description

    The axis of a component is its third axis, c.axes(:, 3): the axis a torus lies about, the third semi-axis of an ellipsoid, the pole of a sector's latitudes. The component is turned by the smallest rotation that takes this axis to the direction, about its own center (c.center_km; a sector about the expansion origin), so its first two axes stay as close as possible to where they were.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, See, also.
      t = sbtk.interior.torus("torus", 0.370, 0.055, 0, -500);
  t.center_km = body.centroid_km;                              % about the center of figure
  t = sbtk.interior.set_axis(t, [sind(5) 0 cosd(5)]);         % axis tilted 5 deg toward +x
See also sbtk.interior.align_with_spin_axis.

    Related functions

    Mentioned in the help text
    sbtk.interior.align_with_spin_axis, sbtk.interior.torus
    Called by
    sbtk.interior.align_with_spin_axis, sbtk.invert.run

    sbtk.interior.to_frame#

    An interior or a true model in another frame: x' = (x - origin_km) * axes.

    Syntax

    MATLAB
    model = sbtk.interior.to_frame(model, origin_km, axes)

    Arguments

    NameSizeClassUnitDefaultDescription
    model1 × 1structrequiredan interior (sbtk.interior.create) or a true model (truth from sbtk.data.simulate)
    origin_km1 × 3doublekmrequiredorigin of the new frame in the current frame [km]; [0 0 0] keeps the origin Validation: mustBeFinite.
    axes3 × 3doublerequired3 x 3 rotation, columns: the new axes as unit vectors in the current frame, e.g. cf.axes of sbtk.gravity.center_of_mass_frame; eye(3) keeps the axes Validation: mustBeFinite.

    Outputs

    NameDescription
    modelan interior (sbtk.interior.create) or a true model (truth from sbtk.data.simulate)

    Description

    Every position is transformed as x' = (x - origin_km)*axes and every direction as d' = d*axes: the centers of spheres, ellipsoids and tori, the axes of ellipsoids, tori and sectors (c.axes), the random field, and for a true model origin_km and com_km. Its coefficients are rotated (exact, sbtk.internal.sh_rotation) and its inertia elements become axes'*I*axes; both stay about the same point. The density at every point of the body is unchanged, so the model, the body from sbtk.body.to_frame and the measurements from sbtk.data.to_frame (same origin_km and axes) describe the same body in the new frame: simulating, gridding, plotting and comparing there gives the transformed results. An inversion result cannot be transformed: transform the measurements and the body and invert in the new frame.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, interior.
    [exact, truth] = sbtk.data.simulate(body, interior, 4, "T1");
spin  = sbtk.gravity.center_of_mass_frame(truth, body, "spin");   % z = axis of the largest moment
truth_s = sbtk.interior.to_frame(truth, [0 0 0], spin.axes);
body_s  = sbtk.body.to_frame(body, [0 0 0], spin.axes, "didymos_spin_axes");
grid = sbtk.exchange.density_grid(body_s, truth_s, 0.020);         % the grid in the new frame

    Related functions

    Mentioned in the help text
    sbtk.body.to_frame, sbtk.data.simulate, sbtk.data.to_frame, sbtk.exchange.density_grid, sbtk.gravity.center_of_mass_frame, sbtk.interior.create, sbtk.internal.sh_rotation
    Calls
    sbtk.body.to_frame, sbtk.data.to_frame

    sbtk.interior.torus#

    Uniform torus component about the z-axis, clipped to the body.

    Syntax

    MATLAB
    c = sbtk.interior.torus(name, ring_radius_km, tube_radius_km, height_km, drho_kgm3)

    Arguments

    NameSizeClassUnitDefaultDescription
    name1 × 1stringrequiredName of the component; unique within a model.
    ring_radius_kmscalardoublekmrequiredradius of the tube's center circle [km] Validation: mustBeNonnegative.
    tube_radius_kmscalardoublekmrequiredradius of the tube [km] Validation: mustBePositive.
    height_kmscalardoublekmrequiredz of the center circle's plane [km] Validation: mustBeFinite.
    drho_kgm3scalardoublekg/m³requiredrelative density [kg/m^3] Validation: mustBeFinite.

    Outputs

    NameDescription
    pThe component. Fields: component.

    Description

    The torus lies about the z-axis of the shape-model frame (c.center_km = [0 0 0], c.axes = eye(3); sbtk.interior.to_frame moves and turns both with the frame). It may be buried, intersect the surface or extend outside the body; only its intersection with the body counts. sbtk.interior.set_axis turns it; sbtk.interior.align_with_spin_axis puts it about the model's own axis of the largest moment. An inversion can estimate its center (c.estimate_position = true, or a mask such as [false false true] for z only) and the direction of its axis (c.estimate_axis = true) besides its density (sbtk.invert.run).

    Example

    MATLAB, from the help text
    torus = sbtk.interior.torus("torus", 0.370, 0.055, 0, -500);

    Related functions

    Mentioned in the help text
    sbtk.interior.align_with_spin_axis, sbtk.interior.set_axis, sbtk.interior.to_frame, sbtk.invert.run

    Implementation: toolbox/+sbtk/+interior/torus.m, line 1.
