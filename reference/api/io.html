    sbtk.io.new_run#

    Create a results folder for one run and start its log.

    Syntax

    MATLAB
    out = sbtk.io.new_run(project, name)

    Arguments

    NameSizeClassUnitDefaultDescription
    project1 × 1stringrequiredProject name: the folder results/<project>/.
    name1 × 1stringrequiredRun name; the folder is results/<project>/<yyyy-mm-dd_HHMMSS>_<name>/.

    Outputs

    NameDescription
    outThe results folder. Fields: out.

    Description

    Creates <SBTK>/results/<project>/<yyyy-mm-dd_HHMMSS>_<name>/ (figures go to its figures/ subfolder) and records everything printed in the command window to log.txt in it until sbtk.io.finish_run(out). Standard file names inside:

    out.project, out.name, out.stamp, out.folder, out.figures

    Example

    MATLAB, from the help text

    sbtk.io.read_jpl_gravity#

    Measurements from a JPL SSD gravity-field file (normalized coefficients + covariance).

    Syntax

    MATLAB
    obs = sbtk.io.read_jpl_gravity(file, body, name, origin_km, degree)

    Arguments

    NameSizeClassUnitDefaultDescription
    file1 × 1stringrequiredJPL SSD gravity file in MATLAB-assignment form (REF_RADIUS, NORMALIZED, NAMES = {...}, VALS = [...], COV = [...]), e.g. the OSIRIS-REx Bennu field Validation: mustBeFile.
    body1 × 1structrequiredfrom sbtk.body.create; body.R_ref_km must equal the file's REF_RADIUS Fields: body.
    name1 × 1stringrequiredname of the data set
    origin_km1 × 3doublekmrequiredpoint the field is expanded about, in shape-model coordinates [km] (the center of mass of the gravity solution) Validation: mustBeFinite.
    degreescalardoublerequiredhighest degree to keep (2 .. the file's DEGREE) Validation: mustBeInteger, mustBeGreaterThanOrEqual(degree, 2).

    Outputs

    NameDescription
    obsThe measurement set: coefficients of degree 2 … degree with their covariance, coef_about = 'origin'. Fields: obs.

    Description

    The file is parsed as text (not executed). Zonal terms J_l are converted to C_l0 = -J_l (with the matching sign changes in the covariance); C_lm, S_lm are kept. The covariance of the kept coefficients is the full submatrix of the file's covariance (GM row and column removed). The mass is GM / G. Degree-1 terms are absent in such files (the expansion is about the center of mass); add them with sbtk.data.add_center_of_mass.

    Example

    MATLAB, from the help text
    body = sbtk.body.create("Bennu", sbtk.shape.bundled("bennu"), 1190, 0.290);
file = fullfile(sbtk.root, "data", "gravity", "bennu_osirisrex_jpl_2019.txt");
obs  = sbtk.io.read_jpl_gravity(file, body, "bennu_jpl2019", [0 0 0], 4);
obs  = sbtk.data.add_center_of_mass(obs, [0 0 0], 0.001);

    Related functions

    Mentioned in the help text
    sbtk.body.create, sbtk.data.add_center_of_mass, sbtk.root, sbtk.shape.bundled
    Calls
    sbtk.units.G

    Implementation: toolbox/+sbtk/+io/read_jpl_gravity.m, line 1.

    sbtk.io.read_measurements#

    Measurement set from the SBTK text format.

    Syntax

    MATLAB
    obs = sbtk.io.read_measurements(file)

    Arguments

    NameSizeClassUnitDefaultDescription
    file1 × 1stringrequiredPath of a text file in the SBTK measurement format. Validation: mustBeFile.

    Outputs

    NameDescription
    obsThe measurement set (diagonal covariance). Fields: obs.

    Description

    Keywords (see sbtk.io.write_measurements and docs/data_formats.md):

      body, name, mass_kg, GM_km3_s2, R_ref_km, degree
  origin_km          expansion origin, shape-model coordinates [km]
  com_minus_cof_km   center-of-mass offset from the center of figure [km]
  coef l m C S sigma_C sigma_S        one line per degree and order
  inertia label value sigma w(1..6)   one line per moment-of-inertia measurement

    Other keywords are ignored. This is the entry point for data from other teams: convert their files to this format, or build the measurements from arrays with sbtk.data.from_coefficients.

    Example

    MATLAB, from the help text
    obs = sbtk.io.read_measurements("measurements.txt");

    Related functions

    Mentioned in the help text
    sbtk.data.from_coefficients, sbtk.io.write_measurements
    Called by
    sbtk.io.load_measurements

    Implementation: toolbox/+sbtk/+io/read_measurements.m, line 1.

    sbtk.io.write_measurements#

    Plain-text copy of a measurement set (read back by sbtk.io.read_measurements).

    Syntax

    MATLAB
    sbtk.io.write_measurements(obs, file)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set. Fields: obs.
    file1 × 1stringrequiredPath of the text file to write.

    Description

    One keyword per line, values separated by spaces, '#' lines are comments, so every block can be pasted into a spreadsheet or another code. Only the diagonal of the coefficient covariance is written (the .mat keeps it all). Keywords: body, name, mass_kg, GM_km3_s2, R_ref_km, degree, origin_km, com_minus_cof_km, coef (l m C S sigma_C sigma_S), inertia (label value sigma w_Ixx w_Iyy w_Izz w_Ixy w_Ixz w_Iyz), plus informational lines.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.
    sbtk.io.write_measurements(obs, "measurements.txt");

    Related functions

    Calls

    Called by
    sbtk.io.save_measurements
