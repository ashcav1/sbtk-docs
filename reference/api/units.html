    sbtk.units.G#

    Gravitational constant in SBTK units [km^3 kg^-1 s^-2].

    Syntax

    MATLAB
    g = sbtk.units.G()      % 6.67430e-20 km^3/(kg s^2)  (CODATA 2018)

    Outputs

    NameDescription
    g6.67430e-20 km³ kg⁻¹ s⁻² (CODATA 2018).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body.
    GM_km3_s2 = sbtk.units.G()*body.mass_kg;

    Related functions

    Called by
    sbtk.body.create, sbtk.data.from_coefficients, sbtk.data.simulate, sbtk.exchange.read_data, sbtk.exchange.read_shadr, sbtk.gravity.polyhedron, sbtk.io.read_jpl_gravity

    Implementation: toolbox/+sbtk/+units/G.m, line 1.

    sbtk.units.length_scale#

    Factor that converts a length in UNIT to km.

    Syntax

    MATLAB
    f = sbtk.units.length_scale(unit)      % unit: "km", "m" or "cm"

    Arguments

    NameSizeClassUnitDefaultDescription
    unit1 × 1stringrequiredLength unit: "km", "m" or "cm". Validation: mustBeMember(unit, ["km", "m", "cm"]).

    Outputs

    NameDescription
    fFactor that converts a length in that unit to km (1, 1e-3 or 1e-5).

    Example

    sbtk.units.length_scale("m") returns 1e-3.

    Related functions

    Called by
    sbtk.shape.from_arrays, sbtk.shape.load

    Implementation: toolbox/+sbtk/+units/length_scale.m, line 1.

    sbtk.units.moi_to_norm#

    Moment of inertia in kg m^2 -> I / (M R_ref^2) (dimensionless).

    Syntax

    MATLAB
    I_norm = sbtk.units.moi_to_norm(I_kgm2, mass_kg, R_ref_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    I_kgm2doublekg m²requiredMoment of inertia, or an array of them. Validation: mustBeFinite.
    mass_kgscalardoublekgrequiredTotal mass M. Validation: mustBePositive.
    R_ref_kmscalardoublekmrequiredReference radius Rref. Validation: mustBePositive.

    Outputs

    NameDescription
    I_normI/(MRref2), same size as the input.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body.
    Izz = sbtk.units.moi_to_norm(1.6e14, body.mass_kg, body.R_ref_km);    % kg m^2 -> I/(M R_ref^2)

    Implementation: toolbox/+sbtk/+units/moi_to_norm.m, line 1.

    NameSizeClassUnitDefaultDescription

    sbtk.units.offset_to_degree1#

    Fully normalized degree-1 coefficient of a center-of-mass offset.

    Syntax

    MATLAB
    c = sbtk.units.offset_to_degree1(offset_km, R_ref_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    offset_kmdoublekmrequiredoffset of the center of mass from the expansion origin along one axis, or its 1-sigma uncertainty [km] Validation: mustBeFinite.
    R_ref_kmscalardoublekmrequiredreference radius of the gravity coefficients [km] Validation: mustBePositive.

    Outputs

    NameDescription
    cFully normalized degree-1 coefficient, d/(3Rref). Fields: component.

    Description

    c = offset_km / (sqrt(3) R_ref_km): C10 for z, C11 for x, S11 for y. Use it to give the degree-1 entry of sbtk.data.uncertainties as a center-of-mass uncertainty.

    Example

    MATLAB, from the help text
    % 2 m center of mass, 1e-4, 2e-4, 4e-4 for degrees 2-4
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);

    Related functions

    Mentioned in the help text
    sbtk.data.uncertainties

    Implementation: toolbox/+sbtk/+units/offset_to_degree1.m, line 1.
