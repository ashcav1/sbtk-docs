    sbtk.plot.anomaly#

    The measured anomaly coefficient by coefficient, with the anomalies of models and how well they match it.

    Syntax

    MATLAB
    fig = sbtk.plot.anomaly(an, models, names)

    Arguments

    NameSizeClassUnitDefaultDescription
    an1 × 1structrequiredthe measurements' anomaly (sbtk.interpret.anomaly of a measurement set) Fields: an.
    models1 × anycellrequiredcell array of model anomalies (sbtk.interpret.anomaly of a fit or a true model, same degree), or {} for the measurements alone
    namesrequiredone name per model Validation: mustBeText.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Top: each coefficient's anomaly (field minus homogeneous body, about the center of figure) divided by its 1-sigma, so that every degree can be read on one axis: black, the measurements with their +-1 sigma; colors, the models. A model fitted to some of the coefficients (a fit, an.fitted_labels) has filled markers on those and open markers on the others, which it predicts. Bottom: (model - measurement)/sigma; the gray band is +-1, the dashed lines +-3. Both axes are symmetric logarithmic, sign(v) log10(1 + |v|): linear near 0, logarithmic beyond a few sigma. Zonal coefficients are shown as J_l = -C_l0 (the sign of their anomaly flips with them); degree 1 is the center-of-mass offset (C11, S11, C10 = x, y, z / (sqrt(3) R_ref)). Vertical lines separate the degrees.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs, body, fit.
    an  = sbtk.interpret.anomaly(obs, body, 5);
fig = sbtk.plot.anomaly(an, {sbtk.interpret.anomaly(fit, body, 5)}, "core + torus");

    Related functions

    sbtk.plot.coefficient_residuals#

    Map of normalized residuals: one row per fit, one column per measurement, fitted ones outlined.

    Syntax

    MATLAB
    fig = sbtk.plot.coefficient_residuals(preds, names)

    Arguments

    NameSizeClassUnitDefaultDescription
    preds1 × anycellrequiredcell array of sbtk.invert.predict results for the same measurements (fits to different subsets of them, or with different models)
    namesrequiredone name per row Validation: mustBeText.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Each cell is (predicted - measured)/sigma of one measurement for one fit, colored on a symmetric logarithmic scale, sign(v) log10(1 + |v|), saturated at 100 (blue: predicted too small, red: too large; nearly white within 1 sigma). The measurements a fit was fitted to are outlined, so one row shows how well a fit matches its own coefficients (outlined cells) and how well it predicts the others. Right: chi-square per measurement of the fitted rows and of the others (with their covariance). Zonal coefficients are labeled J_l; their residual is that of C_l0 (the same size, opposite sign of J_l).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs, opts, preds.
    sets = {["C10" "C11" "S11" "C20"], ["C10" "C11" "S11" "C20" "C30"]};
for k = 1:2
    fit = sbtk.invert.solve(body, components, sbtk.data.select_coefficients(obs, sets{k}), opts);
    preds{k} = sbtk.invert.predict(fit, body, obs);
end
fig = sbtk.plot.coefficient_residuals(preds, ["degree 1 + J2", "+ J3"]);

    Related functions

    Mentioned in the help text
    sbtk.data.select_coefficients, sbtk.invert.predict, sbtk.invert.solve

    Estimate compared with the true model: R2 and each component's density.

    Syntax

    MATLAB

    Arguments

    NameSizeClassUnitDefaultDescription
    cmp1 × 1structrequiredComparison from sbtk.compare.with_truth. Fields: cmp.

    Outputs

    NameDescription

    Description

    Left: R2 of the estimated density (fraction of the variance of the true density explained) next to R2_max, the largest R2 the same components can reach. Right: each component's estimated density with +-1 sigma (bar) and the true density (cross).

    sbtk.plot.degree_ratio#

    Each degree's change from the homogeneous body: scaling (radial structure) and the rest.

    Syntax

    MATLAB
    fig = sbtk.plot.degree_ratio(an, models, names)

    Arguments

    NameSizeClassUnitDefaultDescription
    an1 × 1structrequiredan anomaly (sbtk.interpret.anomaly): measurements, or a model Fields: an.
    models1 × anycellrequiredcell array of further anomalies (fits, true models), or {}
    namesrequiredone name per model Validation: mustBeText.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Left: 100 (k_l - 1), the change of degree l as a scaled homogeneous field, in % of the homogeneous field (an.ratio; measurements with +-1 sigma, cut at the range of the values). A compact central mass excess q M changes every degree by -100 q %; a light surface layer of thickness t changes degree l by about 100 (drho/rho) l t/r % (r the mean radius), more at higher degree; a torus or anything not centrally symmetric adds to some degrees only. Right: the RMS of the rest of each degree (an.residual_rms), the part that is not a scaled homogeneous field, with the RMS 1-sigma of the measurements (dashed): above it, the degree contains structure that is not centrally symmetric.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs, body, truth.
    fig = sbtk.plot.degree_ratio(sbtk.interpret.anomaly(obs, body, 5), ...
                             {sbtk.interpret.anomaly(truth, body, 5)}, "true model");

    Related functions

    Mentioned in the help text

    sbtk.plot.difference_from_homogeneous#

    Gravity coefficients minus those of the homogeneous body, coefficient by coefficient.

    Syntax

    MATLAB
    [fig, differences] = sbtk.plot.difference_from_homogeneous(body, sets, names, scale, frame)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredthe body: its shape model gives the homogeneous body (density M/V everywhere) Fields: body.
    sets1 × anycellrequiredcell array of coefficient sets, each one of a measurement set exact values (sbtk.data.simulate), measurements (sbtk.data.add_noise), a package (sbtk.exchange.read_data), ... a true model truth from sbtk.data.simulate an inversion result fit from sbtk.invert.run: the field of the fitted model
    namesrequiredone legend entry per set, e.g. ["true model" "estimate"] Validation: mustBeText.
    scale1 × 1stringrequired"linear": the signed difference, with +-3 sigma bars for sets that have uncertainties (measurement sets with coef_cov); "log": the absolute difference, with 3 sigma drawn as a separate line Validation: mustBeMember(scale, ["linear", "log"]).
    frame1 × 1stringrequiredthe axes both fields are expressed in (sbtk.gravity.center_of_mass_frame): "shape": the axes of the shape-model frame; "spin": z along the axis of the largest moment of the set, x the shape-model x-axis projected onto the plane normal to it, as in body-fixed radio-science fields (the OSIRIS-REx field of Bennu). The set has C21 = S21 = 0, so the homogeneous body's C21, S21 show how far its axis of the largest moment is tilted from the set's; "principal": the principal axes of inertia of the set (x the axis of the smallest moment, z of the largest). The set has C21 = S21 = S22 = 0, so the homogeneous body's C21, S21, S22 show how its principal axes are tilted and turned. Validation: mustBeMember(frame, ["shape", "spin", "principal"]).

    Outputs

    NameDescription
    figthe figure
    differencesstruct array, one per set: name, labels (as plotted: C10, C11, S11, J2, ...), difference, sigma (1-sigma; NaN where the set has none), axes_deg ([tilt turn]: angle between the axes of the largest moment of the set and of the homogeneous body, and angle about that axis between their axes of the smallest moment, deg)

    Description

    Both fields are about their own center of mass, as radio-science fields are:

      degrees >= 2   the set about its center of mass minus the homogeneous body about its
                 center of mass (the center of figure)
  degree 1       the set's center of mass minus the center of figure, as C11, S11, C10 =
                 (x, y, z)/(sqrt(3) R_ref) in the axes of the plot: about its own center of
                 mass each field's degree 1 is zero, so this shows where the interior moves
                 the center of mass instead

    sbtk.gravity.center_of_mass_frame moves each set to its center of mass and into the axes (it states how the center of mass of each kind of set is found); the homogeneous field is rotated into the same axes. Differences are fully normalized, in SBTK order; zonal coefficients are shown as J_l = -C_l0, so their difference has the opposite sign of the C_l0 difference. The reference radius is the set's (body.R_ref_km for truth and fit). One geometry is built per set (about 1 s for 49,152 facets at degree 4, about a minute for 3 million facets).

    The plot shows how far the gravity field of an interior departs from that of a uniform density, and, against 3 sigma, which departures measurements resolve. The three frames show the same information: the spin and principal axes move the difference in orientation of the principal axes into the homogeneous body's degree-2 terms.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, interior, unc, components.
    [exact, truth] = sbtk.data.simulate(body, interior, 4, "T1");
sbtk.plot.difference_from_homogeneous(body, {truth}, "true model", "linear", "principal");
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);
fit = sbtk.invert.solve(body, components, obs);
sbtk.plot.difference_from_homogeneous(body, {obs, fit}, ["measured" "estimate"], "log", "shape");

    sbtk.plot.interior3d#

    See-through 3D view of the body and the components of a model.

    Syntax

    MATLAB
    fig = sbtk.plot.interior3d(body, model, title_str)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    model1 × 1structrequireda truth or a fit (anything with components and origin_km)
    title_str1 × 1stringrequiredTitle of the figure.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    The surface is drawn translucent; spheres, ellipsoids and tori are drawn where they lie inside the body, layers by their lower boundary. Color is the relative density (blue lighter, red denser than the background). Sectors are not drawn (see sbtk.plot.slices).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, fit.
    fig = sbtk.plot.interior3d(body, truth, "true model");
fig = sbtk.plot.interior3d(body, fit, "estimate");

    sbtk.plot.measurements#

    What the data contain: gravity signal and noise per degree, and the inertia rows.

    Syntax

    MATLAB
    fig = sbtk.plot.measurements(obs)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set. Fields: obs.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Left: root-mean-square size of the coefficients of each degree (dots) and of their 1-sigma uncertainties (line). Degrees where the dots sit well above the line carry information about the interior; where they meet, the data are noise (degree 1 is near zero about the center of mass). Right: each moment-of-inertia measurement with its 1-sigma ('libration' is the row (B - A) - ratio*Izz, measured as 0).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.

    sbtk.plot.point_masses#

    The mass anomalies of a point-mass solution on two cuts through the center of figure.

    Syntax

    MATLAB
    fig = sbtk.plot.point_masses(body, pm, spacing_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    pm1 × 1structrequiredfrom sbtk.interpret.point_masses
    spacing_kmscalardoublekmrequiredthe grid spacing of the points (sbtk.interior.sphere_grid) [km] Validation: mustBePositive.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Each point within half a spacing of the plane z = 0 (left) or y = 0 (right) through the center of figure is a square colored by its mass anomaly spread over its grid cell, mass/spacing^3 in kg/m^3 (red: more mass than the homogeneous body, blue: less), on one color scale symmetric about 0. The crosses are the mass-weighted centroids of the positive (+) and negative (x) parts, projected onto each plane; the line is the outline of the body.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, prob.
    fig = sbtk.plot.point_masses(body, sbtk.interpret.point_masses(prob, "sensitivity"), 0.040);

    Related functions

    Mentioned in the help text

    sbtk.plot.residuals#

    Normalized residuals of a fit, (predicted - measured)/sigma, per measurement.

    Syntax

    MATLAB
    fig = sbtk.plot.residuals(fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    fit1 × 1structrequiredInversion result. Fields: fit.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Gray band: +-1 sigma; dashed: +-2 sigma. Blue within 1 sigma, amber 1-2, red beyond 2. For a correct model about 68% of the residuals fall within +-1 sigma; systematic residuals in one group of coefficients (e.g. all of degree 3) indicate structure the model does not contain.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: fit.

    sbtk.plot.significance#

    Each measurement with its +-1 sigma interval against the constant-density (homogeneous) value.

    Syntax

    MATLAB
    fig = sbtk.plot.significance(an)        % an from sbtk.interpret.anomaly of a measurement set

    Arguments

    NameSizeClassUnitDefaultDescription
    an1 × 1structrequiredAnomaly of a measurement set from sbtk.interpret.anomaly. Fields: an.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    For every gravity coefficient (about the center of figure) and every inertia row: (measured - homogeneous)/sigma with its +-1 sigma interval. The homogeneous body, the same shape model with the bulk density everywhere, is the line at 0: an interval that does not reach it is a measurement that differs from constant density at 1 sigma. Gray: within 1 sigma of constant density; amber: 1 to 3 sigma; red: more than 3 sigma. The axis is symmetric logarithmic, sign(v) log10(1 + |v|). Zonal coefficients are shown as J_l = -C_l0; degree 1 is the center-of-mass offset from the center of figure. The title counts the measurements in each class.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs, body.
    fig = sbtk.plot.significance(sbtk.interpret.anomaly(obs, body, 5));

    Related functions

    Mentioned in the help text
    sbtk.interpret.anomaly
