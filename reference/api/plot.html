    sbtk.plot.comparison#

    Estimate compared with the true model: R2 and each component's density.

    Syntax

    MATLAB
    fig = sbtk.plot.comparison(cmp)          % cmp from sbtk.compare.with_truth

    Arguments

    NameSizeClassUnitDefaultDescription
    cmp1 × 1structrequiredComparison from sbtk.compare.with_truth. Fields: cmp.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Left: R2 of the estimated density (fraction of the variance of the true density explained) next to R2_max, the largest R2 the same components can reach. Right: each component's estimated density with +-1 sigma (bar) and the true density (cross).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, fit.
    fig = sbtk.plot.comparison(sbtk.compare.with_truth(body, truth, fit));

    Related functions

    Mentioned in the help text

    sbtk.plot.densities#

    Estimated density of the background and each component with its 1-sigma uncertainty.

    Syntax

    MATLAB
    fig = sbtk.plot.densities(fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    fit1 × 1structrequiredInversion result. Fields: fit.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    One row per component (background first): the density [kg/m^3] and a +-1 sigma bar. The dashed line is the background density. Gray: components whose relative density is not resolved (|relative density| < 1 sigma).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: fit.
    fig = sbtk.plot.densities(fit);

    Related functions

    Called by

    sbtk.plot.interior3d#

    See-through 3D view of the body and the components of a model.

    Syntax

    MATLAB
    fig = sbtk.plot.interior3d(body, model, title_str)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    model1 × 1structrequireda truth or a fit (anything with components and origin_km)
    title_str1 × 1stringrequiredTitle of the figure.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    The surface is drawn translucent; spheres, ellipsoids and tori are drawn where they lie inside the body, layers by their lower boundary. Color is the density difference (blue lighter, red denser than the background). Sectors are not drawn (see sbtk.plot.slices).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, fit.
    fig = sbtk.plot.interior3d(body, truth, "true model");
fig = sbtk.plot.interior3d(body, fit, "estimate");

    sbtk.plot.measurements#

    What the data contain: gravity signal and noise per degree, and the inertia rows.

    Syntax

    MATLAB
    fig = sbtk.plot.measurements(obs)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set. Fields: obs.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Left: root-mean-square size of the coefficients of each degree (dots) and of their 1-sigma uncertainties (line). Degrees where the dots sit well above the line carry information about the interior; where they meet, the data are noise (degree 1 is near zero about the center of mass). Right: each moment-of-inertia measurement with its 1-sigma ('libration' is the row (B - A) - ratio*Izz, measured as 0).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.
    fig = sbtk.plot.measurements(obs);

    Related functions

    Called by
    sbtk.io.report_simulation

    Implementation: toolbox/+sbtk/+plot/measurements.m, line 1.

    sbtk.plot.residuals#

    Normalized residuals of a fit, (predicted - measured)/sigma, per measurement.

    Syntax

    MATLAB
    fig = sbtk.plot.residuals(fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    fit1 × 1structrequiredInversion result. Fields: fit.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Gray band: +-1 sigma; dashed: +-2 sigma. Blue within 1 sigma, amber 1-2, red beyond 2. For a correct model about 68% of the residuals fall within +-1 sigma; systematic residuals in one group of coefficients (e.g. all of degree 3) indicate structure the model does not contain.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: fit.
    fig = sbtk.plot.residuals(fit);

    Related functions

    Called by
    sbtk.exchange.write_solution, sbtk.io.report_inversion

    Implementation: toolbox/+sbtk/+plot/residuals.m, line 1.

    sbtk.plot.slices#

    Absolute density on the equatorial plane and a meridional plane.

    Syntax

    MATLAB
    fig = sbtk.plot.slices(body, models, titles)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    models1 × anycellrequiredcell array of models (truth from sbtk.data.simulate, fit from sbtk.invert.run): one row of panels each, one shared color scale
    titles1 × anycellrequiredcell array, one label per model

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Left: the plane z = 0 (looking down the spin axis). Right: the plane y = 0. Both pass through the first model's origin_km (its center of mass).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth.
    fig = sbtk.plot.slices(body, {truth}, {'truth'});

    Related functions

    sbtk.plot.truth_vs_estimate#

    Truth, estimate and their difference on two planes.

    Syntax

    MATLAB
    fig = sbtk.plot.truth_vs_estimate(body, truth, fit)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredThe body. Fields: body.
    truth1 × 1structrequiredThe true model. Fields: truth.
    fit1 × 1structrequiredThe inversion result. Fields: fit.

    Outputs

    NameDescription
    figHandle of the new figure.

    Description

    Rows: truth, estimate (same density color scale), and estimate minus truth (blue = estimate too light, red = too dense). Left: plane z = 0; right: plane y = 0, both through the truth's center of mass.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth, fit.
    fig = sbtk.plot.truth_vs_estimate(body, truth, fit);
