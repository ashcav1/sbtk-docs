    sbtk.data.add_center_of_mass#

    Add degree-1 coefficients that place the center of mass at a given point.

    Syntax

    MATLAB
    obs = sbtk.data.add_center_of_mass(obs, com_km, sigma_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set, without degree-1 coefficients. Fields: obs.
    com_km1 × 3doublekmrequiredcenter of mass in shape-model coordinates [km]; obs.origin_km when the coefficients are expanded about the center of mass (degree 1 = 0) Validation: mustBeFinite.
    sigma_kmscalardoublekmrequired1-sigma uncertainty of each component of the center of mass [km] Validation: mustBePositive.

    Outputs

    NameDescription
    obsThe measurement set with C10, C11 and S11 added and coef_about set to 'center_of_mass'. Fields: obs.

    Description

    With fully normalized coefficients, C10 = dz/(sqrt(3) R), C11 = dx/(sqrt(3) R), S11 = dy/(sqrt(3) R), with [dx dy dz] = com_km - obs.origin_km. In an inversion these terms constrain the first moment of the density, which sphere positions (estimate_position) can satisfy. Errors if the data already have degree-1 terms.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: file, body.
    % a field about the center of mass, which is at the shape-model origin within 1 m
obs = sbtk.io.read_jpl_gravity(file, body, "bennu_jpl", [0 0 0], 4);
obs = sbtk.data.add_center_of_mass(obs, [0 0 0], 0.001);

    sbtk.data.add_libration#

    Add a measured libration ratio (B - A)/C.

    Syntax

    MATLAB
    obs = sbtk.data.add_libration(obs, ratio, ratio_sigma, Izz_norm)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set; it must contain C22 and S22. Fields: obs.
    ratioscalardoublerequiredmeasured (B - A)/C: A <= B are the principal moments of inertia about the axes in the xy-plane (the long and intermediate axes of a body spinning about z) and C = Izz. This is what the libration of a synchronously rotating body depends on (amplitude 2e/(3 ratio - 1) for forced libration in an orbit of eccentricity e). Validation: mustBeFinite.
    ratio_sigmascalardoublerequiredits 1-sigma Validation: mustBePositive.
    Izz_normscalardoubleM R_ref²requiredIzz / (M R_ref^2) used to scale the uncertainty (a homogeneous-body value is accurate enough) Validation: mustBePositive.

    Outputs

    NameDescription
    obsThe measurement set with the libration row added. Fields: obs.

    Description

    The principal axes need not be the shape-model axes: their direction in the xy-plane comes from the measured C22 and S22 of obs (which must have them), and the measurement is stored as the linear row

        cos(2a) (Iyy - Ixx) + sin(2a) 2 Ixy - ratio Izz = 0 +- ratio_sigma Izz_norm,

    (B - A) written with the principal-axis angle a (sbtk.internal.libration_weights). Together with C22 and S22, which give B - A, the ratio measures C to a relative precision of about ratio_sigma/ratio.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.
    % (B - A)/C = 0.20 +- 0.03, with Izz/(M R_ref^2) about 0.39
obs = sbtk.data.add_libration(obs, 0.20, 0.03, 0.39);

    Related functions

    Mentioned in the help text
    sbtk.internal.libration_weights
    Calls
    sbtk.data.add_moi_row

    sbtk.data.add_moi_row#

    Add a measurement of any weighted sum of the inertia elements.

    Syntax

    MATLAB
    obs = sbtk.data.add_moi_row(obs, label, weights, value, sigma)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set. Fields: obs.
    label1 × 1stringrequiredName of the new row; must differ from the existing labels.
    weights1 × 6doublerequiredWeights on [Ixx,Iyy,Izz,Ixy,Ixz,Iyz]/(MRref2). Validation: mustBeFinite.
    valuescalardoublerequiredMeasured value of the weighted sum. Validation: mustBeFinite.
    sigmascalardoublerequiredIts 1σ. Validation: mustBePositive.

    Outputs

    NameDescription
    obsThe measurement set with the row added. Fields: obs.

    Description

    The measurement is weights * [Ixx Iyy Izz Ixy Ixz Iyz]' / (M R_ref^2) = value +- sigma. label must not already be in obs.moi.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.
    % Izz - (Ixx + Iyy)/2 = 0.09 +- 0.002 (as a fraction of M R_ref^2)
obs = sbtk.data.add_moi_row(obs, "polar_minus_mean", [-0.5 -0.5 1 0 0 0], 0.09, 0.002);

    Related functions

    Called by

    sbtk.data.add_noise#

    One noisy realization of a measurement set.

    Syntax

    MATLAB
    obs = sbtk.data.add_noise(obs, seed)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredMeasurement set with exact values and stated uncertainties. Fields: obs.
    seedscalardoublerequiredSeed of the random number stream (non-negative integer); the same seed gives the same noise. Validation: mustBeInteger, mustBeNonnegative.

    Outputs

    NameDescription
    obsOne noisy realization: coefficients plus noise drawn from coef_cov (full covariance), each inertia row plus noise from its σ; noise_seed set. Fields: obs.

    Description

    Adds Gaussian noise drawn from the stated uncertainties: the full coefficient covariance and each moment-of-inertia row's sigma. The same seed gives the same noise. The informational tensor obs.moi_tensor_norm is rebuilt from the noisy rows and the seed stored in obs.noise_seed. Errors if the measurements have no uncertainties (the exact values of sbtk.data.simulate).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, interior, unc.
    [exact, truth] = sbtk.data.simulate(body, interior, 4, "T1");
exact = sbtk.data.set_uncertainties(exact, unc);
obs = sbtk.data.add_noise(exact, 1);         % seed 1: the same noise every time

    sbtk.data.from_coefficients#

    Measurement set from gravity-coefficient matrices (e.g. a mission solution).

    Syntax

    MATLAB
    obs = sbtk.data.from_coefficients(body, name, origin_km, C, S, C_sigma, S_sigma)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredfrom sbtk.body.create: gives the mass and R_ref. R_ref must be the reference radius the coefficients are normalized with. Fields: body.
    name1 × 1stringrequiredname of this data set
    origin_km1 × 3doublekmrequiredpoint the coefficients are expanded about, in shape-model coordinates [km] (usually the center of mass) Validation: mustBeFinite.
    Cany × anydoublerequired(L+1) x (L+1) fully normalized coefficients, C(l+1, m+1) = C_lm (Kaula normalization, no Condon-Shortley phase); entries with m > l, the column S(:,1) and C00 are ignored Validation: mustBeFinite.
    Sany × anydoublerequired(L+1) x (L+1) fully normalized coefficients, C(l+1, m+1) = C_lm (Kaula normalization, no Condon-Shortley phase); entries with m > l, the column S(:,1) and C00 are ignored Validation: mustBeFinite.
    C_sigmaany × anydoublerequired1-sigma uncertainties, same layout (must be > 0 where used) Validation: mustBeNonnegative.
    S_sigmaany × anydoublerequired1-sigma uncertainties, same layout (must be > 0 where used) Validation: mustBeNonnegative.

    Outputs

    NameDescription
    obsThe measurement set: coefficients of degree 1 … L, diagonal covariance from the uncertainties, no inertia rows. Fields: obs.

    Description

    Degrees 1..L are used. Add moments of inertia with sbtk.data.add_moi / add_libration and a full covariance with sbtk.data.set_covariance.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, C, S, Cs, Ss.
    obs = sbtk.data.from_coefficients(body, "hera_v1", [0 0 0], C, S, Cs, Ss);

    sbtk.data.libration_ratio_from_amplitude#

    (B - A)/C from the forced libration of a synchronous satellite.

    Syntax

    MATLAB
    [ratio, ratio_sigma] = sbtk.data.libration_ratio_from_amplitude(amplitude_deg, amplitude_sigma_deg, e, e_sigma)

    Arguments

    NameSizeClassUnitDefaultDescription
    amplitude_degscalardoubledegrequiredsigned amplitude G of the forced libration gamma = G sin(M) [deg]: gamma is the angle of the long axis from the direction to the primary, M the mean anomaly. G < 0 (the long axis lags behind the primary direction while the satellite moves fastest) for (B - A)/C < 1/3, which covers elongations up to about 1.4 : 1; G > 0 above that. Validation: mustBeNonzero.
    amplitude_sigma_degscalardoubledegrequired1-sigma of G [deg] Validation: mustBeNonnegative.
    escalardoublerequiredorbital eccentricity and its 1-sigma Validation: mustBeInRange(e, 0, 1, 'exclude-upper').
    e_sigmascalardoublerequiredorbital eccentricity and its 1-sigma Validation: mustBeNonnegative.

    Outputs

    NameDescription
    ratio(B - A)/C (principal moments, see sbtk.data.add_libration) and its 1-sigma, from first-order error propagation
    ratio_sigma(B - A)/C (principal moments, see sbtk.data.add_libration) and its 1-sigma, from first-order error propagation

    Description

    Planar forced libration in a Keplerian orbit about a point-mass primary, to first order in e: gamma'' + 3 n^2 ratio gamma = 2 e n^2 sin(M), so G = 2e/(3 ratio - 1) and ratio = (1 + 2e/G)/3. Free libration, the primary's oblateness and the mutual dynamics of a binary are not included. The sensitivity grows near ratio = 1/3, where the free libration period equals the orbital period: an elongated body gives a large amplitude and a precise ratio, a nearly axisymmetric one a small amplitude that depends little on the ratio.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: obs.
    % amplitude -12 +- 0.2 deg, e = 0.027 +- 0.001: (B - A)/C = 0.247 +- 0.0035 (1.4%)
[k, sk] = sbtk.data.libration_ratio_from_amplitude(-12, 0.2, 0.027, 0.001);
obs = sbtk.data.add_libration(obs, k, sk, 0.39);
% a nearly axisymmetric body: -4.0 +- 0.2 deg gives 0.075 +- 0.016 (21%)

    Related functions

    Mentioned in the help text
    sbtk.data.add_libration

    Implementation: toolbox/+sbtk/+data/libration_ratio_from_amplitude.m, line 1.

    sbtk.data.move_origin#

    Express measurements about the center of mass relative to a new expansion origin.

    Syntax

    MATLAB
    obs = sbtk.data.move_origin(obs, origin_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredMeasurement set with coef_about = 'center_of_mass'. Fields: obs.
    origin_km1 × 3doublekmrequiredNew expansion origin in the shape-model frame. Validation: mustBeFinite.

    Outputs

    NameDescription
    obsThe same measurements with the degree-1 values relative to the new origin. Fields: obs.

    Description

    For obs.coef_about = 'center_of_mass' only: the coefficients of degree >= 2 are about the body's center of mass wherever the origin is, and the degree-1 coefficients give the measured center of mass relative to the origin (C10 = dz/(sqrt(3) R), C11 = dx/(sqrt(3) R), S11 = dy/(sqrt(3) R)). Moving the origin changes only the degree-1 values; uncertainties are unchanged.

    Example

    MATLAB, from the help text
    obs = sbtk.exchange.read_data("CUB-DATA1-Didymos");
moved = sbtk.data.move_origin(obs, obs.origin_km + [0.001 0 0]);     % 1 m along x

    Related functions

    Mentioned in the help text
    sbtk.exchange.read_data

    Implementation: toolbox/+sbtk/+data/move_origin.m, line 1.

    sbtk.data.set_moi_sigma#

    Set the 1-sigma of moment-of-inertia measurements by label.

    Syntax

    MATLAB
    obs = sbtk.data.set_moi_sigma(obs, sigma)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredThe measurement set. Fields: obs.
    sigma1 × 1structrequiredstruct whose field names are measurement labels and whose values are 1-sigma: Ixx, Iyy, Izz, Ixy, Ixz, Iyz (or a label of sbtk.data.add_moi_row) as a fraction of M R_ref^2 libration of the ratio (B - A)/C; the row's 1-sigma becomes this times the Izz / (M R_ref^2) of the Izz row Rows not named keep their sigma. s = struct('Ixx', 2.0e9, 'Iyy', 2.0e9, 'Izz', 2.0e9);
obs = sbtk.data.set_moi_sigma(obs, structfun(@(v) v/(body.mass_kg*body.R_ref_km^2), s, 'UniformOutput', false));

    sbtk.data.set_uncertainties#

    Give measurements a 1-sigma uncertainty per degree and per inertia quantity.

    Syntax

    MATLAB
    obs = sbtk.data.set_uncertainties(obs, unc)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredmeasurements, e.g. the exact values from sbtk.data.simulate, which have none Fields: obs.
    unc1 × 1structrequiredfrom sbtk.data.uncertainties Fields: unc.

    Outputs

    NameDescription
    obsmeasurements, e.g. the exact values from sbtk.data.simulate, which have none Fields: obs.

    Description

    Every gravity coefficient of degree l gets the 1-sigma unc.coef_sigma_by_degree(l), and the coefficient covariance becomes diagonal. Every inertia element (Ixx, Iyy, Izz, Ixy, Ixz, Iyz) gets unc.moi_sigma. The libration row gets unc.libration_sigma times the Izz / (M R_ref^2) of the Izz row (set the uncertainties before sbtk.data.select_moi removes that row). Rows with other labels (sbtk.data.add_moi_row) keep their sigma. The values themselves do not change; sbtk.data.add_noise then draws noise from these uncertainties.

    For other uncertainties: sbtk.data.use_uncertainties (those of another data set), sbtk.data.set_covariance (a full coefficient covariance), sbtk.data.set_moi_sigma (inertia rows by label).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, interior.
    [exact, truth] = sbtk.data.simulate(body, interior, 4, "T1");
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);
obs = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact, unc), 1);

    Outputs

    NameDescription
    exactthe exact values as a measurement set (docs/data_formats.md), without uncertainties (coef_cov and every inertia sigma are NaN); for Didymos to degree 4: coef_labels 24 x 1 {'C10';'C11';'S11';'C20';...}, coef 24 x 1, moi 7 rows (Ixx Iyy Izz Ixy Ixz Iyz, I/(M R_ref^2); libration: (B - A)/C with principal moments, see sbtk.data.add_libration), origin_km the center of mass the coefficients are about [km] Fields: obs.
    truththe true model (rho_bg_kgm3, components, random_field, origin_km, exact values) Fields: truth.
    geogeometry about the center of mass (for plots and comparisons) Fields: geo.

    Description

    The gravity field and inertia are expanded about the center of mass. Layers and sectors are defined along rays from the expansion origin, so the interior, and with it the center of mass, depend on the origin: the geometry is rebuilt about the center of mass until it moves by less than 1 mm (sbtk.internal.fixed_point, at most 50 times; sbtk:iteration:notConverged otherwise). No measurement uncertainties are involved: the values are exact.

    To make measurements of the true model, give the exact values uncertainties (sbtk.data.set_uncertainties: one 1-sigma per degree and per inertia quantity; sbtk.data.use_uncertainties: those of another data set; sbtk.data.set_covariance, sbtk.data.set_moi_sigma) and draw noise from them (sbtk.data.add_noise).

    Errors when the density is negative anywhere.

    Example

    MATLAB, from the help text
    body = sbtk.body.from_mass("Didymos", sbtk.shape.bundled("didymos"), 5.273e11, 0.43);
interior = sbtk.interior.create(sbtk.interior.sphere("core", [0 0 0], 0.170, +450));
[exact, truth] = sbtk.data.simulate(body, interior, 4, "T1");          % the true model
unc = sbtk.data.uncertainties([sbtk.units.offset_to_degree1(0.002, 0.43), 1e-4, 2e-4, 4e-4], 2e-3, 0.02);

    sbtk.data.to_frame#

    A measurement set in another frame: x' = (x - origin_km) * axes.

    Syntax

    MATLAB
    obs = sbtk.data.to_frame(obs, origin_km, axes)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequireda measurement set; to change the axes it must have all six inertia elements without uncertainties, as the exact values of sbtk.data.simulate have (or no inertia rows): a measurement is made in the frame it is reported in, so transform the exact values, then give uncertainties, select and add noise Fields: obs.
    origin_km1 × 3doublekmrequiredorigin of the new frame in the current frame [km]; [0 0 0] keeps the origin Validation: mustBeFinite.
    axes3 × 3doublerequired3 x 3 rotation, columns: the new axes as unit vectors in the current frame, e.g. cf.axes of sbtk.gravity.center_of_mass_frame; eye(3) keeps the axes Validation: mustBeFinite.

    Outputs

    NameDescription
    obsa measurement set; to change the axes it must have all six inertia elements without uncertainties, as the exact values of sbtk.data.simulate have (or no inertia rows): a measurement is made in the frame it is reported in, so transform the exact values, then give uncertainties, select and add noise Fields: obs.

    Description

    origin_km becomes (origin_km - o)*axes and com_minus_cof_km becomes com_minus_cof_km*axes. The coefficients stay about the same point and are rotated degree by degree, with their covariance (exact, sbtk.internal.sh_rotation); every degree present must be complete. The inertia elements Ixx ... Iyz are recomputed as the elements in the new axes (axes'*I*axes); the libration row and libration_ratio use the new z-axis (C = Izz) and the principal axes in the new xy-plane; any other row keeps its meaning (its weights are transformed). A translation alone (axes = eye(3)) applies to any set. Use the same origin_km and axes for the body (sbtk.body.to_frame) and the interior or true model (sbtk.interior.to_frame).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: truth, body, exact, unc.
    spin    = sbtk.gravity.center_of_mass_frame(truth, body, "spin");
exact_s = sbtk.data.to_frame(exact, spin.com_km, spin.axes);      % C21 = S21 = 0
obs_s   = sbtk.data.add_noise(sbtk.data.set_uncertainties(exact_s, unc), 1);

    sbtk.data.use_uncertainties#

    Give measurements the coefficient uncertainties of another data set (e.g. a precision file).

    Syntax

    MATLAB
    obs = sbtk.data.use_uncertainties(obs, ref)

    Arguments

    NameSizeClassUnitDefaultDescription
    obs1 × 1structrequiredmeasurements whose uncertainties are replaced (usually exact values from sbtk.data.simulate, before sbtk.data.add_noise) Fields: obs.
    ref1 × 1structrequiredmeasurements holding the uncertainties to use, e.g. a precision file read with sbtk.exchange.read_shadr or sbtk.exchange.read_data Fields: ref.

    Outputs

    NameDescription
    obsmeasurements whose uncertainties are replaced (usually exact values from sbtk.data.simulate, before sbtk.data.add_noise) Fields: obs.

    Description

    Every coefficient of obs that ref also has takes ref's variances and covariances; the others (e.g. degree 1 if ref has none) keep theirs and become uncorrelated with them (exact values from sbtk.data.simulate have none: give them with sbtk.data.set_uncertainties first). If the reference radii differ, ref's covariance is converted to obs.R_ref_km first: a coefficient of degree l scales by (R_ref / R_obs)^l. Moment-of-inertia uncertainties are not changed (sbtk.data.set_moi_sigma sets them).

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, interior.
    shape = sbtk.shape.load("didymos_g_9309mm_spc_obj_0000n00000_v003.obj", "km");
prec  = sbtk.exchange.read_shadr("Didymos_gravity_fromRS.tab", "Didymos", shape, [0 0 0], 4);
[exact, truth] = sbtk.data.simulate(body, interior, 4, "didymos_T1");
exact = sbtk.data.use_uncertainties(exact, prec);      % every coefficient, degree 1 included
exact = sbtk.data.select_moi(exact, {});               % gravity only in this example
obs = sbtk.data.add_noise(exact, 1);
