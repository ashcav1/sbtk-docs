    sbtk.exchange.density_grid#

    Density of a model at the centers of a cubic grid inside the body.

    Syntax

    MATLAB
    grid = sbtk.exchange.density_grid(body, model, spacing_km)

    Arguments

    NameSizeClassUnitDefaultDescription
    body1 × 1structrequiredfrom sbtk.body.create Fields: body.
    model1 × 1structrequireda true model (sbtk.data.simulate) or a fit (sbtk.invert.run)
    spacing_kmscalardoublekmrequiredcell edge [km] Validation: mustBePositive.

    Outputs

    NameDescription
    gridThe density grid. Fields: grid.

    Description

    Cell centers lie at integer multiples of spacing_km along each axis of the shape-model frame, so grids with the same spacing coincide whoever makes them; cells whose center is inside the shape model are kept (tested along rays from the center of figure, so every model of a body has the same cells). The density is the model's density at the cell center (random field included).

    grid.spacing_km, grid.x_km (n x 3), grid.density_kgm3 (n x 1), grid.density_sigma_kgm3 (n x 1, zero here; sbtk.exchange.write_solution fills it from the fit's covariance), grid.member (n x ncomp: the cell center is inside component c)

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, truth.
    grid = sbtk.exchange.density_grid(body, truth, 0.020);                % 20 m cells
scatter3(grid.x_km(:,1), grid.x_km(:,2), grid.x_km(:,3), 4, grid.density_kgm3, 'filled');

    Related functions

    Mentioned in the help text
    sbtk.body.create, sbtk.data.simulate, sbtk.exchange.write_solution, sbtk.invert.run
    Calls
    sbtk.gravity.geometry
    Called by
    sbtk.exchange.write_model, sbtk.exchange.write_solution

    sbtk.exchange.locate#

    The exchange package of a given kind in a run folder.

    Syntax

    MATLAB
    folder = sbtk.exchange.locate(parent, kind)

    Arguments

    NameSizeClassUnitDefaultDescription
    parent1 × 1stringrequireda run folder (or any folder holding a package) Validation: mustBeFolder.
    kind1 × 1stringrequired"DATA" (measurement package, <team>-DATA<n>...), "MOD" (interior-model package, <team>-MOD<n>...) or "SOL" (solution package, <team>-SOL_...) Validation: mustBeMember(kind, ["DATA", "MOD", "SOL"]).

    Outputs

    NameDescription
    folderPath of the package folder.

    Description

    Looks in parent and in its redacted/ and unredacted/ subfolders (the layout of simulation runs) and returns the one package of that kind. Errors if there is none or more than one.

    Example

    MATLAB, from the help text
    run = sbtk.io.latest_run("hera_hlp6", "didymos_T1");
[obs, body] = sbtk.exchange.read_data(sbtk.exchange.locate(run, "DATA"));
model = sbtk.exchange.locate(run, "MOD");

    Related functions

    Mentioned in the help text
    sbtk.exchange.read_data, sbtk.io.latest_run

    sbtk.exchange.read_data#

    Measurements and body from a measurement package (sbtk.exchange.write_data format).

    Syntax

    MATLAB
    [obs, body] = sbtk.exchange.read_data(folder)

    Arguments

    NameSizeClassUnitDefaultDescription
    folder1 × 1stringrequiredthe package folder (README.txt, gravity_field.txt, gravity_covariance.txt, center_of_mass.txt, moments_of_inertia.txt, conventions.txt, shape model) Validation: mustBeFolder.

    Outputs

    NameDescription
    obsthe measurements, ready for sbtk.invert: coefficients of degree 2..L with their full covariance, expanded about the measured center of mass (obs.origin_km), plus degree-1 coefficients 0 +- sigma that carry the uncertainty of the center of mass, and the moment-of-inertia rows Fields: obs.
    bodyfrom the package's shape model (lengths in km), mass = GM / G and the package's reference radius Fields: body.

    Description

    A package of exact values (no 1-sigma columns, no gravity_covariance.txt) gives a set with NaN uncertainties: give it uncertainties (e.g. sbtk.data.use_uncertainties with the precision file of the test) before sbtk.invert.

    The libration ratio (B - A)/C becomes the row (B - A) - ratio*Izz = 0 with sigma ratio_sigma * Izz, where Izz is the measured Izz if the package has one, otherwise the Izz of the homogeneous body.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: components.
    [obs, body] = sbtk.exchange.read_data("CUB-DATA1-Didymos");
fit = sbtk.invert.solve(body, components, obs, sbtk.invert.options());

    Related functions

    Mentioned in the help text
    sbtk.data.use_uncertainties, sbtk.invert.options, sbtk.invert.solve
    Calls
    sbtk.body.from_mass, sbtk.data.add_libration, sbtk.data.add_moi, sbtk.gravity.geometry, sbtk.shape.load, sbtk.units.G
    Called by
    sbtk.exchange.write_data

    sbtk.exchange.read_shadr#

    Measurements and body from a gravity file in the PDS SHADR layout (e.g. other teams' .tab files).

    Syntax

    MATLAB
    [obs, body] = sbtk.exchange.read_shadr(file, body_name, shape, origin_km, degree)

    Arguments

    NameSizeClassUnitDefaultDescription
    file1 × 1stringrequiredtext file in the layout of the PDS Spherical Harmonic ASCII Data Record: a header row R_ref [km], GM [km^3/s^2], sigma GM, degree, order, normalization state (1 = fully normalized), reference longitude, latitude then one row per (l, m): l, m, C, S, sigma_C, sigma_S Values may be separated by commas or spaces; lines starting with '#' and lines that do not start with a number (column names) are skipped. Validation: mustBeFile.
    body_name1 × 1stringrequiredname of the body, e.g. "Didymos"
    shape1 × 1structrequiredfrom sbtk.shape.load: the shape model the field refers to Fields: shape.
    origin_km1 × 3doublekmrequiredpoint the coefficients are expanded about, in shape-model coordinates [km]: [0 0 0] if the field is about the shape-model origin (it then has degree-1 terms), the center of mass if it is about the center of mass Validation: mustBeFinite.
    degreescalardoublerequiredhighest degree to use Validation: mustBeInteger, mustBePositive.

    Outputs

    NameDescription
    obscoefficients of degree 1..degree present in the file, covariance diag(sigma^2) (the format has no correlations), mass = GM / G Fields: obs.
    bodysbtk.body.from_mass(body_name, shape, GM / G, R_ref of the file) Fields: body.

    Description

    A field about the center of mass has no degree-1 terms; add the measured center of mass with sbtk.data.add_center_of_mass.

    Example

    MATLAB, from the help text
    shape = sbtk.shape.load("didymos_g_9309mm_spc_obj_0000n00000_v003.obj", "km");
[obs, body] = sbtk.exchange.read_shadr("Didymos_gravity.tab", "Didymos", shape, [0 0 0], 4);

    Related functions

    Mentioned in the help text
    sbtk.body.from_mass, sbtk.data.add_center_of_mass, sbtk.shape.load
    Calls
    sbtk.body.from_mass, sbtk.data.from_coefficients, sbtk.data.select_coefficients, sbtk.units.G

    sbtk.exchange.write_data#

    Write a measurement package to send to other teams (nothing about the interior).

    Syntax

    MATLAB
    folder = sbtk.exchange.write_data(parent, data_set, body, obs, prepared_by)

    Arguments

    NameSizeClassUnitDefaultDescription
    parent1 × 1stringrequiredfolder in which the package folder is created
    data_set1 × 1stringrequiredpackage name, e.g. "CUB-DATA1-Didymos" (team - DATA<number> - comment)
    body1 × 1structrequiredfrom sbtk.body.create; its shape-model file is copied into the package Fields: body.
    obs1 × 1structrequiredthe measurements, with noise (sbtk.data.add_noise) and with degree-1 coefficients (the measured center of mass) Fields: obs.
    prepared_by1 × 1stringrequiredwho made the package, e.g. "CU Boulder (name, e-mail)"

    Outputs

    NameDescription
    folderPath of the package folder that was created.

    Description

    Creates <parent>/<data_set>/ with

    README.txtwhat the package contains and how to read it
    gravity_field.txtcoefficients of degree 2..L about the center of mass, 1-sigma
    gravity_covariance.txttheir full covariance
    center_of_mass.txtmeasured center of mass in the shape-model frame, covariance
    moments_of_inertia.txtinertia tensor elements and/or libration ratio, 1-sigma
    conventions.txtunits, frame, normalization (with code), relations
    <shape model>.obj the shape model (exact)

    Nothing else of obs is written: not the expansion origin of the simulation (the true center of mass), the noise seed or the notes. Format: docs/exchange_format.md; read back with sbtk.exchange.read_data.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: out, body, obs.
    sbtk.exchange.write_data(fullfile(out.folder, "redacted"), "CUB-DATA1-Didymos", body, obs, "CU Boulder");

    Related functions

    Mentioned in the help text
    sbtk.body.create, sbtk.data.add_noise, sbtk.exchange.read_data
    Calls
    sbtk.data.set_covariance, sbtk.data.set_moi_sigma, sbtk.data.set_uncertainties, sbtk.data.use_uncertainties, sbtk.exchange.read_data, sbtk.shape.properties

    sbtk.exchange.write_model#

    Write the interior-model package behind a measurement package (released after the solutions).

    Syntax

    MATLAB
    folder = sbtk.exchange.write_model(parent, model_set, data_set, body, truth, obs_exact, spacing_km, prepared_by)

    Arguments

    NameSizeClassUnitDefaultDescription
    parent1 × 1stringrequiredfolder in which the package folder is created
    model_set1 × 1stringrequiredpackage name, e.g. "CUB-MOD1-Didymos"
    data_set1 × 1stringrequiredname of the measurement package made from this model, e.g. "CUB-DATA1-Didymos"
    body1 × 1structrequiredfrom sbtk.body.create Fields: body.
    truth1 × 1structrequiredthe true model (sbtk.data.simulate) Fields: truth.
    obs_exact1 × 1structrequiredthe measurements without noise: the exact values of sbtk.data.simulate, with or without uncertainties (without, their 1-sigma are written as NaN)
    spacing_kmscalardoublekmrequiredcell edge of the density grid [km] Validation: mustBePositive.
    prepared_by1 × 1stringrequiredwho made the package

    Outputs

    NameDescription
    folderPath of the package folder that was created.

    Description

    Creates <parent>/<model_set>/ with

    README.txtwhat the package contains
    interior_model.txtbackground density and every component (type, densities, geometry), random density field, principal axes and moments of inertia
    density_grid.txttrue density at the centers of a cubic grid (sbtk.exchange.density_grid)
    noise_free_data/the measurements of data_set without noise, in the same files
    figures/3-D view and slices of the true density

    Compare a solution with it by sbtk.compare.grids on the two density grids.

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: out, body, truth, exact.
    % exact: the measurements before sbtk.data.add_noise
sbtk.exchange.write_model(fullfile(out.folder, "unredacted"), "CUB-MOD1-Didymos", "CUB-DATA1-Didymos", ...
                          body, truth, exact, 0.020, "CU Boulder");

    Related functions

    Mentioned in the help text
    sbtk.body.create, sbtk.compare.grids, sbtk.data.add_noise, sbtk.data.simulate, sbtk.exchange.density_grid
    Calls
    sbtk.compare.grids, sbtk.exchange.density_grid, sbtk.plot.interior3d, sbtk.plot.slices, sbtk.shape.properties

    sbtk.exchange.write_solution#

    Write an inversion result as a solution package for the other teams.

    Syntax

    MATLAB
    folder = sbtk.exchange.write_solution(parent, solution_set, body, fit, homogeneous, spacing_km, prepared_by)

    Arguments

    NameSizeClassUnitDefaultDescription
    parent1 × 1stringrequiredfolder in which the package folder is created
    solution_set1 × 1stringrequiredpackage name, e.g. "CUB-SOL_ROB1" (team - SOL_<data team><number>)
    body1 × 1structrequiredthe body used in the inversion Fields: body.
    fit1 × 1structrequiredfrom sbtk.invert.run (fit.data_name names the measurement package) Fields: fit.
    homogeneous1 × 1structrequiredfrom sbtk.invert.homogeneous (the same data fitted by a homogeneous body) Fields: fit.
    spacing_kmscalardoublekmrequiredcell edge of the density grid [km]; use the spacing of the interior-model package for a cell-by-cell comparison Validation: mustBePositive.
    prepared_by1 × 1stringrequiredwho made the solution

    Outputs

    NameDescription
    folderPath of the package folder that was created.

    Description

    Creates <parent>/<solution_set>/ with

    README.txtmethod, measurements used, chi-square test
    solution.txtbackground and component densities with 1-sigma, geometry
    solution_covariance.txtcovariance of the estimated parameters
    fitted_measurements.txtevery measurement used: measured, predicted, sigma, normalized residual
    density_grid.txtestimated density and its 1-sigma on the cubic grid
    figures/residuals, densities, 3-D view, slices

    Example

    MATLAB fragment from the help text. Uses variables defined by earlier calls: body, components, obs, out.
    prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
fit  = sbtk.invert.run(prob);
sbtk.exchange.write_solution(out.folder, sbtk.exchange.solution_name("CUB", obs.name), body, fit, ...
                             sbtk.invert.homogeneous(prob), 0.020, "CU Boulder");

    Related functions

    Mentioned in the help text
    sbtk.exchange.solution_name, sbtk.invert.homogeneous, sbtk.invert.options, sbtk.invert.run, sbtk.invert.setup
    Calls
    sbtk.exchange.density_grid, sbtk.plot.densities, sbtk.plot.interior3d, sbtk.plot.residuals, sbtk.plot.slices
