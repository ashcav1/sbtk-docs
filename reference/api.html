    API reference

    Last edited October 20, 2026

    The supported interface of SBTK: every function in the namespace packages below, generated from the help text and arguments block of its source file. Functions are called by their full name, sbtk.<package>.<function>. Arguments have no default values except where the Default column states one (three functions). Structures passed between functions are described in Data structures; error identifiers in Error identifiers. Helper functions in sbtk.internal are not part of the supported interface and are listed separately in Internal functions.

    sbtk.data.add_librationAdd a measured libration ratio (B - A)/C.
    sbtk.data.add_moiAdd one measured inertia element to a measurement set.
    sbtk.data.add_moi_rowAdd a measurement of any weighted sum of the inertia elements.
    sbtk.data.add_noiseOne noisy realization of a measurement set.
    sbtk.data.from_coefficientsMeasurement set from gravity-coefficient matrices (e.g. a mission solution).
    sbtk.data.libration_ratio_from_amplitude(B - A)/C from the forced libration of a synchronous satellite.
    sbtk.data.move_originExpress measurements about the center of mass relative to a new expansion origin.
    sbtk.data.select_coefficientsKeep only the listed gravity coefficients.
    sbtk.data.select_degreeKeep only the coefficients up to a degree.
    sbtk.data.select_moiKeep only the listed moment-of-inertia measurements.
    sbtk.data.set_covarianceReplace the coefficient covariance with a full matrix.
    sbtk.data.set_moi_sigmaSet the 1-sigma of moment-of-inertia measurements by label.
    sbtk.data.set_uncertaintiesGive measurements a 1-sigma uncertainty per degree and per inertia quantity.
    sbtk.data.simulateTrue model of an interior and its exact gravity coefficients and moments of inertia.
    sbtk.data.summaryPrint what is in a measurement set.
    sbtk.data.to_frameA measurement set in another frame: x' = (x - origin_km) * axes.
    sbtk.data.uncertainties1-sigma measurement uncertainties by degree and by inertia quantity, for sbtk.data.set_uncertainties.
    sbtk.data.use_uncertaintiesGive measurements the coefficient uncertainties of another data set (e.g. a precision file).

    sbtk.interior.sphereUniform sphere component (e.g. a core, a boulder or a void).

    sbtk.interior.to_frameAn interior or a true model in another frame: x' = (x - origin_km) * axes.
    sbtk.interior.torusUniform torus component about the z-axis, clipped to the body.

    sbtk.invert.runEstimate the densities for a prepared inversion (bounded, mass-constrained least squares).

    sbtk.invert.solveSetup and run in one call.
    sbtk.invert.summaryPrint an inversion result.

    sbtk.io.save_figureSave a figure as figures/<name>.png (200 dpi) in the run folder.

    sbtk.io.write_comparisonPlain-text copy of a comparison with the true model.
