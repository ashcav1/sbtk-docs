    Results folders and figures#

    Last edited October 20, 2026

    Run folders#

    sbtk.io.new_run(project, name) creates the folder results/<project>/<yyyy-mm-dd_HHMMSS>_<name>/ in the repository and starts recording everything printed in the Command Window to log.txt in it, until sbtk.io.finish_run closes the log. It returns an out structure, which every save and report function takes. A new run never overwrites an earlier one.

    • sbtk.io.latest_run(project, name) returns the newest folder whose name after the time stamp equals name exactly: "didymos_T1" does not match didymos_T1_inversion. Inversion scripts use it to find the newest simulation.
    • sbtk.io.subfolder(out, name) makes the save and report functions write into a subfolder while the log stays in the run folder. The Hera simulation runners use it to keep the true model apart from the data package (Hera blind test).
    MATLAB
    out = sbtk.io.new_run("my_project", "T1_inversion");     % results/my_project/<date_time>_T1_inversion/
prob = sbtk.invert.setup(body, components, obs, sbtk.invert.options());
sbtk.io.report_inversion(out, body, sbtk.invert.run(prob), sbtk.invert.homogeneous(prob));
sbtk.io.finish_run(out);

    This fragment requires body, components and obs as defined in the first script.

    Files#

    File Written by Contents Read with
    log.txt sbtk.io.new_run Everything printed during the run. a text editor
    settings.json sbtk.io.save_settings, called by the report functions Body, degree, uncertainties, components, random field, noise seed and inversion settings of the run. jsondecode(fileread(file))
    measurements.txt, .mat sbtk.io.save_measurements The measurement set (obs); the text has only the diagonal of the coefficient covariance. sbtk.io.load_measurements
    truth.txt, .mat sbtk.io.save_truth The true model of a simulation (truth). sbtk.io.load_truth
    fit.txt, .mat sbtk.io.save_fit Densities with 1σ, χ2 test, every residual (fit). sbtk.io.load_fit
    homogeneous.txt sbtk.io.report_inversion The same data fitted by a homogeneous body.
    comparison.txt, .mat sbtk.io.save_comparison R2, Rmax2, RMS error, per-component comparison (cmp). load
    figures/*.png sbtk.io.save_figure (200 dpi) The figures below.

    The report functions write a standard set in one call:

    Function Writes
    sbtk.io.report_simulation(out, body, obs, truth) measurements.*, truth.*, settings.json, figures/truth_3d.png, truth_slices.png, measurements.png
    sbtk.io.report_inversion(out, body, fit, homogeneous) fit.*, homogeneous.txt, settings.json, figures/residuals.png, densities.png, estimate_3d.png, estimate_slices.png
    sbtk.io.report_comparison(out, body, truth, fit, cmp) comparison.*, settings.json, figures/comparison.png, truth_vs_estimate.png

    Figures#

    Every plot function returns a figure handle. sbtk.io.save_figure(out, fig, name) saves it as figures/<name>.png at 200 dpi in a run folder; exportgraphics saves it anywhere. Densities are drawn with a sequential color map (dark blue to yellow); signed differences with blue for lower and red for higher density.

    The figures below come from one synthetic Didymos run, made by documentation/tools/make_samples.m: a core (+450 kg/m³) at the center of figure, an equatorial torus (−500) about the z-axis through it, a 12 m regolith layer (−900), a boulder of radius 40 m (+900) and a random field of 40 kg/m³ with a 60 m correlation length; measurements to degree 4 with the uncertainties of the first script; an inversion for core, torus and regolith (the boulder and the field are not in the inversion model). The fit has χ2/ν=1.08 (p=0.36), the homogeneous body χ2/ν=45.0; R2=0.93 with Rmax2=0.98.

    Shape model#

    sbtk.plot.shape(body): the mesh with its center of figure and axes.

    Interior in three dimensions#

    sbtk.plot.interior3d(body, model, title): the surface drawn translucent; spheres, ellipsoids and tori drawn where they lie inside the body, layers by their lower boundary; color is the relative density. Sectors are not drawn (use slices). Saved as truth_3d.png and estimate_3d.png by the report functions.

    Density slices#

    sbtk.plot.slices(body, {models}, {titles}): the density on the plane z=0 (left) and the plane y=0 (right), both through the first model's origin, one row per model with a common color scale. Saved as truth_slices.png and estimate_slices.png.

    Measurements#

    sbtk.plot.measurements(obs): left, the root-mean-square size of the coefficients of each degree (points) and of their 1σ uncertainties (line); degrees where the points lie well above the line carry information about the interior. Degree 1 is close to zero about the center of mass. Right, each inertia measurement with its 1σ. Saved as measurements.png.

    Normalized residuals#

    sbtk.plot.residuals(fit): (predicted − measured)/σ for every measurement; gray band ±1σ, dashed lines ±2σ. Saved as residuals.png.

    Estimated densities#

    sbtk.plot.densities(fit): the density of the background and each component with its ±1σ interval; the dashed line is the background. Components whose relative density is smaller than its 1σ are drawn in gray. Saved as densities.png.

    Comparison with the true model#

    sbtk.plot.comparison(cmp): left, R2 of the estimate and Rmax2; right, each component's estimate with ±1σ and its true density (cross). Saved as comparison.png.

    sbtk.plot.truth_vs_estimate(body, truth, fit): rows for the true density, the estimate (same color scale) and their difference, on the two planes through the true center of mass. Saved as truth_vs_estimate.png.

    Difference from the homogeneous body#

    sbtk.plot.difference_from_homogeneous(body, sets, names, scale, frame): for each set of gravity coefficients (a measurement set, a true model or an inversion result), the coefficients minus those of the homogeneous body (density M/V), both about their own center of mass, as radio-science fields are. Degree 1 shows the set's center of mass minus the center of figure. A measurement set about another point (for example a field about the shape-model origin) is first moved to its center of mass by the exact translation of solid harmonics. Zonal coefficients are shown as Jl=−C¯l0. With scale = "linear" the signed difference has ±3σ bars for sets with uncertainties; with "log" the absolute difference is drawn with 3σ as a separate line, which shows which departures from a uniform density the measurements resolve. With frame = "shape" both fields are in the shape-model axes; with "spin" in the spin axes of the set (z along its axis of the largest moment), where the set's C¯21, S¯21 vanish; with "principal" in its principal axes, where also S¯22 vanishes. The differences in the vanishing terms are the homogeneous body's own terms in those axes: they measure how far the principal axes of the interior are tilted and turned from those of the homogeneous body (Frames of a gravity field). Not saved by the report functions; save it with sbtk.io.save_figure.
