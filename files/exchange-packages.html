    Exchange packages#

    Exchange packages carry measurements, interior models and solutions between teams, for example in a blind test where one team simulates measurements of an interior it keeps hidden and other teams invert them. They are plain text with the units, frame and normalization written in them, and can be read without SBTK.

    Package Name Written by Contents Released
    Measurements <team>-DATA<n>-<comment> sbtk.exchange.write_data Gravity field, covariance, center of mass, moments of inertia, shape model with the data set
    Interior model <team>-MOD<n>-<comment> sbtk.exchange.write_model True model, density grid, noise-free measurements, figures after the solutions
    Solution <team>-SOL_<data team><n> sbtk.exchange.write_solution Estimated densities, covariance, fitted measurements, density grid, figures with the solution

    sbtk.exchange.solution_name forms solution names; sbtk.exchange.locate finds the package of a given kind in a run folder and its redacted/ and unredacted/ subfolders.

    File layout#

    Each file starts with metadata lines # key: value, followed by one line of column names and comma-separated rows. Every column and key with a unit ends with it; NaN marks a value that is not provided.

    Reader Statement
    MATLAB T = readtable('gravity_field.txt', 'FileType', 'text', 'CommentStyle', '#');
    Python with pandas T = pandas.read_csv('gravity_field.txt', comment='#')
    Python, standard library rows = list(csv.DictReader(l for l in open('gravity_field.txt') if not l.startswith('#')))
    SBTK sbtk.exchange.read_data(folder), sbtk.exchange.read_grid(file)

    Measurement package#

    File Contents
    README.txt Summary: GM, bulk density, degree, reference radius, inertia quantities, noise.
    gravity_field.txt l,m,C,S,sigma_C,sigma_S for degrees 2 and higher, fully normalized, about the center of mass.
    gravity_covariance.txt Full covariance of those coefficients; rows and columns labeled.
    center_of_mass.txt Measured center of mass in the shape-model frame with its 3 × 3 covariance, and the center of figure.
    moments_of_inertia.txt quantity,value,sigma,unit: inertia elements as I/(MRref2) about the center of mass and/or the libration ratio.
    conventions.txt Units, frame, normalization (with MATLAB and Python code), relations between the quantities.
    <shape>.obj The shape model the data were made with, in km, in the frame of every position of the package. For a package in another frame than the original shape-model file (spin or principal axes, sbtk.body.to_frame), the transformed model, named after its frame; conventions.txt states the transformation from the original file.

    The gravity field is expanded about the center of mass, as a radio-science solution is, so it has no degree-1 terms; the position of the center of mass is a separate measurement in center_of_mass.txt. The package contains nothing about the interior: not the expansion origin of the simulation (the true center of mass), the noise seed, the model name or any component; testNothingAboutTheInterior checks this (Validation).

    sbtk.exchange.read_data returns the measurement set with coef_about = 'center_of_mass': the coefficients of degree ≥ 2 with their covariance, degree-1 coefficients 0 ± σ that carry the uncertainty of the center of mass, the inertia rows, and the body built from the package's shape model and GM. A libration ratio becomes the row (B−A)−kIzz=0 with σ = σkIzz, using the measured Izz if the package has one and that of a homogeneous body otherwise.

    Packages of exact values#

    A set without any uncertainties, such as the exact values of a true model (sbtk.data.simulate), is written as a package of exact values:

    • gravity_field.txt has the columns l,m,C,S, center_of_mass.txt the columns axis,center_of_mass_km,center_of_figure_km, and moments_of_inertia.txt the columns quantity,value,unit;
    • there is no gravity_covariance.txt;
    • the uncertainties metadata and the README say that none are given, and no noise was added.

    In a blind test the makers send such packages, and each receiving team applies uncertainties of its own choosing. sbtk.exchange.read_data reads them with NaN uncertainties. The inversion then stops with sbtk:data:noUncertainties until uncertainties are given, for example with sbtk.data.use_uncertainties from a precision file and sbtk.data.set_moi_sigma, after truncating with sbtk.data.select_degree to the degrees the precision covers. A set with some uncertainties but not all is not written (sbtk:data:noUncertainties).

    Density grid#

    Cell centers lie at integer multiples of spacing_km along each axis of the shape-model frame, so grids of the same spacing coincide regardless of who made them. A cell is listed when its center is inside the shape model, tested along rays from the center of figure, so all models of a body have the same cells. Each cell stands for the volume spacing_km³ and carries the density at its center. sbtk.compare.grids compares two grids (Comparison of density grids); the comparison of the example solution with its model:

    conventions.txt#

    Every measurement package includes this file, written by sbtk.internal.exchange_conventions. The tests check the relations it states and the normalization code it prints.

    Output
    SBTK exchange format: conventions
=================================

UNITS
  Lengths and positions in km, mass in kg, time in s, GM in km^3/s^2, densities in kg/m^3,
  angles in degrees. Every column and key name that has a unit ends with it (x_km,
  density_kgm3, GM_km3_s2); names without a unit are dimensionless. All uncertainties are
  1-sigma. NaN marks a value that is not provided.

FILES
  Lines that start with '# ' are metadata ('# key: value'). The first other line names the
  columns; every following line is one row of comma-separated values.
    MATLAB   T = readtable('gravity_field.txt', 'FileType', 'text', 'CommentStyle', '#');
    Python   T = pandas.read_csv('gravity_field.txt', comment='#')
    Python, standard library only
      rows = list(csv.DictReader(l for l in open('gravity_field.txt') if not l.startswith('#')))

FRAME
  Every position is in the frame of the shape-model file of the data package: its origin
  and its axes, lengths in km. The origin of a shape-model file is in general neither the
  center of mass nor the center of figure; both are given in center_of_mass.txt.
  Latitude is measured from the xy-plane toward +z; longitude from +x toward +y.
  Center of figure = centroid of the shape model's volume (the center of mass of a
  homogeneous body).

GRAVITY FIELD
  U(r, lat, lon) = GM/r * sum_{l=0..L} (R/r)^l * sum_{m=0..l} Pbar_lm(sin lat) *
                   [ Cbar_lm cos(m lon) + Sbar_lm sin(m lon) ]
  U > 0 and the gravitational acceleration is +grad U. R = reference_radius_km. r, lat and
  lon are measured from the expansion origin, which is the center of mass, with axes
  parallel to the shape-model axes. Cbar_00 = 1.
  For a density rho(x) with total mass M, the unnormalized coefficients are
    C_lm = (2 - delta_m0)/M * (l-m)!/(l+m)! * integral rho (r/R)^l P_lm(sin lat) cos(m lon) dV
    S_lm = (2 - delta_m0)/M * (l-m)!/(l+m)! * integral rho (r/R)^l P_lm(sin lat) sin(m lon) dV

NORMALIZATION
  The files give fully normalized coefficients (the 4-pi normalization of geodesy):
    Cbar_lm = C_lm / N_lm,   Sbar_lm = S_lm / N_lm,   Pbar_lm = N_lm P_lm,
    N_lm = sqrt( (2 - delta_m0) (2l + 1) (l - m)! / (l + m)! )
  so that the mean of [Pbar_lm(sin lat) cos(m lon)]^2 over the sphere is 1.
  P_lm(x) = (1 - x^2)^(m/2) d^m/dx^m P_l(x), without the Condon-Shortley phase (-1)^m.
  N_20 = sqrt(5), N_21 = sqrt(5/3), N_22 = sqrt(5/12), N_30 = sqrt(7).
  Zonal coefficients: J_l = -C_l0 = -sqrt(2l + 1) Cbar_l0.

  MATLAB
    function N = sh_normalization(l, m)
    % Unnormalized = N .* normalized (the same factor for C and S); l, m may be arrays.
    N = sqrt((2 - (m == 0)) .* (2*l + 1) .* factorial(l - m) ./ factorial(l + m));
    end
    % C_unnormalized = sh_normalization(l, m) .* C_normalized
    % C_normalized   = C_unnormalized ./ sh_normalization(l, m)

  Python
    from math import factorial, sqrt
    def sh_normalization(l, m):
        # unnormalized = N * normalized (the same factor for C and S)
        return sqrt((2 - (m == 0)) * (2*l + 1) * factorial(l - m) / factorial(l + m))

  Changing the reference radius from R to R': Cbar'_lm = Cbar_lm (R/R')^l.

DEGREE 1 AND THE CENTER OF MASS
  For coefficients expanded about a point O, with (xc, yc, zc) = center of mass - O,
    Cbar_10 = zc / (sqrt(3) R),   Cbar_11 = xc / (sqrt(3) R),   Sbar_11 = yc / (sqrt(3) R).
  The gravity fields here are expanded about the center of mass, so these are zero and are
  not listed. The position of the center of mass in the shape-model frame is a separate
  measurement (center_of_mass.txt).

MOMENTS OF INERTIA
  Inertia tensor about the center of mass, shape-model axes:
    I_ij = integral rho (r^2 delta_ij - x_i x_j) dV
  so the off-diagonal elements carry the minus sign (Ixy = -integral rho x y dV).
  Values are given as I / (M R^2), dimensionless; multiply by MR2_kg_m2 for kg m^2.
  Libration ratio = (B - A) / C: A <= B are the principal moments about the axes in the
  xy-plane, C = Izz (z, the spin axis, taken as a principal axis). The principal axes need
  not be the shape-model axes: B - A = sqrt((Iyy - Ixx)^2 + 4 Ixy^2) = 4 M R^2 sqrt(C_22^2 + S_22^2).
  Relation to the degree-2 coefficients (both about the center of mass, same axes, same R):
    C_20 = (Ixx + Iyy - 2 Izz) / (2 M R^2)     Cbar_20 = C_20 / sqrt(5)
    C_21 = -Ixz / (M R^2)                       Cbar_21 = C_21 / sqrt(5/3)
    S_21 = -Iyz / (M R^2)                       Sbar_21 = S_21 / sqrt(5/3)
    C_22 = (Iyy - Ixx) / (4 M R^2)              Cbar_22 = C_22 / sqrt(5/12)
    S_22 = -Ixy / (2 M R^2)                     Sbar_22 = S_22 / sqrt(5/12)
  The degree-2 field fixes five combinations of the six tensor elements. The trace (for
  example through the polar moment Izz) is the information the moments of inertia add.

DENSITY GRID (interior model and solution packages)
  Density at the centers of cubic cells with edge spacing_km. Cell centers lie at integer
  multiples of spacing_km along each axis of the shape-model frame, so grids with the same
  spacing coincide; only cells whose center is inside the shape model are listed. Each
  cell stands for a volume spacing_km^3. density_sigma_kgm3 is the 1-sigma uncertainty of
  the density (0 for a true model).
