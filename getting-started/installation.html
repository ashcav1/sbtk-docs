    Installation#

    Last edited October 19, 2026

    Requirements#

    • MATLAB R2024b or newer. SBTK 1.0.0 is tested with R2025a.
    • Optimization Toolbox, for lsqlin in the inversion.
    • A compiled copy of the polyhedral gravity kernel ComputePolyhedralCSBar_mex for the platform. Binaries for macOS on Apple silicon (.mexmaca64) and Intel (.mexmaci64) are included; on other platforms it must be compiled once (below).

    No other toolboxes or external libraries are used.

    Repository layout#

    Folder Contents
    toolbox/+sbtk/ The toolkit: one function per file, one folder per package (+units, +shape, …).
    sbtk_setup.m Adds toolbox/ to the MATLAB path for the current session.
    data/shapes/ Shape models in OBJ format, lengths in km.
    data/gravity/ The OSIRIS-REx gravity field of Bennu (JPL, 2019).
    examples/ Eight tutorial scripts, ex01_quick_start.m … ex08_moments_of_inertia.m (Tutorial scripts).
    projects/ Runner scripts for the project template, Bennu and the Hera blind test (Projects).
    results/ Output of every run, created on demand (Results folders).
    tests/ Unit and integration tests, longer studies and test reports (Validation).
    tools/ Maintenance scripts (reduced shape models, benchmark, README figures).
    docs/ Notes in Markdown and earlier documents.

    Setting the path#

    Scripts in examples/ and projects/ add toolbox/ to the path themselves, so they can be run directly, also section by section. For the Command Window or other scripts, run sbtk_setup.m once per MATLAB session:

    MATLAB
    run("/path/to/SBTK/sbtk_setup.m")     % replace /path/to/SBTK with the location of the repository

    It prints the version and the repository folder. sbtk.version and sbtk.root return them.

    Runner scripts locate themselves with fileparts(which('<script name>')) rather than mfilename, because under Run Section MATLAB executes a temporary copy of the script. A copied runner must have the name inside which changed to its own file name.

    Compiling the gravity kernel#

    On platforms without a compiled kernel, with a C compiler configured for MATLAB (mex -setup C):

    MATLAB
    cd(fullfile(sbtk.root, "toolbox", "+sbtk", "+internal"))
mex -O ComputePolyhedralCSBar_mex.c

    Then run the tests; the regression test compares the kernel output with stored values.

    Files that are not in the repository#

    File Needed by Source
    data/shapes/g_01165mm_spc_obj_didy_0000n00000_v003.obj (Didymos, 1.165 m sampling, about 160 MB) sbtk.shape.bundled("didymos_highres"), tools/make_reduced_shapes.m, examples/ex01_quick_start.m DART shape models on ESA's SPICE server, spiftp.esac.esa.int/data/SPICE/HERA/kernels/dsk/
    data/shapes/g_00243mm_spc_obj_dimo_0000n00000_v004.obj (Dimorphos, 0.243 m, about 160 MB) sbtk.shape.bundled("dimorphos_highres"), tools/make_reduced_shapes.m same
    Uncertainty files of the Hera end-to-end test the simulation runners of projects/hera_hlp6 Hera working group; not distributed (Hera blind test)

    All other shape models used in the examples and tests are in data/shapes/.

    Checking the installation#

    MATLAB
    run(fullfile(sbtk.root, "tests", "run_tests.m"))

    This runs 129 unit and integration tests in about three minutes and writes tests/reports/test_report.txt. Every test should pass (Validation).
