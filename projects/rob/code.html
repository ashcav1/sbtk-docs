    Code of the ROB solutions#

    Last edited October 30, 2026

    Every solution on these pages is made by its own script in projects/hera_hlp6/rob/: for each package, one runner per kind of solution and one script for the figures and tables of its page. Change a model or an option in a runner and run it again; the figure script reads the newest run of each runner.

    Script What it does Run folder in results/hera_hlp6/
    rob<n>_components.m fits the model with components chosen for the package; the header says why <date_time>_ROB-DATA<n>_components
    rob<n>_sectors.m fits a sector grid with the Tikhonov parameter of the lowest AIC <date_time>_ROB-DATA<n>_sectors
    rob<n>_point_masses.m fits about 2,700 point masses with the Tikhonov parameter of the lowest AIC; weighting is "sensitivity" or "equal" <date_time>_ROB-DATA<n>_point_masses_<weighting>
    rob<n>_figures.m the figures and tables of the page, one section per figure <date_time>_ROB-DATA<n>_figures

    Run them in this order: the point masses (once with each weighting), the sector grid, the model with components (rob2_components.m starts from the point masses), the figures. The Didymos runners take seconds to a few minutes. Each Dimorphos runner adds the GRASS surface point: about a minute for the model with components and the sector grid, up to half an hour for the point masses.

    The runners share a few functions in the same folder:

    Function What it does
    rob_package(number) reads ROB-DATA<number> with the Hera radio-science uncertainties: degrees 1 to 5 for Didymos, 1 to 3 for Dimorphos, and Ixx,Iyy,Izz, on the 49,152-facet shape model; and ROB's exact values to degree 10
    rob_solution(name, kind, result) a fit or point masses in the form the figures read: the model, χ², the number of parameters, AIC, p
    rob_load(number, run) the solution of the newest run of a runner
    rob_grass(number, body_full, model) the acceleration a model predicts at the GRASS surface point, against ROB's
    rob_reproduced(a, exact, degrees) the fraction of ROB's exact anomaly a solution reproduces
    rob_tables(...), rob_grass_table(...) the Markdown tables of a page

    Every runner has the same sections. DATA reads the package. MODEL is the interior that is fitted. OPTIONS are those of sbtk.invert.options. RUN fits, reports in a new run folder and saves solution.mat. For Dimorphos, SURFACE POINT predicts the GRASS acceleration.

    The models with components#

    Each package has its own model, chosen by reading the coefficients and ranked against the other candidates by AIC (see How the models were chosen).

    MATLAB script: projects/hera_hlp6/rob/data1/rob1_components.m
    %% ROB1_COMPONENTS  ROB-DATA1 (Didymos): a light column along the spin axis and two dense equatorial ellipsoids.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA1): J2 is
% higher and C22, S22 say mass has moved from the spin axis toward the two ends of one
% equatorial axis, at longitudes about -20 and 160 deg; degree 1 says the 160 deg end is
% heavier. A light column (a prolate ellipsoid about the spin axis through the center of figure)
% takes mass from along the axis; a dense ellipsoid at each end of the equatorial axis puts it
% there. Of the models tried (rob_candidates.m, ranked by analyze_rob.m) this one has the
% lowest AIC. Fits the background density, the three relative densities and the centers of
% the two ellipsoids to the coefficients of degrees 1-5 and Ixx, Iyy, Izz.
% Writes results/hera_hlp6/<date_time>_ROB-DATA1_components/: solution.mat (read by
% rob1_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 1;                                                % ROB-DATA1
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
cof = body.centroid_km;                                    % positions are from the center of figure
rm  = (3*body.volume_km3/(4*pi))^(1/3);                    % mean radius [km]
u   = [cosd(-20) sind(-20) 0];                             % the equatorial axis of degree 2
column = sbtk.interior.ellipsoid("column", cof, [0.25 0.25 0.70]*rm, [0 0 0], 0);
east   = sbtk.interior.ellipsoid("east", cof + 0.6*rm*u, [0.35 0.20 0.20]*rm, [-20 0 0], 0);
west   = sbtk.interior.ellipsoid("west", cof - 0.6*rm*u, [0.35 0.20 0.20]*rm, [160 0 0], 0);
east.estimate_position = true;
west.estimate_position = true;
components = [column east west];

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too

%% RUN
out  = sbtk.io.new_run("hera_hlp6", sprintf("ROB-DATA%d_components", number));
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("light column along the spin axis, two equatorial ellipsoids", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

save(fullfile(out.folder, "solution.mat"), 'solution');
sbtk.io.finish_run(out);
    MATLAB script: projects/hera_hlp6/rob/data2/rob2_components.m
    %% ROB2_COMPONENTS  ROB-DATA2 (Didymos): a dense and a light sphere, and compact masses where the measurements ask for them.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA2): the center
% of mass is 2.3 m off center toward the south, degree 2 is tilted 58 deg from the equator and
% degree 3 is large. No model of a core, a torus and a layer fits (rob_candidates.m,
% analyze_rob.m). The point masses (rob2_point_masses.m: run it first) put the excess below the
% equator toward -x and -y and the deficit toward +y and the north. This model starts a dense
% and a light sphere at the centroids of the point masses' positive and negative mass and fits
% their densities and centers; then compact masses (spheres of a quarter of the mean radius,
% from a grid of candidate positions) are added one at a time while each passes the
% likelihood-ratio test at the 5% level, every position refitted each time (sbtk.search.run).
% Of the models tried this one has the lowest AIC. Fitted to the coefficients of degrees 1-5
% and Ixx, Iyy, Izz. A few minutes.
% Writes results/hera_hlp6/<date_time>_ROB-DATA2_components/: solution.mat (read by
% rob2_figures.m), search.txt, fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 2;                                                % ROB-DATA2
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
rm = (3*body.volume_km3/(4*pi))^(1/3);                     % mean radius [km]
r  = load(fullfile(sbtk.io.latest_run("hera_hlp6", sprintf("ROB-DATA%d_point_masses_sensitivity", number)), ...
                   "point_masses.mat"));                   % where the point masses put the mass
dense = sbtk.interior.sphere("dense", r.pm.positive_centroid_km, 0.30*rm, 0);
light = sbtk.interior.sphere("light", r.pm.negative_centroid_km, 0.30*rm, 0);
dense.estimate_position = true;
light.estimate_position = true;
components = [dense light];
candidates = sbtk.interior.sphere_grid(body, rm/4, rm/4);  % compact masses: every quarter of the radius

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too
settings = sbtk.search.settings(keep=1, max_masses=6, mass_starts=3);
params = struct([]);                                       % no geometry searched on a grid

%% RUN
out = sbtk.io.new_run("hera_hlp6", sprintf("ROB-DATA%d_components", number));
sr  = sbtk.search.run(body, components, obs, opts, params, candidates, settings);
fit = sr.best_fit;
writelines(formattedDisplayText(sr.log, 'SuppressMarkup', true), fullfile(out.folder, "search.txt"));
sbtk.io.report_inversion(out, body, fit, sbtk.invert.homogeneous(sbtk.invert.setup(body, components, obs, opts)));
solution = rob_solution(sprintf("dense and light spheres, %d compact masses", sr.masses.n_masses), "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);
save(fullfile(out.folder, "solution.mat"), 'solution');
sbtk.io.finish_run(out);
    MATLAB script: projects/hera_hlp6/rob/data3/rob3_components.m
    %% ROB3_COMPONENTS  ROB-DATA3 (Didymos): a dense core, a light thick torus about the spin axis and a dense surface layer.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA3): J2 is 570
% sigma lower and J4 95 sigma higher than at constant density, and little else changes: a light
% ring about the spin axis, mass moved out of the equatorial plane. The torus is large and
% thick: of the four ring and tube radii tried (1.00 or 1.05, 0.25 or 0.30 of the mean radius;
% rob_candidates.m, ranked by analyze_rob.m) this one has the lowest AIC. The core is placed
% by its chi-square profile along the center-of-mass offset, then fitted with the densities.
% Fits the background density, the three relative densities and the core's center to the
% coefficients of degrees 1-5 and Ixx, Iyy, Izz.
% Writes results/hera_hlp6/<date_time>_ROB-DATA3_components/: solution.mat (read by
% rob3_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 3;                                                % ROB-DATA3
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
cof = body.centroid_km;                                    % positions are from the center of figure
rm  = (3*body.volume_km3/(4*pi))^(1/3);                    % mean radius [km]
core  = sbtk.interior.sphere("core", cof, 0.40*rm, 0);
core.estimate_position = true;
torus = sbtk.interior.torus("torus", 1.05*rm, 0.30*rm, 0, 0);   % about the z-axis
torus.center_km = cof;
layer = sbtk.interior.layer("regolith", 0, 0.03*rm, 0);        % from the surface to 3% of the radius deep
components = [core torus layer];

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too

%% RUN
out  = sbtk.io.new_run("hera_hlp6", sprintf("ROB-DATA%d_components", number));
% 1. Place the core: chi-square along the measured center-of-mass offset, the rest of the
%    geometry fixed (sbtk.invert.scan_position), from -0.4 to 0.4 mean radii of the center.
an = sbtk.interpret.anomaly(obs, body, obs.degree);
u  = an.com_offset_km/norm(an.com_offset_km);
fixed = components;
[fixed.estimate_position] = deal(false);
scan = sbtk.invert.scan_position(sbtk.invert.setup(body, fixed, obs, opts), "core", cof + (-0.40:0.025:0.40)'*rm*u);
components(1).center_km = scan.centers_km(scan.best, :);
% 2. Fit the densities and the core's position from there (Gauss-Newton).
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("core, torus, layer", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

save(fullfile(out.folder, "solution.mat"), 'solution');
sbtk.io.finish_run(out);

%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA6): all three
% moments of inertia are 30 to 60 sigma larger than at constant density (light inside, dense
% outside), C22 is 97 sigma lower (mass toward the ends of the y-axis), J2 79 sigma higher, and

%    geometry fixed (sbtk.invert.scan_position), from -0.4 to 0.4 mean radii of the center.
an = sbtk.interpret.anomaly(obs, body, obs.degree);
u  = an.com_offset_km/norm(an.com_offset_km);
fixed = components;
[fixed.estimate_position] = deal(false);
scan = sbtk.invert.scan_position(sbtk.invert.setup(body, fixed, obs, opts), "core", cof + (-0.40:0.025:0.40)'*rm*u);
components(1).center_km = scan.centers_km(scan.best, :);
% 2. Fit the densities and the core's position from there (Gauss-Newton).
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("core, torus, layer", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

%% SURFACE POINT
% The acceleration the model predicts at the GRASS point, on the full-resolution shape model.
solution.grass = rob_grass(number, body_full, fit);
fprintf('GRASS: acceleration %+.1f%% of ROB''s, %.1f deg from it\n', solution.grass.error_percent, solution.grass.angle_deg);

save(fullfile(out.folder, "solution.mat"), 'solution');
sbtk.io.finish_run(out);

    How the models were chosen#

    projects/hera_hlp6/analyze_rob.m fits every candidate of rob_candidates.m to a package, two searches of the geometry (sbtk.search.run) and the point masses, and ranks them all by the Akaike information criterion, AIC = χ² + 2 × the number of parameters. A regularized fit counts its effective number of parameters; a search counts each size it chose on its grid as well as the densities and positions it estimated. The model of each kind with the lowest AIC is the one its runner fits. To try another model, copy a component runner, change MODEL, and compare the AIC it prints with the others (Testing with ROB data).
