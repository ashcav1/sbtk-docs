    Code of the ROB solutions#

    Last edited November 3, 2026

    Every solution on these pages is made by its own script in projects/hera_hlp6/rob/: for each package, one runner per kind of solution and one script for the figures and tables that compare them. Change a model or an option in a runner and run it again: its folder is replaced, the run before moves to history/, and the figure script reads the newest of each.

    Script What it does Folder in results/hera_hlp6/finder/ROB-DATA<n>/
    rob<n>_components.m fits the model with components chosen for the package; the header says why components/
    rob<n>_sectors.m fits sectors with the Tikhonov parameter of the lowest AIC sectors/
    rob<n>_point_masses.m fits about 2,700 point masses with the Tikhonov parameter of the lowest AIC; weighting is "sensitivity" or "equal" point_masses_<weighting>/
    rob<n>_figures.m what the measurements show, and the solutions side by side, one section per figure data/, compared/

    Every plot and text file of a package is in that one folder:

    Where What
    summary.txt the solutions side by side: parameters, reduced χ², p, AIC and the tests; finder/summary.txt has every package
    data/ before any solution: reading.txt, geometry.txt, and in figures/ the measured coefficients against constant density (measured.png), each degree as a map (anomaly_map.png, anomaly_map_exact.png), significance.png, degree_ratio.png
    components/, sectors/, point_masses_<weighting>/ one solution: solution.txt and in figures/ against_measurements.png, residuals.png, exact.png, with densities.png, estimate_3d.png, estimate_slices.png for fits, point_masses.png for point masses and contributions.png for the model with components
    compared/ the solutions together: in figures/ against_measurements.png, density_cuts.png, exact.png, and the tables in tables/
    analysis/ the ranking of every candidate model (models.txt), from analyze_rob.m
    history/ the earlier runs, dated

    Run them in this order: the point masses (once with each weighting), the sectors, the model with components, the figures. The Didymos runners take seconds to a few minutes. Each Dimorphos runner adds the GRASS surface point: about a minute for the model with components and the sectors, up to half an hour for the point masses.

    The runners share a few functions in the same folder:

    Function What it does
    rob_package(number) reads ROB-DATA<number> with the Hera radio-science uncertainties: degrees 1 to 5 for Didymos, 1 to 3 for Dimorphos, and Ixx,Iyy,Izz, on the 49,152-facet shape model; and ROB's exact values to degree 10
    rob_solution(name, kind, result) a fit or point masses in the form the figures read: the model, χ², the number of parameters, AIC, p
    rob_load(number, run) the newest solution of a runner
    rob_finish(out, number, run, solution) the last step of every runner: the tests, solution.txt, summary.txt, the end of the log
    rob_present(...) the tests on what a solution was not fitted to: figures/exact.png, contributions.png and the end of solution.txt
    rob_summary(number) summary.txt of the package and of all packages
    rob_data_report(number) the folder data/: what the measurements show, before any solution
    rob_replot(number) every figure and text of the saved solutions again, without fitting: for when a plot changes
    rob_update_documentation(number) copies what a page shows into documentation/figures/rob/
    rob_grass(number, body_full, model) the acceleration a model predicts at the GRASS surface point, against ROB's
    rob_reproduced(a, exact, degrees) the fraction of ROB's exact anomaly a solution reproduces
    rob_tables(...), rob_grass_table(...) the Markdown tables of a page

    Every runner has the same sections. DATA reads the package. MODEL is the interior that is fitted. OPTIONS are those of sbtk.invert.options. RUN fits and reports in the solution's folder (sbtk.io.solution_run). For Dimorphos, SURFACE POINT predicts the GRASS acceleration. The last line, rob_finish, adds the tests and updates summary.txt, so every run leaves all its plots and text in place.

    The models with components#

    Each package has its own model, chosen by reading the coefficients and ranked against the other candidates by AIC (see How the models were chosen).

    MATLAB script: projects/hera_hlp6/rob/data1/rob1_components.m
    %% ROB1_COMPONENTS  ROB-DATA1 (Didymos): a light column along the spin axis and two dense equatorial ellipsoids.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA1): J2 is
% higher and C22, S22 say mass has moved from the spin axis toward the two ends of one
% equatorial axis, at longitudes about -20 and 160 deg; degree 1 says the 160 deg end is
% heavier. A light column (a prolate ellipsoid about the spin axis through the center of figure)
% takes mass from along the axis; a dense ellipsoid at each end of the equatorial axis puts it
% there. Of the models tried (rob_candidates.m, ranked by analyze_rob.m) this one has the
% lowest AIC. Fits the background density, the three relative densities and the centers of
% the two ellipsoids to the coefficients of degrees 1-5 and Ixx, Iyy, Izz.
% Writes results/hera_hlp6/finder/ROB-DATA1/components/: solution.txt, solution.mat (read by
% rob1_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/. The run
% before moves to history/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 1;                                                % ROB-DATA1
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
cof = body.centroid_km;                                    % positions are from the center of figure
rm  = (3*body.volume_km3/(4*pi))^(1/3);                    % mean radius [km]
u   = [cosd(-20) sind(-20) 0];                             % the equatorial axis of degree 2
column = sbtk.interior.ellipsoid("column", cof, [0.25 0.25 0.70]*rm, [0 0 0], 0);
east   = sbtk.interior.ellipsoid("east", cof + 0.6*rm*u, [0.35 0.20 0.20]*rm, [-20 0 0], 0);
west   = sbtk.interior.ellipsoid("west", cof - 0.6*rm*u, [0.35 0.20 0.20]*rm, [160 0 0], 0);
east.estimate_position = true;
west.estimate_position = true;
components = [column east west];

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too

%% RUN
out  = sbtk.io.solution_run("hera_hlp6", sprintf("ROB-DATA%d", number), "components");
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, obs, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("light column along the spin axis, two equatorial ellipsoids", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

rob_finish(out, number, "components", solution);
    MATLAB script: projects/hera_hlp6/rob/data2/rob2_components.m
    %% ROB2_COMPONENTS  ROB-DATA2 (Didymos): a large dense body to the south, a dense tilted lens and a dense crust with a gap.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA2): the center
% of mass is 2.3 m off center toward the south, degree 2 is tilted 58 deg from the equator and
% degree 3 is large. No model of a core, a torus and a layer fits (rob_candidates.m,
% analyze_rob.m). The point masses and the sectors put a dense region below the equator toward -x
% and -y and a light region above it toward +y. Few large shapes make that: a large dense body
% toward -y and a dense tilted lens below the equator, under a dense crust 5% of the radius thick
% with a gap at latitude 27 deg, longitude 151 deg. The sizes and the crust's geometry came from a
% search of 17,400 large shapes and count as 8 parameters; AIC does not charge for the search
% itself, so the lead over the sectors and the point masses is not decisive. Fits the background
% density, the three relative densities, the centers of the two bodies and the axes of the lens
% to the coefficients of degrees 1-5 and Ixx, Iyy, Izz. A few seconds.
% Writes results/hera_hlp6/finder/ROB-DATA2/components/: solution.txt, solution.mat (read by
% rob2_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/. The run
% before moves to history/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 2;                                                % ROB-DATA2
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
cof = body.centroid_km;                                    % positions are from the center of figure
rm  = (3*body.volume_km3/(4*pi))^(1/3);                    % mean radius [km]
south = sbtk.interior.ellipsoid("south", cof + [-0.01 -0.40 -0.08]*rm, 0.775*rm*[1 1 1], [0 0 0], 0);   % a sphere the surface clips
lens  = sbtk.interior.ellipsoid("lens", cof + [-0.26 0.11 -0.34]*rm, [0.63 1.33 0.48]*rm, [4 57 -93], 0);
crust = sbtk.interior.sector("crust", [0.95 1], [-77 90], [-180 180], 0);   % all but 13 deg about lat 27, lon 151
crust = sbtk.interior.set_axis(crust, [cosd(-27)*cosd(-29) cosd(-27)*sind(-29) sind(-27)]);
south.estimate_position = true;
lens.estimate_position = true;
lens.estimate_axis = true;
components = [south lens crust];

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too

%% RUN
out  = sbtk.io.solution_run("hera_hlp6", sprintf("ROB-DATA%d", number), "components");
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.internal.fewer_dof(sbtk.invert.run(prob), 8);  % chosen outside the fit: radius, 3 semi-axes, crust pole (2), edge, depth
sbtk.io.report_inversion(out, body, obs, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("south body, lens, crust with a gap", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

rob_finish(out, number, "components", solution);
    MATLAB script: projects/hera_hlp6/rob/data3/rob3_components.m
    %% ROB3_COMPONENTS  ROB-DATA3 (Didymos): a dense core, a light thick torus about the spin axis and a dense surface layer.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA3): J2 is 570
% sigma lower and J4 95 sigma higher than at constant density, and little else changes: a light
% ring about the spin axis, mass moved out of the equatorial plane. The torus is large and
% thick: of the four ring and tube radii tried (1.00 or 1.05, 0.25 or 0.30 of the mean radius;
% rob_candidates.m, ranked by analyze_rob.m) this one has the lowest AIC. The core is placed
% by its chi-square profile along the center-of-mass offset, then fitted with the densities.
% Fits the background density, the three relative densities and the core's center to the
% coefficients of degrees 1-5 and Ixx, Iyy, Izz.
% Writes results/hera_hlp6/finder/ROB-DATA3/components/: solution.txt, solution.mat (read by
% rob3_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/. The run
% before moves to history/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m
addpath(rob, hlp6, fullfile(fileparts(fileparts(hlp6)), 'toolbox'));

%% DATA
number = 3;                                                % ROB-DATA3
[obs, body] = rob_package(number);                         % degrees 1-5 and Ixx, Iyy, Izz, Hera uncertainties

%% MODEL
cof = body.centroid_km;                                    % positions are from the center of figure
rm  = (3*body.volume_km3/(4*pi))^(1/3);                    % mean radius [km]
core  = sbtk.interior.sphere("core", cof, 0.40*rm, 0);
core.estimate_position = true;
torus = sbtk.interior.torus("torus", 1.05*rm, 0.30*rm, 0, 0);   % about the z-axis
torus.center_km = cof;
layer = sbtk.interior.layer("regolith", 0, 0.03*rm, 0);        % from the surface to 3% of the radius deep
components = [core torus layer];

%% OPTIONS
opts = sbtk.invert.options(moi_labels={'Ixx', 'Iyy', 'Izz'});
opts.background = "estimate";                              % the background density is fitted too

%% RUN
out  = sbtk.io.solution_run("hera_hlp6", sprintf("ROB-DATA%d", number), "components");
% 1. Place the core: chi-square along the measured center-of-mass offset, the rest of the
%    geometry fixed (sbtk.invert.scan_position), from -0.4 to 0.4 mean radii of the center.
an = sbtk.interpret.anomaly(obs, body, obs.degree);
u  = an.com_offset_km/norm(an.com_offset_km);
fixed = components;
[fixed.estimate_position] = deal(false);
scan = sbtk.invert.scan_position(sbtk.invert.setup(body, fixed, obs, opts), "core", cof + (-0.40:0.025:0.40)'*rm*u);
components(1).center_km = scan.centers_km(scan.best, :);
% 2. Fit the densities and the core's position from there (Gauss-Newton).
prob = sbtk.invert.setup(body, components, obs, opts);
fit  = sbtk.invert.run(prob);
sbtk.io.report_inversion(out, body, obs, fit, sbtk.invert.homogeneous(prob));
solution = rob_solution("core, torus, layer", "components", fit);
fprintf('AIC %.1f with %.0f parameters, reduced chi-square %.2f, p = %.2g\n', solution.aic, solution.parameters, ...
        solution.chi2_reduced, solution.p_value);

rob_finish(out, number, "components", solution);

    MATLAB script: projects/hera_hlp6/rob/data6/rob6_components.m
    %% ROB6_COMPONENTS  ROB-DATA6 (Dimorphos): one light prolate core.
%
% The reading of the coefficients (documentation: Testing with ROB data > ROB-DATA6): all three
% moments of inertia are 30 to 60 sigma larger than at constant density because the inside is
% light, and C22 is 97 sigma lower because that light body is elongated along x. Its tilt gives
% S22 and C21, and its offset of 5.5 m gives the center of mass. A torus or a layer adds nothing
% AIC accepts: a layer of any thickness from 1 to 20 m leaves chi-square at 0.57. The semi-axes
% were chosen on a 2.5 m grid and count as two parameters. The size and the density trade off:
% fits with chi-square below 3 have densities of 993 to 1025 kg/m^3. Gauss-Newton reaches this
% minimum only from a good start, so the start is kept here. Fits the background density, the core's
% relative density, its position along x and the direction of its long axis to the coefficients
% of degrees 1-3 and Ixx, Iyy, Izz; then predicts the acceleration at the GRASS surface point
% (seconds).
% Writes results/hera_hlp6/finder/ROB-DATA6/components/: solution.txt, solution.mat (read by
% rob6_figures.m), fit.txt/.mat, homogeneous.txt, settings.json, log.txt, figures/. The run
% before moves to history/.

clear; close all;
here = fileparts(mfilename('fullpath'));                   % this package's folder
rob  = fileparts(here);                                    % rob/: the functions the runners share
hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m

    The figures and tables#

    DATA AND SOLUTIONS writes data/ (rob_data_report); each section after it makes one figure of compared/; THE GRASS POINT and TABLES write its tables. The Didymos scripts have no GRASS section.

    MATLAB script: projects/hera_hlp6/rob/data4/rob4_figures.m

%
% Run first: rob4_components.m, rob4_sectors.m and rob4_point_masses.m (once with weighting
% "sensitivity", once with "equal"). Run DATA AND SOLUTIONS, then any section: each makes one
% figure (SOLUTIONS SIDE BY SIDE before TABLES, which uses its cuts). Writes
% results/hera_hlp6/finder/ROB-DATA4/data/ (rob_data_report.m) and compared/: figures/<name>.png and
% tables/<name>.md; rob_update_documentation(4) copies them to the documentation page.
% A few minutes, most of
% them for the GRASS point of constant density.

clear; close all;

hlp6 = fileparts(rob);                                     % hera_hlp6/: rob_data.m, hlp6_uncertainties.m

S = [rob_load(number, "components"), rob_load(number, "sectors"), rob_load(number, "point_masses_sensitivity")];
W = [S(3), rob_load(number, "point_masses_equal")];        % the two weightings of the point masses

an = sbtk.interpret.anomaly(obs, body, L);                 % the measurements minus constant density

%% SOLUTIONS AGAINST THE MEASUREMENTS
% Each solution's CS - CS_CD with ROB's values, and (CS_computed - CS_ROB)/sigma.
models = arrayfun(@(s) sbtk.interpret.anomaly(s.model, body, L), S(shown), 'UniformOutput', false);
moi = zeros(numel(shown), 3);
for i = 1:numel(shown)

    How the models were chosen#

    projects/hera_hlp6/analyze_rob.m fits every candidate of rob_candidates.m to a package, two searches of the geometry (sbtk.search.run) and the point masses, and ranks them all by the Akaike information criterion, AIC = χ² + 2 × the number of parameters. A regularized fit counts its effective number of parameters; a search counts each size it chose on its grid as well as the densities and positions it estimated. The model of each kind with the lowest AIC is the one its runner fits, except that on ROB-DATA2, 5 and 6 a later search found better models with components; the header of each runner says how. To try another model, copy a component runner, change MODEL, and compare the AIC it prints with the others (Testing with ROB data).
