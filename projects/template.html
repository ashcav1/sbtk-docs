    Project template#

    Last edited October 20, 2026

    A project is a folder of runner scripts for one body that write to results/<project>/. The folder projects/template/ is the starting point for a new body. Body-specific numbers are kept in one settings function, my_body.m; nothing body-specific is in the toolbox.

    Files#

    File Purpose
    my_body.m Returns the body (shape model and its length unit, bulk density, reference radius), the gravity degree and the density-grid spacing.
    simulate_measurements.m Simulates exact measurements of a prescribed interior and writes a measurement package and an interior-model package.
    invert_measurements.m Gives the measurements of a package uncertainties, estimates component densities and writes a solution package.
    compare_with_truth.m Compares an inversion with the true model of a simulation, by component and on the density grid.

    As delivered, the template runs on data/shapes/example_asteroid.obj, a synthetic body of about 1.2 km. tests/integration/test_template_project.m runs the three scripts.

    Use#

    1. Copy projects/template/ to projects/<body>/.
    2. In my_body.m, replace the shape file, its length unit, the bulk density (or use sbtk.body.from_mass), the reference radius, the degree and the grid spacing. The shape must be closed and star-shaped about its center of mass (Shape models).
    3. Set project at the top of each script.
    4. In simulate_measurements.m, edit the sections PROJECT, NAME AND DELIVERY and INTERIOR. The simulation writes exact values, without uncertainties or noise.
    5. In invert_measurements.m, edit UNCERTAINTIES (the 1σ the receiving team gives the exact values), MODEL and OPTIONS.
    6. Run the scripts in order. Each run writes its own folder (Results folders); the inversion finds the newest simulation of the given name with sbtk.io.latest_run.

    A simulation run writes

    Simulation run folder
    results/<project>/<date_time>_<name>/
  log.txt                               everything printed (includes the true model)
  redacted/<team>-DATA<n>-<name>/       measurement package: nothing about the interior
  unredacted/<team>-MOD<n>-<name>/      interior-model package: true model, density grid, the same exact values
  unredacted/                           measurements.*, truth.*, settings.json, figures/

    Code#

    MATLAB: projects/template/my_body.m
    function [body, degree, grid_km] = my_body()
%MY_BODY  Everything specific to your asteroid, used by every runner in this project.
%
%   [body, degree, grid_km] = my_body()
%
%   Replace the shape file (and its length unit), the bulk density, the reference
%   radius, the degree and the grid spacing with your own. The measurement
%   uncertainties are set by the receiving team in each inversion run (invert_measurements.m).

shape = sbtk.shape.load(fullfile(sbtk.root, 'data', 'shapes', 'example_asteroid.obj'), ...   % your shape model
                        "km");                                                               % its length unit: "km", "m" or "cm"
body  = sbtk.body.create("Example asteroid", shape, ...
            2000, ...       % bulk density [kg/m^3]
            0.60);          % reference radius of the gravity coefficients [km]
degree = 4;                 % highest degree of the gravity field
grid_km = 0.040;            % cell edge of the density grids in model and solution packages [km]
end
    MATLAB script: projects/template/simulate_measurements.m
    %% SIMULATE_MEASUREMENTS  Synthetic measurements of a prescribed interior, for any body.
%
% Edit NAME and INTERIOR; the body is defined in my_body.m. The measurements are the exact
% values of the interior, without uncertainties or noise: the receiving team applies its own
% (invert_measurements.m). Writes results/<project>/<date_time>_<name>/:
%   redacted/<team>-DATA<n>-<name>/    measurement package to send (nothing about the interior)
%   unredacted/<team>-MOD<n>-<name>/   interior-model package (true model, density grid,
%                                      the same exact values, figures)
%   unredacted/                        measurements.*, truth.*, settings.json, figures/
%   log.txt
% Package format: docs/exchange_format.md.

clear; close all;
here = fileparts(which('simulate_measurements'));
addpath(here, fullfile(fileparts(fileparts(here)), 'toolbox'));
[body, degree, grid_km] = my_body();

%% PROJECT, NAME AND DELIVERY
project     = "my_asteroid";
name        = "T1";
team        = "TEAM";                 % team identifier in package names
number      = 1;                      % package numbers: <team>-DATA<number>, <team>-MOD<number>
prepared_by = "Team name, contact";

%% INTERIOR
% Components with their relative density (density minus background, kg/m^3);
% lengths in km. See sbtk.interior: sphere, ellipsoid, torus, layer, sector. Spheres,
% ellipsoids and tori are placed from the center of figure (cof), layers and sectors are
% measured from the center of mass.
cof = body.centroid_km;
components = [ ...
    sbtk.interior.sphere("core",     cof,                                     0.250, +500), ...
    sbtk.interior.layer("regolith",  0.000, 0.020,                                   -800), ...
    sbtk.interior.sphere("boulder",  cof + sbtk.interior.latlon(10, -40, 0.35), 0.060, +900)];
field = sbtk.interior.no_random_field();     % or sbtk.interior.random_field(sigma kg/m^3, correlation length km, seed)

%% RUN
out = sbtk.io.new_run(project, name);
[exact, truth] = sbtk.data.simulate(body, sbtk.interior.create(components, field), degree, name);   % the true model
sbtk.io.report_simulation(sbtk.io.subfolder(out, "unredacted"), body, exact, truth);
data_set = sprintf("%s-DATA%d-%s", team, number, name);
sbtk.exchange.write_data(fullfile(out.folder, "redacted"), data_set, body, exact, prepared_by);
sbtk.exchange.write_model(fullfile(out.folder, "unredacted"), sprintf("%s-MOD%d-%s", team, number, name), ...
                          data_set, body, truth, exact, grid_km, prepared_by);
sbtk.io.finish_run(out);
    MATLAB script: projects/template/invert_measurements.m
    %% INVERT_MEASUREMENTS  Component densities from gravity coefficients and moments of inertia, for any body.
%
% Edit DATA, UNCERTAINTIES, MODEL and OPTIONS. Writes results/<project>/<date_time>_<name>_inversion/:
% fit.txt / .mat, homogeneous.txt, settings.json, log.txt, figures/.

clear; close all;
here = fileparts(which('invert_measurements'));
addpath(here, fullfile(fileparts(fileparts(here)), 'toolbox'));
[~, ~, grid_km] = my_body();
team = "TEAM";  prepared_by = "Team name, contact";

%% DATA
project = "my_asteroid";
name    = "T1";
data_folder = sbtk.exchange.locate(sbtk.io.latest_run(project, name), "DATA");   % or any package folder
[obs, body] = sbtk.exchange.read_data(data_folder);

%% UNCERTAINTIES (1-sigma): ours, since the package has exact values
unc = sbtk.data.uncertainties( ...
    [sbtk.units.offset_to_degree1(0.005, body.R_ref_km), ... % degree 1: 5 m center of mass
     1e-4, 2e-4, 4e-4], ...                                 % degrees 2..degree (fully normalized)
    2e-3, ...                                               % each moment of inertia, as a fraction of M R_ref^2
    0.02);                                                  % libration ratio (B-A)/C
obs = sbtk.data.set_uncertainties(obs, unc);
% obs = sbtk.data.add_noise(obs, 1);                         % noise drawn from them, if wanted

%% MODEL (geometry fixed; relative densities estimated)
cof = body.centroid_km;                                     % center of figure of the package's shape model
components = [ ...
    sbtk.interior.sphere("core",     cof,          0.250, 0), ...
    sbtk.interior.layer("regolith",  0.000, 0.020,        0)];
% Without assumed structure:
% components = sbtk.interior.sector_grid([0 0.45 0.8 1], [-90 0 90], [-180 -90 0 90 180]);

%% OPTIONS
opts = sbtk.invert.options();
opts.moi_labels = {'Ixx', 'Iyy', 'Izz'};   % moment-of-inertia measurements used ({} = gravity only)

%% RUN
out  = sbtk.io.new_run(project, name + "_inversion");
prob = sbtk.invert.setup(body, components, obs, opts);
if numel(components) > 6
    prob.opts.regularization = sbtk.invert.choose_regularization(prob);    % many components
end
fit = sbtk.invert.run(prob);
hom = sbtk.invert.homogeneous(prob);
sbtk.io.report_inversion(out, body, fit, hom);
sbtk.exchange.write_solution(out.folder, sbtk.exchange.solution_name(team, obs.name), body, fit, hom, grid_km, prepared_by);
sbtk.io.finish_run(out);
    MATLAB script: projects/template/compare_with_truth.m
    %% COMPARE_WITH_TRUTH  Compare an inversion with the true model of a simulation, for any body.
%
% Reports R2 (fraction of the variance of the true density explained by the
% estimate), R2_max for the same components, the RMS density error and each
% component's estimated and true density; then compares the density grids of the
% solution package and the interior-model package cell by cell. Writes
% results/<project>/<date_time>_<inversion>_comparison/: comparison.txt / .mat,
% grid_comparison.txt, figures/comparison.png, figures/truth_vs_estimate.png.

clear; close all;
here = fileparts(which('compare_with_truth'));
addpath(here, fullfile(fileparts(fileparts(here)), 'toolbox'));
body = my_body();

project       = "my_asteroid";
truth_run     = "T1";              % simulation
inversion_run = "T1_inversion";    % inversion

simulation = sbtk.io.latest_run(project, truth_run);
inversion  = sbtk.io.latest_run(project, inversion_run);
truth = sbtk.io.load_truth(simulation);
fit   = sbtk.io.load_fit(inversion);
out   = sbtk.io.new_run(project, inversion_run + "_comparison");
sbtk.io.report_comparison(out, body, truth, fit, sbtk.compare.with_truth(body, truth, fit));

% the solution package against the interior-model package, cell by cell
cmp = sbtk.compare.grids(sbtk.exchange.read_grid(fullfile(sbtk.exchange.locate(simulation, "MOD"), "density_grid.txt")), ...
                         sbtk.exchange.read_grid(fullfile(sbtk.exchange.locate(inversion, "SOL"), "density_grid.txt")));
writelines(sbtk.compare.grid_summary(cmp), fullfile(out.folder, "grid_comparison.txt"));
sbtk.io.finish_run(out);
