    Hera blind test#

    Last edited October 29, 2026

    projects/hera_hlp6/ contains the runner scripts SBTK uses in a blind test of interior-modeling methods for the binary asteroid Didymos–Dimorphos, the target of ESA's Hera mission. In such a test one team simulates measurements of an interior it keeps hidden and shares only the measurements; other teams estimate the interior; the hidden models are released afterwards and compared with the estimates on a common density grid. The makers deliver exact values, without uncertainties or noise; each receiving team weights them with uncertainties of its own choosing. SBTK's inversion runners use those of the Hera end-to-end simulation, read from files on the Hera working-group server (Didymos and Dimorphos values); the runners need copies in data/hera_rse/.

    Files#

    File Purpose
    hlp6_didymos.m, hlp6_dimorphos.m Settings shared by every run of one body: shape model, mass, reference radius, degree, density-grid spacing.
    hlp6_team.m Team identifier and contact written into package names and files.
    hlp6_uncertainties.m The receiving team's uncertainties: the Hera radio-science precision of the gravity coefficients (to degree 5 for Didymos, 3 for Dimorphos, to which the coefficients are truncated), the inertia elements and the libration ratio.
    simulate_didymos.m, simulate_dimorphos.m Simulate measurements of a hidden interior; write the measurement package and the interior-model package.
    invert_didymos.m, invert_dimorphos.m Invert a measurement package (by default the redacted package of the newest simulation); write a solution package.
    invert_didymos_sectors.m The same with a 36-sector grid, the background held at the bulk density and regularization by the discrepancy principle.
    invert_received_data.m Invert another team's package (SBTK format) or a gravity file in the PDS SHADR layout.
    compare_didymos.m, compare_dimorphos.m Compare an inversion with the hidden model, by component and on the density grid.
    rob_data.m Read a ROB package (shgrav.txt, moi.txt) with the receiving team's uncertainties.
    analyze_rob.m, rob_candidates.m Read a ROB package and rank every candidate model by AIC: how the models of the ROB runners were chosen (Testing with ROB data).
    rob/data<n>/ One runner per ROB solution (components, sector grid, point masses) and the script of each package's figures and tables (Code of the ROB solutions).
    rob_surface_point.m What the Dimorphos surface point adds: a buried sphere under it.

    Where each of these values comes from, and the alternatives: Didymos and Dimorphos values. A run on the full-resolution models takes minutes: the geometry of 3 million facets to degree 10 takes about a minute and 4.5 GB, and a simulation repeats it until the center of mass settles.

    Simulation runs#

    A simulation runner has four sections:

    1. NAME AND DELIVERY: the run name, the package number n, and the inertia quantities the package contains (any of Ixx … Iyz, libration, or none; sbtk.data.select_moi).
    2. INTERIOR: components and random field (Density distributions), in the axes of the DART shape-model file with positions measured from the center of figure (cof = body.centroid_km), not from the origin of the file, which is 57 m from it for Didymos (Where to place components). The torus lies about the z-axis through cof. align_with_spin_axis names the components whose axis is set along the axis of the largest moment of the whole true model (Didymos: "torus", which forms about the spin axis; Dimorphos: none), with sbtk.interior.align_with_spin_axis.
    3. FRAME OF THE PACKAGES: "shape", as the HLP6 makers agreed: the frame and origin of the DART shape model file as distributed, with the gravity field (degree 1 included) and the moments of inertia about that origin. The alternatives "spin" and "principal" move everything to the center of mass of the true model and rotate it into its spin or principal axes (Frames of a gravity field).
    4. RUN: sbtk.interior.create and sbtk.interior.align_with_spin_axis; sbtk.data.simulate (the true model and its exact values, without uncertainties); sbtk.data.select_moi and, for "shape", sbtk.data.expand_about to the origin of the file (for "spin" or "principal", sbtk.gravity.center_of_mass_frame and sbtk.body.to_frame, sbtk.interior.to_frame, sbtk.data.to_frame, with the shape model moved and rotated: The shape model of a package); then sbtk.io.report_simulation, sbtk.exchange.write_data (a package of exact values: no 1σ columns, no covariance file, Exchange packages) and sbtk.exchange.write_model.

    The run folder separates what may be shared from what may not:

    Simulation run folder of projects/hera_hlp6
    results/hera_hlp6/<date_time>_<name>/
  log.txt                          everything printed, including the true model
  redacted/<team>-DATA<n>-<body>/  the measurement package to share
  unredacted/<team>-MOD<n>-<body>/ the interior-model package, shared after the estimates
  unredacted/                      measurements.*, truth.*, settings.json, figures/

    Only the package folder in redacted/ is shared: log.txt and everything in unredacted/ contain the true model.

    Maker models#

    examples/make_didymos_1.m to make_dimorphos_3.m are six true models made the same way, one script each, into results/didymos_models/ and results/dimorphos_models/, as packages 1 to 6. Didymos and Dimorphos share one numbering because a solution name carries only the number; the T1 demo sets of the simulate scripts are 7 and 8. They send exact values of every degree to 10, normalized and unnormalized, and Ixx, Iyy, Izz, in the frame and about the origin of the DART shape model file (degree 1 and C¯21, S¯21 are not zero). The packages name that file but do not include it.

    The interiors of these models are not described on this site, which is public, until the true models are released; projects/hera_hlp6/README.md in the repository lists them. examples/make_didymos_homogeneous.m makes the reference the makers compare, as their cross-validation asks (Didymos and Dimorphos values): Didymos at 2600 kg/m³, every degree to 10 and all six inertia elements, in the same frame and about the same origin, and the potential and acceleration at the 20 agreed points (sbtk.exchange.write_potential; package UCB-DATA0-Didymos-homogeneous). Its degree 1 gives the center of figure. If two makers compute the same homogeneous field from the same shape model file, they work in the same frame with the same conventions. tests/integration/test_maker_scripts.m runs make_didymos_3, make_dimorphos_3 and make_didymos_homogeneous and checks their packages.

    Inversion runs#

    invert_didymos.m reads the redacted package of the newest simulation of the given name with sbtk.exchange.locate and sbtk.exchange.read_data, exactly as another team receives it. Its coefficients, degree 1 included, and its moments of inertia are about the origin of the shape model file, and the inversion predicts the model's about the same point, with no change of frame (Density estimation). hlp6_uncertainties.m then gives the exact values the receiving team's uncertainties (the Hera radio-science precision, truncating the coefficients to the degree it covers). Its model places the core and the torus at the center of figure of the package's shape model, as a receiving team would, and estimates the torus axis and height (Estimated geometry): estimate_axis = true, estimate_position = [false false true], with a priori 1σ of 1° and 10 m and limits of 10° and 50 m. It writes fit.*, homogeneous.txt, figures and the solution package <team>-SOL_<data team><n>/. invert_received_data.m does the same for a package from another team, or, with the commented lines, for a SHADR-layout gravity file, for which the shape model and the point the coefficients are about must be given.

    Comparison runs#

    compare_didymos.m loads the newest simulation and inversion of the given names and the body from the simulation's measurement package (so that all three are in the frame of the packages), compares the fit with the true model (sbtk.compare.with_truth) and compares the solution package's density grid with the interior-model package's (sbtk.compare.grids), which is the comparison every team's solution receives.

    Example runs#

    The delivered interiors (named T1) include a boulder and a random density field that the delivered inversion models do not contain. Weighted by the uncertainties of the end-to-end simulation, the χ2 test rejects the inversion models of both bodies, and the estimated densities are biased accordingly. At this precision an inversion model has to include structure down to the scale of such features to pass the test (Goodness of fit). For Didymos T1, whose torus is aligned with the spin axis of the true model (3.7° from the z-axis of the DART file), the model with the torus about the z-axis and fixed geometry has a reduced χ2 of 157 and R2=0.49. Estimating the torus axis and height lowers χ2 to 49 but R2 to −1.95: the torus moves 50 m, to its limit, and tilts 6.9° to take up the signal of the boulder, which the model lacks (Estimated geometry). The run takes about a minute. For Dimorphos, an ellipsoidal core and the regolith give a reduced χ2 of 47 and R2=0.04.
