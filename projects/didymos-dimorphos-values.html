    Didymos and Dimorphos values#

    Last edited October 20, 2026

    Every value SBTK uses to model Didymos and Dimorphos, where it comes from and how it is used. Each value is one of:

    • agreed: the value the Hera blind-test group uses (projects/hera_hlp6/hlp6_didymos.m, hlp6_dimorphos.m);
    • derived: computed from other values in this table;
    • assumed: an SBTK choice, not a measurement;
    • published: from a paper or a public data product.

    A copy of this table with the files of the Hera working group it was checked against (their locations and the values of the end-to-end test products, which are not for redistribution) is projects/hera_hlp6/VALUES.md in the repository.

    Shape models#

    The shape models are the DART stereophotoclinometry (SPC) models, Didymos version 3 and Dimorphos version 4 (from before the DART impact). They are distributed by ESA in the Hera SPICE kernels (digital shape kernels, at spiftp.esac.esa.int/data/SPICE/HERA/kernels/dsk/). sbtk.shape.bundled loads them by name. The volume and the volume-equivalent diameter D=(6V/π)1/3 are derived from each file.

    bundled name File Sampling Facets Volume (km³) D (m) Use
    didymos didymos_g_9309mm_spc_obj_0000n00000_v003.obj 9.3 m 49,152 0.20336 729.6 agreed for the blind test
    didymos_highres g_01165mm_spc_obj_didy_0000n00000_v003.obj 1.165 m 3,145,728 0.20381 730.1 the most detailed Didymos model; not in git (160 MB)
    didymos_every8 g_01165mm_spc_obj_didy_0000n00000_v003_every8.obj 9.3 m 49,152 0.20375 730.1 derived: every 8th grid point of didymos_highres
    dimorphos g_00243mm_spc_obj_dimo_0000n00000_v004_every8.obj 1.94 m 49,152 0.0017597 149.8 derived: every 8th grid point of dimorphos_highres; used for the blind test
    dimorphos_highres g_00243mm_spc_obj_dimo_0000n00000_v004.obj 0.243 m 3,145,728 0.0017602 149.8 the most detailed Dimorphos model; not in git (160 MB)

    Points to know:

    • Use the same file as the other teams. The 9.3 m Didymos file is a separate product, not a subsample of the 1.165 m model: its volume is 0.22% smaller, its center of figure is 0.35 m away, and its degree-2 coefficients differ by up to 3×10−4, about the size of the measurement uncertainties. Data made with one file and inverted with another carry that difference as an error.
    • Dimorphos. The group's Dimorphos file is an official 1.94 m product. SBTK does not have it yet and uses its own 1.94 m subsample of the 0.243 m model (dimorphos), which may differ from it in the same way. The models are from before the DART impact, which may have changed the shape.
    • Frame. Each file has its own body-fixed frame, z along the spin axis. The origin of the Didymos files is not the center of figure (57 m from it); the HLP6 makers keep that origin (Frames of a gravity field).
    • Shape models describes how SBTK reads and checks them; data/shapes/README.md compares the subsampled and full-resolution models.

    Mass and GM#

    Quantity Didymos Dimorphos Kind Source
    Mass M 5.273 × 10¹¹ kg 2.700 × 10⁹ kg agreed Didymos Reference Model v6.2 (Makadia et al. 2026), the masses the Hera radio-science end-to-end test was made with
    Gravitational constant G 6.67430 × 10⁻²⁰ km³ kg⁻¹ s⁻² same published CODATA 2018 (sbtk.units.G)
    GM 3.51936 × 10⁻⁸ km³/s² 1.80206 × 10⁻¹⁰ km³/s² derived GM

    The maker packages give GM and the mass (GM/G). sbtk.exchange.read_data takes the mass from GM, so a package from a team that used another G gives that team's mass.

    Bulk density#

    The bulk density is derived: the mass divided by the volume of the shape model in use. It is not set separately, and it is the background density of a homogeneous model (Density distributions).

    Shape model Didymos Dimorphos
    Blind-test files (didymos, dimorphos) 2593 kg/m³ 1534 kg/m³
    Full resolution (didymos_highres, dimorphos_highres) 2587 kg/m³ 1534 kg/m³

    Gravity field settings#

    Setting Didymos Dimorphos Kind Source
    Reference radius Rref 0.43 km 0.10 km agreed the reference radii of the gravity fields of the Hera radio-science end-to-end test
    Degree of the receiving team's fit 5 3 agreed the degrees of those fields; finders truncate to them
    Degree the makers send 6 6 assumed the makers send every degree to 6; finders truncate
    Expansion point and axes origin and axes of the shape model file same agreed the HLP6 makers (Exchange packages)
    Inertia data Ixx, Iyy, Izz about the same origin same assumed the maker models (Hera blind test)

    Coefficients given with another reference radius R′ convert as C¯lm′=C¯lm(R/R′)l (Gravity coefficients).

    Uncertainties#

    The makers send exact values. Each receiving team chooses its uncertainties; SBTK's inversion runners use the precision of the Hera radio-science end-to-end test (projects/hera_hlp6/hlp6_uncertainties.m), which is not distributed with SBTK (Hera blind test).
